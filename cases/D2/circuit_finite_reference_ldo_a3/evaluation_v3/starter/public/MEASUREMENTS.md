# A3 固定环境与测量定义

`contract.json` 和原封存代码定义精确数值；本文件解释测量物理口径。新增测量提取器尚未接入。

参考宏模型：设 e=clip(VIN/1.2,0,1)，指令 u=VSET×e，经 R=1 MΩ、C=5 pF 滤波得到 x。令 z=tanh((x−VREF)/(10kΩ×20µA))，h=clip((VIN−VREF)/50mV,0,1)。上拉电流 VIN→VREF 为 e×10µA×(1+z)×h；下拉 VREF→VSS 为 e×10µA×(1−z)；基础供电电流 VIN→VSS 为8µA×e。输出另有20pF与1TΩ泄放电阻，用于零供电操作点的确定性；标称10kΩ为驱动支路的小信号值，实际并联1TΩ后变化可忽略。正常余量且无负载时两驱动各10µA，参考净电流为0；净差分驱动斜率为1/10kΩ。过载趋向±20µA，非硬截断；不额外添加理想0.4V源到参考输出。指令状态使用理想行为源仅表征控制信息，其非物理RC功率不算额外外部供电；输出电流的能量通过 VIN→VREF 支路真实扣到参考供电，基础电路开销用固定8µA表征。

两个同电压电源分别给 DUT 与参考，PSR 时二者 AC=1 同相，startup 二者同时100µs线性爬升。0V串联 VREFS 记录 DUT 参考端口电流；正号表示从参考进入 DUT。电压误差以命令 VSET 比较，启动只在200µs以后使用稳态参考阈值。

DC：`.dc ILOAD 0 20m 0.1m`，必须有201个点且负载坐标正确。有限参考30点矩阵与trim4点分别标记。组1检查所有点输出相对2.5×VSET；组2检查vref与i(VREFS)；组5比较每点的供电预算。

PSR：20mA、27°C，`.ac dec 80 10 10Meg`；拒斥为 `−20log10(|Vout/Vin_ac|)`，Vin_ac=1。在1k、100k、1Meg读取，不能错误减去一条参考供电造成重复归一化。每供电的1k阈值分别30/35dB。

负载瞬态：0.5→20→0.5mA，PWL边沿20–21µs和60–61µs，仿真0–100µs。输出峰值窗[20,41]、[60,81]µs≤150mV；恢复窗[41,60]、[81,100]µs≤30mV。全时段参考误差≤10mV，|i(VREFS)|≤10µA。

启动：Rload=2kΩ，0–400µs，VIN在0–100µs线性爬升，不使用恒流负载或UIC；输出全程峰值≤1.05V，200–400µs误差≤20mV；参考200–400µs误差≤2mV。记录启动积分能量，不单独打能量分。

对每条供电 j，`Pj=max(−Vj×I(Vj),0)`；`P_total_positive=P_DUT+P_reference`。DC要求 `Ptotal≤VIN×(Iload+100µA)`。动态为积分Ptotal/100µs≤VIN×(积分Iload/100µs+150µA)。这是计入所有供电的输入功率预算；不把负载所需电流当成空载静态电流，也不将VIN侧负载项误称为输出功率。记录 `Vout×Iload` 和功率损耗作诊断，不能用它替代本题预算。

新增数值设置：reltol=1e−4、abstol=1e−12、vntol=1e−7、Gear2；负载瞬态最大步长5ns、启动50ns。原题数值选项保持字节不变。波形提取须插值加入测量窗端点，检查有限值、时间覆盖和步长，不用粗采样漏掉峰值；校准必须用半步长复核临界结果。边界相等按通过；除电容原有容差外不偷偷加阈值宽限。
