# URMP v2：按请求创建排练卡

90秒真实URMP源素材（源时间5–95秒），五幅演奏画面重新排列，五条独立音轨重新匿名。包含两位小提琴手、两位中提琴手和一位大提琴手；画面与声音保持原同步。作者原本分开录制并同步合成，本题又裁切重排画面，不是同场实录。

组合修改1、2、4：按自然语言排练请求定位事件并执行；通过休止/进入辨认同类乐器的声部对应；在粗略概览之后主动选择局部音视频证据。没有加入失同步故障，未使用预制网页骨架。

三条请求的准确操作定义以public/TASK.md为准：

1. 找到红衫中提琴手第二次至少3.5秒的内部休止，在其中从灰衫中提琴手第一个音到红衫再进入，生成去掉灰衫声部的循环卡。
2. 找到后半段印花T恤小提琴手第一次在至少2.5秒休止后回归，循环其前四个音，只播放该小提琴与大提琴。
3. 找到两位小提琴手共同休止至少2秒后，首次至少错开0.7秒进入的位置，从较早者起音到较晚者第三音结束；去掉较早声部，按请求分配其余增益。

初始提供四帧和全曲2秒粒度的粗略能量/发声率/音高概览；详细音频工具一次最多2轨、8秒，总预算96轨秒。视频工具一次最多4秒、8帧，可裁切指定画面位置；总预算32帧。最多两批自适应只读取证，最多12次工具调用；首次最终提交即封存，不允许候选网页执行、预览、测试、评分反馈或返修。

60分考内容与决策：声部位置/乐器15、三条请求的起止/目标/增益36、可核实且相关的音视频引用9。40分考实际执行：普通媒体/混音/传输10、三张卡24、切换和手动控件4、布局与来源2。内容分对照真实请求，执行分检查网页是否正确实现自己提交的计划；两者分别报告。

共享工具读取匿名WAV进行信号分析，不读官方标注或原始轨名；不输出乐器、人物和请求答案。网关仍无原生音频输入，因此只声称工具辅助的多模态agent任务。只测一个公开片段、每个网关别名一次，未做正式模态消融，也不宣称训练数据未见。
