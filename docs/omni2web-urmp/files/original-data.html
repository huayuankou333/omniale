合并方法

将全部分卷、urmp-parts.json与merge-urmp.ps1放在同一目录，在该目录运行下列命令。脚本先核验每卷SHA256，再合并并核验完整ZIP，不覆盖已有文件。

powershell -ExecutionPolicy Bypass -File .\merge-urmp.ps1

也可在Linux/macOS按序拼接：

cat case9_urmp_original-data_v2.zip.[0-9][0-9][0-9] > case9_urmp_original-data_v2.zip
sha256sum case9_urmp_original-data_v2.zip

完整ZIP SHA256：

42d1f70481a497203eceab7b094f6a15ee9ffec97156c0396d04214ad95af0aa

合并后正常解压ZIP即可。逐文件来源与哈希在ZIP内MANIFEST.json，分卷哈希在urmp-parts.json。
