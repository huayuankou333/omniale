# 评分规则 v0.1

这是计划采用的明确计分协议。逐项可评分事实、允许时间窗、原声保护区间和工具参考尚未审核冻结；目前不可据此启动正式测试或产生正式总分。冻结时保留本公式，公开告知有实质变化的规则。

## 评测证据与判断顺序

评测基于实际成片、独立AD声轨、原始音视频，以及隐藏的专业AD文稿。先验证工程门槛，再对新增语音转写和对齐，最后逐项核查内容及声音。

专业参考按“信息片段→事实单元”整理。一个信息片段允许包含几个相关事实；每个片段总权重相同，片段内事实等权，避免把长参考句拆得越碎就越占分。姓名、颜色和专名等只有在输入足以辨识且确实有理解价值时才保留为要求。专业参考出现可疑事实时须对照原片修订或排除并留存理由。

隐藏标注须在测试前由组织者对照原片审核并冻结：

- 重要事实与允许的等价表达、稳定人物指代。
- 每个事实适合描述的一个或多个起点区间，以及应播完的最晚时间。
- 需要保护的原旁白、现场对白和有理解价值的声音区间；不把全片音乐设为不可插入区间。
- 每个评分单元的采用、修改或排除理由；不得看完候选模型交付后改变权重。

机器生成的视觉摘要和YouTube ASR只是定位线索；不能直接当人工真值。LLM可辅助匹配与提出疑点，正式评分须保留逐项证据和人工可复核决定。

## 共同变量

设已审核参考含M个信息片段。第i个片段有nᵢ个事实，每个事实权重 `wᵢⱼ = 1/(M×nᵢ)`，全部权重之和为1。

对成片**实际说出的内容**进行匹配：每个参考事实覆盖值 `cᵢⱼ∈{0,0.5,1}`。1为事实及其必要关系准确完整；0.5为明确提到核心但缺少一个必要关系；0为未说、实质错误或只能靠猜。部分得分须指出具体缺项。合理同义表达、拆句、合句及非专名人物称呼均可得满分。

`R = Σwᵢⱼcᵢⱼ` 为重要事实覆盖率。

将全部已播口述拆为有独立事实含义的断言，包含未被参考列出的新增内容。`P = 正确且有画面/原声依据的断言权重 ÷ 全部断言权重`。普通断言权重1，颠倒人物/动作/因果或捏造事件、身份、重要文字的实质错误权重2。每条错误留证据；细节未写在专业参考里不等于错误。没有口述时P=0、R=0。

匹配、断言划分和错误权重均在逐项表中公开，不用一句“整体像参考”代替。重复句仍计入冗余；不能通过大量复述稀释错误。

## A. 重要视觉信息覆盖与准确性：45分

`F₂ = 5PR/(4P+R)`，分母为0时取0。

`S_A = 45F₂`。

参考覆盖R决定是否交代关键画面，准确率P处罚捏造和关系错误。此处不计播报位置，位置在B项计算。同一事实重复播出只覆盖一次。新增正确内容不降低P；没有新增AD或全部错误时得0分。

## B. 插入时机与原声保护：30分

从实际AD声轨得到有效发声区间U，排除纯静音。原声保护区间在开测前冻结，并在边界不确定处留合理余量。

- `O_D = AD有效发声与受保护原对白重叠的秒数 / AD有效发声总秒数`。
- `O_K = AD有效发声与受保护关键非语言声音重叠的秒数 / AD有效发声总秒数`。本片若没有经审核的关键声音，冻结前将该5分并入对白保护项，不临时补造声音要求。
- 对已匹配事实，定义时间偏差δ：实际播报该事实的起点到最近允许起点区间的距离，与实际播完相对该事实最晚期限的超时量，两者取较大值。都满足时δ=0；早于画面成立的时间不得获得“及时”分。`j=max(0,1-δ/2)`，单位秒。
- `J = Σwᵢⱼcᵢⱼjᵢⱼ / R`，R=0时J=0。事实在句中何时出现由实际语音对齐确定；不能只用整段起点蒙混。一个事实合理播报多次时用首次完整成立且可理解的一次作定位，重复仍受C项处罚。

`S_B = R × [15(1-O_D) + 10J + 5(1-O_K)]`。

无AD时S_B=0。覆盖不足时不能靠大量留白、完全避开一切声音获得30分。无需精确复刻专业参考的毫秒起点；允许区间须验证存在自然、清楚且可达到满分的排布。

对白保护按重叠秒数计算，不因原声被压低而豁免。少量不可避免且不影响理解的拟声、笑声等不得未经审核就标成受保护对白；这在标注阶段决定。

## C. 信息精炼与原声互补：15分

对全部已播口述统计冗余时间 `T_red`：无需再解释的原声信息逐义复述、无新作用的AD重复，以及不帮助理解的填充语。必要的消歧或为承接镜头而作的简短指代不算冗余。重叠冗余区间取并集，逐条说明为何可从原声得到或为何是无效重复。

`D = min(1,T_red/AD有效发声总秒数)`；无AD时D=1。

`S_C = 15R(1-D)`。

不按“语句越短越好”评分，不因描述数量与参考不同扣分。不奖励只说一两句而遗漏其余关键内容的空泛简洁。

## D. 实际播报与混音：10分

四项各取 `q∈{0,0.5,1}`，每项最高2.5分，再乘R：

|项目|1|0.5|0|
|---|---|---|---|
|可懂度与发音|正常播放能听清；关键专名/文字正确或用准确替代表达|有少量需重听或非关键误读|多句听不清，或关键误读阻碍理解|
|语速与句内节奏|句子自然，无需靠极快压缩才能听懂|部分句子明显赶或停顿别扭，但可理解|多处无法跟上或严重机械切碎|
|声音层次|AD清楚，原节目仍保持连贯与可听|部分音量遮蔽或跳变，可通过短时重听恢复|AD或原节目经常不可理解|
|编辑完整性|无可闻截字、爆音、断句缺失和不自然硬切|少量局部瑕疵|多处明显截断、缺字或故障声|

`S_D = 2.5R(q₁+q₂+q₃+q₄)`。

逐项至少给出支持该档位的片段；满分不要求名人声线、真人录音或某一种TTS。组织者须先确认预置TTS在本片可达到高质量，工具缺陷不能形成不可达到的评分上限。

## 总分及门槛

`S = S_A+S_B+S_C+S_D`，只在最终显示时四舍五入至1位小数，中间不截断。

工程门槛见 `DELIVERY-SPEC.md`。工程不给基础分。不含实际新增AD的原片交回基线R=0，总分为0；只提交文字而未播出的部分覆盖为0。技术失格、工具故障与内容得分分别记录，不把未播放的产物编成一项听评分数。

满分要求：重要事实准确完整，事实在审核允许的时机播完，不压住受保护原声，内容有补充价值，声音清楚自然，工程可交接。允许多套达到这些条件的表达和排布。

## 开测前校准

1. 用与候选模型同样可用的TTS把专业稿做成参考初稿，实际试听后在允许范围调整，不把它标为原始专业真人录音。
2. 审核确认存在高质量、可达上述高分条件的交付；若专业稿在当前片源版本或工具中无法成立，先修题或换片，再冻结，不能带缺陷开测。
3. 保存无AD基线、故意遮挡对白基线、错配描述基线的分数。无AD必须为0；后两者应在对应维度显著失分。没有原片时不能伪造这些校准结果。
4. 内容参考和规则冻结在候选模型运行之前。对参考未覆盖的正确新信息，按固定政策核查；确有参考错误时作公开勘误并对所有模型统一重评。
