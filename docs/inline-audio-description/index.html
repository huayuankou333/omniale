主体叙事有覆盖，细部动作会丢失。

雪山、家人备餐、唱片浏览、祈祷与用餐、栏杆与影子、收行李和结尾翻滚，都能在候选文稿找到语义对应。

主要遗漏集中在搅拌、车辆经过、布置餐桌、餐食拍照，以及片尾两个明确的接触动作。另有6项只交代了动作的一部分或缺少人物关系。

这个分数衡量什么？

它衡量提交文稿对专业参考信息的覆盖程度。准确率P、实际播报核对、插入时机、对白保护、原声互补及听感未在本次初评中计分，整题正式总分仍未给出。

逐项语义判读由评测助手完成，在服务器Docker中计算并留存。本轮未调用Qwen；参考事实表仍为待正式冻结版本。
