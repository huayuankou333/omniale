# RoomSound：单次交付版

素材与产品功能沿用真实STARSS23空间声音探索器：60秒全景视频、同步四通道FOA、随视角变化的真实立体声、动态声源标记、事件时间线、跳转、筛选、循环和音画同步。

本版按用户要求重新评测：两个模型从空白项目开始，最多两次批量只读取证（合计12次工具调用、12张素材帧，其中3张预先提供），随后一次提交全部网页文件、events.json与evidence.md。首次提交即封存。模型无浏览器、代码运行、网页预览、自检或返修入口。工具调用需要后续API响应接收结果，因此最多3次模型请求，但只有1次产品交付。

评分保留原50分感知与50分实现，使用已修正自定义开关点击方式的同一评分器，并在新运行前冻结。此前多轮成绩不混入本轮。仍为共享ASR/YAMNet/FOA工具辅助评测，不是原生音频能力测试。

详细功能、坐标公式、文件格式及DOM接口见本目录TASK.md；原中文功能说明见../public/TASK.zh-CN.md。
