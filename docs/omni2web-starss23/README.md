# RoomSound：真实空间声音探索器

输入60秒真实房间全景视频与同步四通道空间录音。Agent需要判断哪些声音实际发生、发生在何时何处，并生成随视角改变实际声音的可交互网页。

- GitHub Pages: https://huayuankou333.github.io/omniale/omni2web-starss23/
- 原始数据: https://github.com/huayuankou333/omniale/releases/download/omni2web-data-2026-10-30/case8_starss_original-data_v1.zip
- 完整结果: https://github.com/huayuankou333/omniale/releases/download/omni2web-data-2026-10-30/case8_starss_single_delivery_v1.zip
- 运行轨迹: traces.html
- 原交付在records，部署副本在demos；仅替换媒体路径。
- 单次交付，工具辅助，无原生音频。详见页面限制与原报告。
