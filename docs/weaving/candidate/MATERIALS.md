# 材料与任务边界

目标为装饰性伞绳手链，不用于承重。需要同样粗细、长度充足的两根伞绳、合适插扣、固定架或稳定夹持工具、软尺。使用原片完整示范的两芯版本。

原片展示的配色涉及预先接好的双色绳，也说明可以使用不同纯色整绳。材料配色可以变化，但教程需保持对象命名和实际动作一致。预先接绳可由熟练者完成，不要求学习者自行热接。

原片开编时扣具底座已准备好，没有给出可靠的通用切绳长度、腕围换算公式或完整逐步装扣流程。不要编造精确用量或把未演示过程当成视频事实。可提供明确标注的等效准备方案，或说明应由协助者完成的准备及其可检查结果。

读者能看实物和你的 PDF，不是蒙眼任务。允许暂停操作、翻页和重读。剪切与热处理可交熟练者协助；教程需要清楚说明完成状态及冷却后检查。
