# Flowboard 原创 checklist / 冻结版

在候选生成前固定。目标分数与模型身份不能交给 judge。不能为了达到 80 分阈值改变权重、舍弃高分试次或压低视觉锚点。旧积木题成绩不变，新题不可直接当作旧题重评。

## 计分
功能项按 JSON 中每个 probe 单独判 0/1，得分为 probe.weight × pass。没有“实现了大概意思”的整体印象分。一个组两个 probe，各占一半；不是两者全过才拿全部分的隐性封顶。总分 80 分功能/执行 + 20 分视觉，无额外扣分或能力封顶。

每项需记录：操作前截图、操作序列、操作后截图/视频时间段、期望、实际、判定。只看代码、自述、按钮存在，均不能判成功。导入导出用候选自身格式，不强制 Excalidraw 私有 JSON 字段。画布坐标/字段名/DOM 实现可不同。需要判关系时以导入后真实拖动和 UI 变化为主；自报数据不能替代 UI 证据。

新需求必须被录屏展示，或在 TASK.md 明示。H07、非法 JSON 两类、二次导入不累加等通用语义已经公开。参数复测仅改变节点、位移、颜色或短标签，不能引入未公开功能。

## 视觉锚点（逐状态评分）
1.00：列出的结构、比例、字体、颜色、反馈均吻合；允许手绘随机线条和抗锯齿差异。
0.75：结构与关键比例正确，有一至两个局部字体/间距/颜色差异；无显著遮挡、截断或缺失面板。
0.50：能辨认同一页面和状态，但多个明显样式差异，或一个重要视觉组件缺失/比例明显错误。
0.25：只有粗略布局或主题相似，关键状态大幅不同。
0.00：该状态没有实现或画面与参考无对应关系。

每项列出的参考状态等权平均。遮罩或面板缺失只能按实际状态评分，不因首页美观予以补分。手绘随机种子不作像素级相等要求；不以单一 SSIM 当质量分。不同 judge 在相同截图、相同尺度下判断。比较前对齐相同操作状态，排除录制辅助 RECORDER 条和紫色光标，不将模型页面自身选择框排除。

## 取证与缺失
评测器找不到按钮、坐标偏移、接口/浏览器环境故障属于待补证/基础设施问题，不能默认算模型 0 分。修正定位后重试相同步骤并保留前次日志。候选本身无法完成已公开功能可判相应 probe 失败，须实际证明。前一步失败造成后续不可达时，优先从 Reset 建立最小独立场景；仅能证明端到端链失败时，不凭空判所有底层能力失败。未解决的取证缺失使总分为 N/A，不把缺项平均到已评分项目。

## Judge
功能证据由评测执行者记录，两个 LLM 独立核对；视觉由两个不同模型独立按上述锚点打分。功能分歧，或同一视觉状态相差 >0.25，需依据原始视频补证/裁定。无分歧视觉项平均两名 judge。裁定者身份必须披露；代理复核不得称人工认证。judge 尽量跨家族；同家族或候选自评时明确标记，不能隐藏。每个断言需 evidence 引用，不接受空引用评分。

## 难度校准
新版尚无候选模型分数。先取得四模型有效试测，再至少 3 次独立完整运行评估波动，报告全部分数、最大值、均值和有效率。基础设施失败=N/A。有限试测只能证明这些试次的得分，不能保证未来所有输出 ≤80。若有模型 >80，保留结果，用新增可观察的复杂工作流建立下一个版本，再冻结后重测。

参考实现的箭头重算可能产生不足1像素的浮点差异；内部参考回放检查允许1px几何容差，候选判定也不要求浮点坐标完全相同。此容差在候选运行前登记。
