# Devil Dragon v3：把长折纸教程转为可续作的中文图文指南

你要为会基本山折/谷折、但没有做过这个模型的学习者，将 Jo Nakashima 的 Devil Dragon v3 视频转为一份可执行的中文图文 PDF。学习者需要从正方形纸开始完成作品，并能在中途停下后，依据照片恢复操作。不要假设读者还在同时播放视频。

## 输入

- `/input/input/tutorial.mp4`：作者原教程，64分59秒，1920×1080。视频内的图示和步骤编号是合法参考。
- `/input/input/source_record.json`：作者、来源、时长、作者章节时间。章节标题是检索提示，不是细操作答案。
- `/input/input/resume_cards/`：四组真实正常过程照片；读 `cards.json`。每组最后一张是当前状态；RC02 水平镜像，RC03 旋转180度，其余保持原方向。均已裁去原片右侧图解区；没有合成、添加或删改纸层。需要解释实际照片上的位置，而非仅要求读者自行镜像。
- `/input/evidence.schema.json`：交付索引的结构约定。
- `/input/RUBRIC.md`：预先固定的评分规则。

## 交付

1. `/work/output/tutorial.pdf`：中文图文教程，页数自定，包含：
   - 材料、纸面与初始方向说明，准备到最终整形的完整路径。重复和镜像操作可合并成明确规则，但不能漏掉关键的展开、内折、纸层交换或另一侧操作。
   - 稳定的部位/纸层称呼，至少三类身份贯穿前后状态；区分纸模型自身的部位、当前画面左右、正反面和翻转后的方位。
   - 对关键层次给出实际可看的图、操作方向、操作后检查点。至少五处你自己添加的、指向可辨认纸层或折线的标注，不把原片箭头原样摆上就称为新增标注；包含至少两类头部/手指/翼面的局部细节。
   - RC01至RC04各一张续作说明：当前已完成/尚未完成什么；在该照片上定位具体目标层；下一动作的方向、折线或支点；下一可核对状态；此刻不要误做的动作。必要时可跨数个连续小动作解释，不用猜遮挡下的细节。配来源区间。
   - 至少两条可逆纠错/恢复方法，写明适用状态、退回哪一步、如何检查恢复成功。新增教学建议必须标为推断，不能伪装成作者明确说过的话；不要建议剪开、粘住或强拉层次来跳过步骤。
   - 作者与出处、图像出处、页码、来源时间定位。不要仅给一堆截图、章节标题，或用“照视频继续”替代动作。可以引用作者视频内图解，但要用中文解释操作。
2. `/work/output/evidence.json`：按schema列出PDF页码、来源区间、图、身份表和四张续作卡的索引。该索引用于定位，不能替代PDF里的教学内容。

## 边界

这是一项视频视觉理解与文档制作任务，没有让你实际折出实体。画面或纸层不可确认时，明确写出不确定处并给可复看的位置；不凭想象补出作者未显示的细节。原声保留，但本轮工具以帧提供视觉，无原生听音功能，不要声称听过解说。不要查询隐藏评审答案、其他模型输出或互联网。你可以任意抽取真实视频帧、局部裁切、连续观察与生成标注；这些都是本任务允许的方法。

最终调用 `check_submission` 检查可读文件与索引格式，再检查真实PDF页像素并提交。评分依据真实页面和来源证据，不依赖自报完成情况。
