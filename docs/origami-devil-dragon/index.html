01 / ASSIGNMENT

把“看过教程”变成“能继续折”

面向会基本山折、谷折但未做过该模型的学习者，制作一份无需同时播放原片也能执行的中文图文PDF。完整路径从正方形纸开始，覆盖基础形、手指、翼臂、头颈、面部和最终整形。

模型必须交付

  1. tutorial.pdf：完整路径、稳定的部位/纸层名称与操作后检查点。
  2. 至少5处自建且指向正确纸层或折线的标注，覆盖至少两类局部细节。
  3. RC01–RC04四张续作说明：当前状态、目标层、下一动作、检查状态和误操作提醒。
  4. 至少两条可逆恢复方法；推断必须明示，禁止剪开、粘住或强拉跳步。
  5. evidence.json：页码、来源时间、图像、身份和卡片索引。

真正考察的能力

屏幕位置变化后，仍把同一窄瓣、覆盖层、头、尾和翼对应起来；区分“刚完成的细节”与“下一动作”，避免把整形当成已经完成。

它考察长视频视觉理解、状态追踪和教学文档生成，不包含实体折纸验收。原声虽保留，本轮工具以视频帧提供视觉，没有原生听音。

07 / FAILURE ANALYSIS

状态、实体和操作没有接起来

认错持久部位

RC03第8页用“尾根、尾端”解释头颈照片，并给出尾部回折动作。评审核对原片50:58–52:00及作者第10页106–111步骤，定位为头颈连接。

错过已经完成的状态

RC01第6页未正确利用已完成的第一组手指。下一个阶段应降低／展开中央长瓣，并保护手指细节；笼统整理窄瓣不能替代目标层与支点。

输出漂亮不等于可跟折

Luna可读性5/5，视觉标注仅2/15。圈②⑤落到手部，③落在背景，①未指到所述手指折线，④无法充分确认。教学执行性与排版分开计分。

DeepSeek：更多观察未转为成品

140轮运行没有交付；新开280轮后仍没有PDF或索引。280轮共109次命令、119次看图、48次取帧、4次解析错误；17次工具错误保留在轨迹中。返回297幅JPEG、按字节去重256幅，说明不只是重开同一张图，但没有转入正式文档制作。

该轮280次API请求全部成功；中止由轮次上限触发，而非API故障。最近4批图像保留策略、旧图需要重开，以及耗时的模板匹配操作，都可能影响效率；不能仅用未交付推断模型完全不懂折纸。

DeepSeek后续预算的估计

若工具与策略完全不变，可把400–500轮作为一次探索性上限，相比280轮多120–220轮。这个范围是排程建议，不是由完成曲线拟合出的最低需求，也不保证会交付：到280轮尚无PDF草稿里程碑。

本轮平均17.53有效秒／轮，按恒定速度粗算400–500轮约117–146有效分钟；上下文增长和工具耗时可能使实际更长。建议同时设置120轮前形成完整草稿、200轮前完成四卡、最后80–100轮验证与交付的检查点。加入强制阶段或提示会改变执行协议，应另列结果。
