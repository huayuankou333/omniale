# EasyCom｜指定人物同期声交接

三条独立记录均保留各自 0–60 s 的原始时基。工程区域 **A 00:00、B 01:05、C 02:10** 起。默认只送目标声到主输出；对照时切换本条 TARGET 与 Monitor 的静音，或独奏 Residual 检查移除量。残余不是配好的背景，可能含反相成分。

| 记录 | 从画面绑定到声源 | 优先复核 |
|---|---|---|
| **A** | 20 s 标框为画面右侧格纹衫，保留此人的座位方向轨；灰衣邻座及摄像机佩戴者分别另建空间模型。 | 29–36 s 共同发笑，44–50 s 与近端插话，末段弱声与近端问句交叠；最弱笑尾、辅音及少量串音仍需复核。 |
| **B** | 5 s 标框为左侧灰色 Polo 衫。根据头面位置和场景稳定后的座位方向，随镜头左右摆动更新；局部手挡嘴和转身不停止提取。 | 4–7、37–44 s 中，侧脸、转头与近端发声同时出现，可能仍有弱应答衰减及邻声残留。 |
| **C** | 46 s 标框为最左侧深外套人物，不是旁边的胡须男。用背景求连续镜头转向，把该座位延伸到画外；同时跟踪其他座位，并把开头走动者与佩戴者单列为干扰。 | 开头约 1–9 s、17–20 s 转向及多声同发最不确定；约 43–48 s 跨画外/画内仍按同一人处理。邻座近角度的反射可能残留。 |

按音画标定把方向与六轨相位、能量对应，带回录音估计各人的实际阵列响应。轻量去混响后，联合估计多源时频功率，配合局部空间聚类、经验协方差波束和轻度同相串音消除。口部动作只作弱辅助，未用口型或硬门删重叠；没有生成或替换发言。目标、残余及预览均从零点起，残余按第 5 声道监听减目标计算。

核查采用画面、波形、阵列相关性及本地 ASR 辅助，未作直接听审；不把识别文本或这些诊断当作验收真值。

在 `/workspace` 运行 `bash submission/source/reproduce.sh`。加 `--retrack` 可从提供的画面重新计算视觉参数（固定模型及校验见 `source/MODEL-SOURCES.md`）。无插件依赖，除源码、配置及已交付媒体外不需其他工程素材。
