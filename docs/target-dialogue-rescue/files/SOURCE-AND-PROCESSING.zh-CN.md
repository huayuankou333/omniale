# 数据来源与网页预览处理

来源：Jacob Donley 等人，EasyCom: An Augmented Reality Dataset to Support Algorithms for Easy Communication in Noisy Environments (2021)。官方仓库：https://github.com/facebookresearch/EasyComDataset。

数据许可：CC BY-NC 4.0。原许可文本、作者名单、源素材处理说明随页面公开。真实研究录制中自然发生多人重叠发声，包含餐厅环境噪声播放；纪录片后期委托为题目模拟。

题目只提供原场景画面、六声道阵列混合录音、第五声道监听副本、单帧目标指示和通用标定。视频左侧独立的身份肖像编号栏已移除，场景内部时序不变。没有人工相加干净人声。

网页复制已有服务器预览：960×540 H.264 / AAC、原长60秒。原混合预览来自题包监听声道，目标预览来自封存Sol交付。新增原混合、目标、残余MP3在服务器Docker内由48kHz单声道WAV编码为160k，不额外改变增益、不再降噪、不重剪。三类WAV的600点峰值包络仅用于可视化，同一记录的原混合与目标使用共同幅度尺度。

转码前后核对六个封存目标/残余WAV的SHA256，原交付未改变。处理与文件校验见WEB-MEDIA-MANIFEST.json。网页压缩副本用于试听，不作为无损评分输入。

隐藏近讲轨仅供组织者内容核对，不在页面托管或作为满分参考试听；它不是阵列端逐样本真值。完整题包、无损交付、REAPER原生工程与隐藏参考继续保存在服务器，本地仅获取展示预览和报告。

本轮只制作展示页、记录案例通过和发布，不追加模型运行或改变模型初评分。58.6为现有证据的初评估计，正式模型总分尚未确认。案例通过记录见CASE-ACCEPTANCE.zh-CN.md。
