## 音频、教程方法与导出复现

A1为实际参与导出的英文原声，40段：官方混合轨与局部同一时刻的耳麦捕获。A2按编辑段落保存官方混合参考，**轨道和所有参考片段均禁用**。重新导出请保持A2禁用，避免重复叠音。

编辑前查看本地Blackmagic Design《Working with Audio Track Layers》0–180秒自动转写，并观察28、135、145秒实际教程帧。适用方法是：保留替代材料以便非破坏修改，而且**隐藏轨道不等于静音**；不应参与播放的参考轨必须明确静音/禁用。

具体迁移：

- A1放所选捕获，A2按同输出位置保留原混合参考并明确禁用。实际导出测量确认没有双重叠加。
- 原型18.8–34.8秒用S2耳麦，白板保留意见144.8–151.2秒用离座S1耳麦，领导反驳271.96–294.28秒用S3耳麦；可回到A2对应段比较。
- 耳麦是**同一事件不同捕获**，不是不同表演take。教程的“拼最佳配音表演”不能照搬到真实会议立场；没有拼造新句、改写英文对白或伪造回应。
- 受限脚本接口不提供全部GUI同轨层功能，因此用分开的原生stereo轨落实参考保存/禁用管理，不声称执行了未执行的同轨层comp。

音量采用原生AudioVolume增益和1帧边缘淡化。原始混合轨测得约-52.45LUFS，电平很低；根据离线ASR、真实画面、波形/频段统计与Resolve片段分析选择同事件捕获并平衡增益，再用实际导出测量校正。没有直接向模型提供原音，因此**不声称亲耳听过**工具未提供的音频。没有为了指标强力降噪、改变对白速度或生成语音。

## 编辑取舍与语义边界

1. **旧计划→本次原型→定稿**分别标注。旧计划无LCD、希望动能加电池；本次原型因可打开结构昂贵改提小LCD；最后因成本再删LCD及高级芯片、换普通芯片，电视提供反馈。没有把较晚提议自动升格为决定。
2. 保留初算16.8与2.3→4.3同期纠错。单曲面是未选备选；4键是面板计价估算而非实际4键；删数字键盘特殊色而非整机黄色。0.5是中途余额，后面仍讨论标识/造型费用。最终只说预算内，**不另编精确总价**。
3. 最终预算结论前置到费用段尾，再回看厚度与使用性。黏土不够使模型扁平，2.5厘米为讨论估计而非实测。布局压缩为创新与熟悉性取舍，没有宣布陌生布局获批。
4. 评价量表1更达标、7更差，保留纠错，再给风格2.5、创新3、软弹5。黄色受欢迎程度的疑虑没有因评分折中而消失。不把后面的临时百分比换算包装为性能成功率。
5. 评价后立体造型与主题色系列仅为构想，保留“只是讨论、可以放弃”，没有获批。
6. room的字面误会在先、澄清在后；果蔬潮流色/公司色是具体约束冲突。设备批评保留氛围纠正：**不是氛围，氛围已轻松**。
7. 领导争议保留S1“不是坏领导”的限定、S4追问控制、S3反对control而强调structured/consensus，以及S3随后承认流程规定做法。对象包括简报、辅导和议程结构，不只主持人；不是人身指责、持续敌对或全员一致否定。团队批评保留“你们经历也许不同”“已尽所能”“不是不满意”。
8. 限时收益与概念设计可能多15分钟的例外一并保留。检索不止于2220秒左右第一次收尾；用到2303–2343秒实体/触觉创意反思。
9. S1离座后到白板、后来坐桌左侧新位置，评价用近景2，后续构想用同期Corner，不用近景1空座。宽景其他人仅为同期在场，不剪成异时假反应。最后一句“尺寸”补充不依短句ASR强定身份，**最终字幕已去掉具体说话者前缀**。
