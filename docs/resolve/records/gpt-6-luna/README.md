# ES2002d 决策演变简报｜交付说明

## 复现 / 重链接
- 工程：`project.drp`，DaVinci Resolve 21.1.2.10 免费版导出；时间线“决策演变_信息简报”，25 fps、1280×720。所有画面剪辑、A1官方混合轨与V2原生Text+仍可编辑。
- 在 Resolve 中导入 `project.drp`，若离线，选中媒体池离线项执行 Relink Selected Clips，指向题包 `media/resolve/` 和 `media/audio/` 相应文件。建议优先链接题包兼容MP4；这些仅是原片容器/编码转换副本，原始AVI仍在题包内。
- `final.mp4` 和 `mix.wav` 由上述原生时间线导出；不是外部整片导入Resolve。映射时间均从各媒体0秒起算。`edit_map.json`记录源/输出范围。

## 编辑取舍与局限（请注意）
这是**有限覆盖的工作版**而非完整满足任务的5–6分钟信息简报。总长355秒，但只用了8个会议段落（源时间30–74、175–220、600–645、755–800、1202–1247、1280–1325、1460–1496、1622–1672）。为实交可编辑工程/渲染，没有把不可核实的对话编进字幕。缺漏包括完整原始报价与需要节省数额、预算当场纠错的完整上下文、原型/厚度手势对应镜头、评分者离座后的跟踪镜头、白板真实评分动作的近景核验、实测的颜色欢迎度疑虑、量产设想/被否决外形细节、创意词义误会的充分交接、领导观点完整交锋、团队评价让步、会外交流限制、限时益处及例外、以及会议结尾白板/触觉复盘的完整搜索与核查。当前作品不应被当作这些事项均已覆盖的版本。现有片名、中文编辑注释与少量信息字幕只概括所选片段，不是逐句翻译。

成片中的成本句保留为讨论性估算；由于当前入选段落未包含原始报价和预算纠错，不能推导最终精确金额。白板字符未从低清画面进行臆读。量表字幕采取原声中“0最高”纠错口径；评分数值只作为口头评论，不是外部实测结果。设计仍属AMI情境模拟，不是企业发布、量产承诺或性能测试。

## 教程方法应用
查看了 Blackmagic Design 官方 Fairlight Working with Audio Track Layers 教程的实际画面（约20秒处可见多层轨道与片段；约80秒处显示分离的声音/画面层）。可迁移的方法是把对白与画面保留在可独立编辑的轨道，并按段落管理，而不是烘焙为单一整片。本工程保留A1官方混合轨及V1多机位片段、V2 Text+，便于日后替换某段音画而不改写其他轨。不同耳麦不是同一表演的可随意替换take，因此未把单轨互相拼成假连续对白。

## 声音 / 技术
使用官方单声道混合轨 `media/audio/ES2002d.Mix-Headset.wav`，不另行降噪。音画区间对应源时间一致，没有J/L cut；画面源区间按25fps帧边界映射。渲染工具测得视频与PCM混音约 -21.99 LUFS、真峰值 +0.03 dBTP（目标为 -18±2 LUFS、≤-1 dBTP），因此响度/峰值**未达规格**；没有外部压限器或隐藏音频加工可用。目标响度与峰值的冲突未解决，听感未通过逐句试听验证。源素材低清352×288，标题和中文字卡属编辑叠加，未声称恢复细节。

## 时间准确性
八段音画使用同一源起点、帧数与输出起点，在工程剪辑级别无人为音画偏移；兼容MP4清单记录相同时间原点。原片多路尾部时长略有差异；本次只使用早期区间。评测所需的原型、白板、领导同期镜头尚未完整制作与逐帧核对，不能声称已完成跨机位偏差验证。

## 身份映射
`speaker_map.json`中的S1–S4是暂定编辑代号，不是自动声纹分离。摄像机清晰度不足，除房间总体和有人离座至白板区域等观察外，未依据可疑口型把人物、麦克风和评价者强行对应。
