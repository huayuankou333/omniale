# 遥控器，如何定案？——AMI ES2002d 中文信息简报

## 交付
- `final.mp4`：356.48秒（5分56.48秒），1280×720，25fps，H.264／AAC 48kHz。从本地 Resolve 原生时间线导出。
- `project.drp`：DaVinci Resolve **21.1.2.10 免费版**原生工程。时间线 `ES2002d_中文简报`，起始00:00:00:00；不是导入烘焙整片伪装工程。
- `mix.wav`：同长48kHz、24-bit、stereo PCM。最终实测 **-19.97 LUFS，-1.07 dBTP，LRA 8.20 LU**。成片AAC实测 **-19.98 LUFS，-1.09 dBTP**。在-18±2 LUFS与≤-1 dBTP容差内，靠近响度下限；优先保留自然语音而非过度处理。
- `edit_map.json`：视频、音频逐片段独立映射；关键图卡按连续语义区间记录。工程内文字机械拆为≤5秒Text+片段，视觉连续。时间区间均左闭右开、秒单位。
- `claims.json`：成片主张及状态、源证据。
- `speaker_map.json`：四人稳定身份与耳麦、机位和离座追踪。

`.native-renders/`是工具实际导出的PCM中间容器，不是剪辑输入。正式审阅使用上述根目录文件。

## 重开与重链接
1. 在 Resolve Project Manager 中 Import Project，选择 `project.drp`。
2. 打开时间线 `ES2002d_中文简报`。媒体离线时在Media Pool选素材，使用Relink Selected Clips，指向题包的 `media/resolve/` 与 `media/audio/`；也可Change Source Folder，将原工程路径中的input根替换为当前public根。
3. 使用五个ES2002d机位的兼容MP4及官方Mix和耳麦WAV；文件名不变。不要用不同起点的重新裁切文件替代。manifest说明兼容MP4仅转码，保持25fps与时间原点。
4. V1为39个同期实拍片段，V2为中文关键字幕/片头片尾，V3为章节及状态注释；文字均原生Text+，可在Inspector编辑。A1为主要对话（官方混音及局部耳麦），A2为领导争议交接的实际重叠声音；两者都是显式stereo音轨。
5. 不需要最终MP4或mix.wav作为工程剪辑输入。保持1倍速，完整导出0至8912帧（末帧不含），即可复现长度。

## 编辑方法与主要取舍
- 以“计划→原型→成本删改→使用性→评价→方法复盘”为主线；仅在82–90秒回看此前的按键估价依据，屏幕明确标记回看。其余选段保持源会议大体先后。
- 保留英文原声；中文是关键字幕与必要压缩，不是全字逐字转写。无生成语音、无对白补写、无音乐、无合成会议画面或超分恢复。
- 片头注明研究项目情境会议；公司色、设计目标、预算都是该情境中的讨论，不是实际企业产品发布。没有把团队自评换算成实测性能。
- 原始计划无LCD；原型因翻盖内藏键成本而提LCD；最终又删LCD、高级芯片改普通芯片，电视负责显示反馈。动能供电取消，只用电池。
- 不把单曲面备选、后续立体形态／系列色系建议写成批准方案。按钮12个功能与按4个估价分开；数字键盘特殊色与整体黄色分开；0.5余额与最终成本分开。不杜撰精确终价。
- 量表1为达成度高、7低。保留纠正方向的原声、风格2.5、创新3、软弹5，以及黄色未必受欢迎的疑虑。
- 领导争议保留“不是坏领导”的限定，以及“控制不是合适词”的否定和共识决策理由。发言人1接受“结构化”表述，但未声称所有约束批评得到充分解决。会外交流限制和团队尽力的让步并置；限时好处与概念设计多15分钟的例外并置。
- 会议第一次在约2220秒开始收尾；继续检查到音频2624.16秒，并抽查视频至2686秒。保留2294.2–2309.92秒的橡皮泥、触觉和创意生成反思，没有在第一次收尾处停止。更晚尾段ASR重复“Thanks for watching”置信度极低，不作为会议事实引用。视频尾部仍有人操作设备，音频长度与视频不一，不能据尾长推断漂移。

## Fairlight官方教程的迁移
先观察了 `tutorial/DaVinci-Resolve-17-Fairlight-WorkingwithAudioTrackLayers.mp4` 的0–240秒自动转写和138、213秒实际画面。教程区分“隐藏音轨”与“静音”，并演示用音轨层选择不同录音take。这里四耳麦是同一次会议的同时录音，不是可互换表演take，不能像配音comp那样拼词重造一句话。
实际落实：成片286.88–291.08秒将Headset-1主持者放A1、Headset-2发言人1放A2，同源1730.2–1734.4秒同时播放，保留真实交叠；不叠加官方混音，以免同一声音重复。Headset-0该窗1731秒有很强瞬态但此人尚未开始反驳，改用正在发言的两麦。反驳1734.4秒起恢复混音，保留否定词与插话。导出采用实际clip-enabled门控并恢复状态，而非把隐藏等同静音。其余主要使用官方Mix，轻声评价局部换耳麦，所有切口用2帧短淡化，没有重度降噪。

## 核查与局限
- 全部音频分九窗检索；关键量表、领导否定与预算纠错另查单麦。观察工具是离线faster-whisper base.en，可能漏词或幻觉；本轮没有原始音频直接聆听接口，不声称已亲耳审核。关键翻译以多窗、多轨相互支持及上下文为依据。
- 实际解码审看了成片2、9、24、58、80、122、136、161、180、242、294、354秒等帧，中文字清晰、不覆盖嘴部，源比例保留。最后一轮只改音量，未变画面或字幕。
- 源画面352×288，机位固定；桌面模型与白板小字不可详辨。保留留边，无生成细节。原型画面不如现场面部镜头清楚，这是当前剪辑的可见性局限。
- 来源映射中的title记录关键图卡的语义区间而非每个机械拆分文字片段；实际逐句时机和可编辑文字以DRP为准。claims记录用于核对的上下文可长于入片选段。
- 主要内容为压缩简报而非完整会议存档：省略设备软件细节、部分重复讨论和闲谈。不声称所有批评都获得回应。
