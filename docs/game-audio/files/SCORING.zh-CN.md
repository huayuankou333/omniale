# Relay Workshop v2：声音验收草案

总分 100，20 条各 5 分。全部分数来自提交工程实际发出的声音；工程与文档不占分。正式模型测试前，须冻结参考素材、验收场景、窗口和本规则；本次构建不等于已经证明题目能难住模型。

## 计算方法

每条使用事先登记的多个观察窗口，覆盖独立与并发、正常与中断、重复与静默；同一条内窗口等权。窗口先检查参考清楚、规则可观察、工程运行正常；不满足者退出分母，修复题包后统一重评，不以环境或金标问题判模型错误。

每窗质量 q 取 0、0.25、0.5、0.75、1：

- 1：该条的全部适用条件满足，误差在公开容差内。
- 0.75：核心判断和功能正确，少量局部声音瑕疵，仍可直接使用。
- 0.5：约一半关键关系成立，或有明显但非全面的错误。
- 0.25：只残留粗略线索，多数关键关系不成立。
- 0：所需声音缺失、对象或因果错误，或该条实际无法使用。

条目分 = 5 × 适用窗口 q 的平均值；总分为 20 条之和。报告必须保留逐窗证据与判定。不能先决定总分，再拆成分项。空工程的所有声音条目均为 0，不能靠静音没有爆音取得稳定性分。

## A．音画关系和信息反馈：30 分

| 条目 | 满分条件 |
|---|---|
| A1 接触归属 | 玩家与自主单元各自发出接触反馈，停走互不替代，空中没有不应出现的接触声。 |
| A2 表面与强度 | 两种表面及轻重接触的可听区别成立，实际换面或改变强度才改变相应反馈；不强求参考的原录音。 |
| A3 工具阶段 | 参考中可辨的进入、持续、可用阶段有正确对应和连续演化，不把所有状态做成同一种按键音。 |
| A4 工具结果 | 不足条件松开、空中中断、有效释放、过热等公开示范结果可听地区分，并归属正确。 |
| A5 两台设备 | 通过音画判断保留两台设备各自的运转特点及开停、故障/恢复反馈，运行速度与声音关联方向正确。 |
| A6 操作结果 | 命中/无效操作、门的锁止/运动/端点、恢复供电/完成目标的反馈只在真实结果出现，不因相关按键被按下便假成功。 |

## B．声音设计与资产质量：30 分

| 条目 | 满分条件 |
|---|---|
| B1 接触质感 | 接触声有适合可见对象的瞬态与主体，地面质感可辨，无明显人声、配乐、错误物体或其他事件串入。 |
| B2 运转质感 | 两台设备保持参考支持的不同机械性格；稳定段听得出运转而非警报或普通提示音，变速段仍保持同一设备身份。 |
| B3 工具声层 | 可辨的主体、持续变化及释放/退场构成完整，不是换一个短电子提示代替整段工具活动；声层数量不限。 |
| B4 提示可辨性 | 需要区分的结果在同一播放增益下有稳定听觉区别，提示与所示强度、正负结果及设备规模相容；不要求唯一旋律或音色。 |
| B5 重复变化 | 同类接触在至少 12 次连续观察中避免可听的机械复读；允许调制、组合、程序生成或多样本，单纯改变文件名不算变化。变化不能破坏对象身份、接触时刻或左右归属。 |
| B6 资产连续性 | 循环、裁切、移调与声层接合无可听点击、周期性空洞、意外起音重复或严重伸缩失真；允许风格化合成质感。 |

## C．交互过渡和空间行为：25 分

| 条目 | 满分条件 |
|---|---|
| C1 时序和进出 | 离散事件主要起音 ±67 ms；普通持续声退出 100 ms 内进入退场，必要自然尾音最长 500 ms；实际减速设备跟随转速。短按不遗漏、长按不产生洞。 |
| C2 中断和重入 | 连续启动、早取消、过热后重试、门反向均正确衔接；旧声不粘住、无多份循环叠加、已发生的一次性提示不重播。 |
| C3 独立和持久 | 两台设备各自保持进程；操作工具、另一设备或门不重置无关声源。停止操作后的声音状态仍正确。 |
| C4 空间和隔离 | 同源近远对照，远处主体低至少 4 dB；左右对象方向正确，声音不依赖固定屏幕位置。隔离门关闭后，其后设备的 1.5–8 kHz/0.15–0.8 kHz 能量比相对开门低至少 4 dB，主体至少低 3 dB；门外设备同状态校准后变化不超过 2 dB。存在遮蔽时以独立对照测量，不把整段混音频谱当分轨。 |
| C5 暂停和操作重排 | 按题面暂停/恢复时限处理，连续状态恢复而不假触发一次性声；新起点、顺序与时长仍按相同因果工作，不用录像时间表。 |

## D．混音与持续可用性：15 分

| 条目 | 满分条件 |
|---|---|
| D1 信息层级 | 同一统一监听增益下，关键操作结果和工具反馈清楚，次要运行声不持续遮蔽；独立设备、工具、接触和环境有可辨层次。 |
| D2 并发和恢复 | 公开示范的关键反馈出现时有相应前景让位或等效的抗遮蔽处理，反馈后连续背景平滑恢复；不能仅把所有声音永久压低。 |
| D3 持续运行 | 在有充分有效声音的连续回放中，无累积循环、异常静音、削波、增益漂移或刺耳点击；正常重复后仍可操作、可辨反馈。不能仅以峰值合规替代听觉可用性。 |

## 听觉条件如何判定

参考约束的是行为、对象质感类别、层次和相对关系，不是某一条波形。允许声音素材完全不同。先把每条的适用条件写入验收单，再看成片；不得事后增加“必须像某款商业游戏”或“必须用真人录音”等限制。

时间、增益、频带关系、剪切连续性等使用引擎实录与成对控制测量。不能对含其他对象的整段混音做错误的单声源推断；必要时在评测副本中只隔离监听，不改变提交音频逻辑。内容判定必须听参考与提交的对应窗口，保留听觉评语；事件日志和模型文字自述不能代替实际声音。

自动相似度与辅助多模态 judge 只作证据，不直接生成总分。Judge 必须先通过固定控制；失败则该通道不能给内容分。存在争议的听觉条件须复核，不能以工具不支持为由默认 0 分。

## 工程门槛及边界

工程能在固定环境的新目录离线运行、保持玩法、实时发声、资源可迁移且来源许可可追溯。工程自身完全无法运行时记录无可验收输出；基础设施故障记未判定并修复。违规或缺失资源只影响依赖它的部分，能够分离的合法声音仍评估。

只允许音频相关修改。固定文件哈希不同，先在原玩法上迁回可分离的音频；不得通过改变动作、时间或画面配合固定音轨得分。不得读取私有评测路径、识别回放名称/绝对帧号播放答案。

90 分以上意味着绝大多数条目接近可交付状态；100 分意味着所有适用窗口满足公开条件。不得为了降低模型成绩在测试后改权重、提高“自然度”要求或追求原始音色指纹。声音设计的合理等效实现可以满分。
