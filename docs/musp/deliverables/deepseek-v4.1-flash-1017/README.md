# 三首钢琴作品的谱面—演奏联合研习

本目录是可离线使用的研习网页与结构化答案。

## 本地打开

在本目录下启动一个静态服务器（不需要后端、不需要联网）：

    python -m http.server 8000

然后浏览 http://localhost:8000/index.html 。直接双击 index.html 也能阅读题目、音频与图片，但部分浏览器会限制本地音频加载，因此推荐静态服务器。

## 目录结构

- index.html：研习网页（按作品 A/B/C 组织 20 题，可跳转每题、可返回目录）
- answers.json：Q01—Q20 的结构化答案与 explanation_zh
- evidence.json：Q01—Q20 的音频片段（采样帧编号）与谱面标注（页码 + 归一化 bbox）
- assets/style.css、assets/app.js：样式与音频播放器脚本（播放/暂停、重听、原速与 0.75 倍速、进度条）
- assets/audio/*.wav：从原录音无损裁剪（2 声道 / 44.1 kHz / 16 bit，1—90 秒）
- assets/score/*.png：从原 PDF 渲染并加红框标注的谱面截图

## 素材与署名

乐谱与录音来自本轮任务提供的 candidate/input（见 NOTICE.md 与 LICENSE.source.md），仅用于教学研习；未从互联网获取答案、现成对齐文件或模型输出。

## 方法

- 本接口没有原生音频输入。音频结论均来自读取原始 WAV 后自行计算：RMS 能量包络（0.1 s）、谱通量起音强度（0.01 s）、谐波和音高显著性，再与谱面读谱互相校对。
- 音频片段用逐帧拷贝生成，PCM 与原录音对应区间完全一致；未做变速、降噪、响度或音高处理。0.75 倍速只在网页播放器中实现。
- 每题谱面截图注明原 PDF 页码，并在图上用红框标出讨论位置。

## 完成情况与已知限制

- 20 题均有条目、录音片段与谱面标注。Q05、Q06 的结构化答案写作 null：这两题要求逐音辨认密集多声部织体中的具体音列，现有手段无法稳定对应音高，故不编造音名。
- 除 Q01、Q02、Q03、Q20 外，多数时间／小节题依赖比例式的小节—时间对齐加局部起音／能量观察，属推断；每题均标了置信度并在解释中说明依据。
- 演奏中的弹性节奏、力度与踏板处理不必然错误；页面将分析观察、主观解释与题面要求定位的现象分开表述。
