# 从谱面到演奏：三首钢琴作品联合研习

## 打开方法

推荐用任意本地静态文件服务器，将 `submission/` 作为站点根目录，在浏览器打开 `index.html`。例如电脑已装 Python 时，可在本目录运行：

```text
python -m http.server 8000
```

再访问 `http://localhost:8000/`。这只是静态文件服务，不是应用后端；无需联网、登录、额外下载资源或插件。页面不使用 fetch、CDN 或在线字体，也可直接双击 `index.html`（浏览器若限制本地媒体，请改用静态服务器）。研习本身不需要安装Python。

## 使用

- 顶部作品导航、作品内题号导航和桌面逐题目录均可跳转。每题底部可返回本作品或三部作品总目录。
- 每段原音均有浏览器原生播放／暂停、进度条；“重头听”重新从该证据片段起点播放。
- 勾选“循环”可反复回听，速度可切换原速／0.75倍速。播放新片段会暂停其他片段，避免声音叠加。速度只改变播放器行为，不改变WAV。
- 时间标签为原录音绝对时间，播放时下方原录音时钟随进度更新；片段边界的准确值见 evidence.json 的采样帧编号。
- 谱例红框标示讨论位置，并标注原PDF页码。手机谱图可在图框中横向滑动；点击谱例或按回车可在弹窗按原尺寸放大。可按Esc或“关闭”退出。
- “标记已研习”仅保存在本机localStorage，不能当作作答正确性的判断。

## 文件结构

- `index.html`：静态中文研习网页，20题题文、答案与说明。
- `answers.json`：保留原case_id、Q01—Q20与对应作品；简答字段为字符串或null。
- `evidence.json`：23段原音和23处标注谱面区域的逐题索引。所有路径相对本目录。
- `assets/Qxx_n.wav`：原WAV的连续无损PCM裁剪。均为44,100Hz、双声道、16-bit PCM；未变速、降噪、响度处理或移调。
- `assets/Qxx_score_n.png`：原PDF局部渲染后加框。图头中Q号与原PDF页码便于核对。
- `assets/style.css`、`assets/app.js`：本地响应式样式及交互。
- `NOTICE.md`、`LICENSE.source.md`：来源和许可说明。

## 分析边界与未完成部分

本接口无原生音频输入，未声称直接听到了演奏。演奏层面的答案采用原始音频的短时频谱、起音间隔、能量变化及声部候选，与谱面视觉相互核对。谱峰含谐波，能量不等于琴键力度、RMS不等于速度；踏板动作是从衰减／截断形态推断，未直接测量踏板传感器。学习者应利用所附原音亲自回听核查。

全部20题均已建立答案、说明和音频证据条目；Q10的简答仍为null：当前末尾匀速外推出现与题设“延后”相反的方向，未能可靠解决其非负整数判定。已保留所用时刻、计算疑问、完整尾声片段与谱例，不把绝对差值强行充当答案。其余19题给出明确简答，但演奏力度、弹性节奏与隐含声部的识别仍属于分析判断，并非权威参考答案。Q05的终界F#包含在音符列表中；Q06用B3表示谱写Cb4的实际音高，解释中保留原拼写。

页面的答案与解释由已保存的JSON直接生成，Q10在两处都保持未定。Q16同时提供主题初现与后期变奏的音频、谱例；Q20同时提供飞升构思初现与结尾回收的独立证据。

## 来源、署名与许可

素材、原始问题与适用改编来自MuSP-Bench：Milan Liessens Dujardin、Song-Ze Yu、Kevin Miao，2026；论文《MuSP-Bench: Advanced Multimodal Benchmarking of Music Understanding Across Score and Performance》，arXiv:2608.28212；数据集bryel-labs/MuSP-Bench。三份钢琴录音在原数据中归属ASAP来源。

## 交付自检记录

- 20题题号与case_id覆盖检查通过；此检查不评价音乐内容。
- 23段音频逐帧PCM与原录音指定区间相等，声道、采样率、位深和帧数核验通过。
- 所有要求的音频／谱例数量覆盖通过；网页答案与解释和JSON逐项核对一致。
- 真实Chromium以本地静态服务器加载：1280px与390px两种宽度，无整页横向溢出，无脚本错误，无缺失资源、无外网请求；23段音频的播放、暂停、倍速媒体API检查通过。
- 循环、重头播放与单片段独占播放由本地脚本实现；默认不勾选循环。
