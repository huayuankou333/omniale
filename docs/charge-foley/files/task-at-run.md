# 电影声音后期委托：Charge 工厂段落

你是一名电影声音后期 agent。请为 `input/picture_v1.mp4` 的完整 90 秒画面设计并制作声音。你可以自主在线寻找真实录音，裁切、重组、变调、变速、叠加、均衡、动态处理、混响与自动化，创造可信的动作声音和科幻机械声音。

请先观看画面，自行判断事件、发声主体、接触时刻和声音层次。人物、机械装置、机器人、手持物与工厂环境应有可区分且前后一致的声音身份。重点包括取电池与机械抓取、机器人和武器动作、投掷物及喷溅、设备损坏、电弧、近身接触、身体落下和撤离。你不需要模仿原电影的音色，也不需要给每个细微运动强行配音。

## 创作要求

1. 主要动作应有合理的声源、材质、力度和持续过程，不能用一种撞击声覆盖所有不同事件。允许使用替代材料或组合声音，只要成片效果与画面相容。
2. 接触类声音的可闻起音应贴合可见接触，而非仅把一段包含静音的录音文件起点放在动作附近。重复发射、机械运动、摩擦和电弧要具有相应节奏、起止与状态变化。
3. 维持可识别的角色和物体声音身份；根据镜头距离和可见空间组织声像、远近及环境尾音。没有明确空间证据时允许合理的电影化处理。
4. 环境、动作与特殊效果应有层次；不能用持续的宽频噪声掩盖缺失的拟音。允许克制处理小动作。不要加入对白、旁白或配乐；非语言的呼吸、用力声可自行决定，不是必做项。
5. 画面保持给定的帧序、速度、分辨率和时长，不添加字幕、片头、标识或额外画面。

## 在线素材与软件

- 不提供固定音效答案库。通过评测宿主提供的在线检索入口，自主查询、试听和下载真实录音。本轮通过 Openverse 实时索引检索 Freesound 的 CC0/CC BY 录音；两候选使用相同入口与查询缓存，不提供预选音效清单。下载使用公开预览编码，明确保存实际格式；解码为 WAV 不表示获得原始无损质量。
- 使用明确标注为 CC0 或 CC BY 的素材；记录原页面、作者、许可版本、下载时间、原文件哈希以及实际使用区间。预览可用于试听；正式使用预览文件时必须如实记录其格式与质量，不能宣称为原始无损文件。
- 可以跨类别寻找声音并充分加工；不要求最低音效数量、最低轨道数量或最低效果器数量。不得提取本片原音轨、使用本片现成拟音或成片配音包，也不得用其他 agent 的答案。所有可听素材应能追溯到真实开放录音；本题不开放生成式音频模型。
- 在真实 REAPER 中完成编辑、自动化与混音；在真实 Shotcut/MLT 中完成分轨回填、音画检查及视频导出。允许 GUI、脚本、CLI 或已验收的桥接 API。Python/FFmpeg 可用于素材分析、转码与检查，不能替代两款指定软件完成它们承担的交付环节。
- 桥接工具只执行明确操作；素材选择、剪辑时刻、处理参数、声音层次与返修决策由你决定。自行审听素材和输出，不能只依赖文件名或波形推断听感。

## 交付规范

画面：1920×804、24 fps、90.000 秒、2160 帧，H.264 MP4。声音：48 kHz stereo；混音和分轨为 24-bit PCM WAV。全片混音目标为 -20 LUFS，容差 ±2 LU，最大 true peak 不高于 -1 dBTP。这是本题的网络审片交付规范，不是“好莱坞统一标准”。

请交付以下内容，媒体引用采用交付包内的相对路径：

```text
v1/
  final.mp4
  mix.wav
  reaper/session.rpp
  shotcut/project.mlt
  stems/AMB.wav
  stems/FOLEY_HUMAN.wav
  stems/FOLEY_PROPS.wav
  stems/MECH.wav
  stems/SFX.wav
  media/...
  cue_sheet.json
  asset_manifest.json
  processing_manifest.json
```

`AMB` 为持续的工厂/空间环境；人物身体与衣料放入 `FOLEY_HUMAN`，物件接触放入 `FOLEY_PROPS`，机械运动放入 `MECH`，发射、电弧等特效放入 `SFX`。这些是交付总线；内部可以自由细分。跨类别的复合声音可放入最合适的总线，并在记录中解释。不允许通过给空轨命名来代替相应声音。

交付五条带完整处理的分轨，线性相加应能重建 `mix.wav`。如果使用总线非线性处理或共享效果，须以可验证方式打印并分配到这些分轨，使总和仍能重建混音；不要叠加一条完整 Mix 导致重复混音。最终 MP4 音轨应来自这份混音。

`cue_sheet.json` 记录你自己识别的声音事件、画面时间、素材片段、处理和轨道位置。`asset_manifest.json` 记录源文件和许可。`processing_manifest.json` 记录素材到工程、分轨和成片的对应关系。模板位于 `templates/`，它们只定义字段，不提供答案。

## 两阶段制作

完成首版后调用提交入口。宿主会保存首版文件、哈希及真实操作日志，随后发放一份所有候选相同的固定返修委托。请保留首版，在 `v2/` 完成新版工程、混音、分轨与成片，并提交 `revision_report.json`。返修内容不会由另一个模型临时生成。

本题按交付与过程质量 15 分、拟音内容 40 分、音画同步 25 分、混音与声音质量 20 分评分。声音内容允许多种合理答案；不按与原电影音轨的波形相似度计分。过程项不奖励搜索数量或复杂效果器数量。

建议冻结的统一预算：首阶段 120 分钟、返修 45 分钟；总计不超过 500 次工具操作、60 次在线搜索、100 个素材下载、2 GB 下载量。服务故障和宿主启动等待单独记账；超时处理和恢复规则在所有候选之间相同。正式计分前，宿主必须先验收候选听觉输入、检索和两款软件的操作能力。
