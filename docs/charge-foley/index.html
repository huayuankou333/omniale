一、题目要求：从观察到可编辑交付

Agent 扮演电影声音后期制作者。先从画面识别谁在动作、什么物体发生接触、机械处于什么状态，再自主选择和加工开放录音。主要动作须有合理的材质、力度与起止，人物、机器人、电池、道具和厂房环境应能区分。

01 · 看与听

观察动作与空间；在线查询、试听真实录音。

02 · REAPER

裁切、组合、变调、自动化、混音，导出五条分轨。

03 · Shotcut

回填分轨、检查音画、保存 MLT 并原生导出。

04 · 固定返修

按分段时间映射迁移声音，只降低环境总线。

跨软件具体体现在哪里？

本题在同一 Windows 环境中跨越 REAPER 和 Shotcut 两款专业软件。在线检索用于获取声音；REAPER 负责声音制作，Shotcut 负责将声音与画面组合并交付视频。两款软件承担不同工作，并通过五条分轨交换结果。

环节Agent 必须完成的操作可核查交付
REAPER · 声音制作把下载录音裁切、叠加、变调、处理和混音，建立事件时间线及五个声音总线。可编辑的 session.rpp、五条 48 kHz / 24-bit WAV 分轨及 mix.wav。
Shotcut / MLT · 音画交接加载指定画面和 REAPER 分轨，保持共同时间基准，检查音画对应并由原生 MLT 渲染链导出。可编辑的 project.mlt 与 final.mp4；检查媒体引用、画面帧序和实际导出。
固定返修 · 两边同步更新收到删镜与环境降音要求后，迁移 REAPER 的声音，再更新 Shotcut 交接、重新导出第二版。两套软件的首版与返修工程、混音、分轨、成片及变更记录；同时检查未要求修改的声音是否保留。

允许脚本、CLI 和桥接 API，不要求 GUI 点击，也不要求跨操作系统。工程项以软件实际加载、原生导出和异路径重放证据核验；声音内容与同步仍根据成片判断。

拟音素材由谁提供？Agent 能自由发挥什么？

题目不提供固定音效库、预选录音清单或逐事件声音答案。提供的是无声电影片段、制作要求、交付模板，以及首版封存后才发放的固定返修包。

Agent 在允许的工具和预算内自行决定查询词、试听和下载哪些录音。本轮通过 Openverse 实时索引检索 Freesound 的 CC0 / CC BY 开放录音，并保存来源、许可和加工记录；使用的下载是预览编码，未冒充原始无损文件。

  • 可自主设计：用哪些声音表现机械臂、脚步、道具与环境，如何叠加、裁切、变速、变调、EQ、动态、混响和自动化，以及事件时刻、声级和空间关系。
  • 明确边界：不使用原电影音轨、现成拟音包、其他候选答案或生成式音频；画面帧序、速度和长度保持给定规范，不添加对白、配乐、字幕或额外画面。
  • 按效果评价：合理创意音色允许多种答案；不按与原声的波形或音色相似度、不按搜索量、轨道数或效果器数量奖励。

必须交付

final.mp4、mix.wav、REAPER session.rpp、Shotcut project.mlt，以及来源、cue 与处理记录。

五条处理后分轨：AMB、FOLEY_HUMAN、FOLEY_PROPS、MECH、SFX；线性相加应重建混音。

1920×804 · 24 fps · H.264；48 kHz stereo、24-bit PCM WAV。首版 −20±2 LUFS，两版 true peak ≤−1 dBTP。工程采用包内相对媒体引用。

这是本题的审片规格，不宣称是通用电影行业标准。

固定返修单：为什么不能只改最终视频？

首版封存后才释放同一份返修输入。删除首版 [4,5) 秒及 [66,67) 秒，得到 88 秒新版。对应声音须分段迁移、裁除删除区间并处理剪口。

AMB 环境降低 4.0±0.5 dB；四个前景总线保持原声级和音色，只允许剪口前后250 ms及首尾100 ms的必要衔接。需要更新两款软件工程、分轨、混音、成片及返修报告。

这同时检验时间映射、局部修改与非目标保护。返修限定范围内的错误仍会保留，不能把第二阶段视作任意重做首版。

二、输入素材与 Omni 考点

跨模态难点

声源归属：区分机器人、人物机械手、厂房设备和被击中的道具；同一金属声并不能解释所有接触。

动作演变：机械运动、受力、停止，喷罐击穿后的压力释放，电弧的持续状态。

细粒度时序：四次发射与闪光的节奏，接触起音，连续动作的起止，返修后的非统一位移。

听觉取证：既要看到动作，也要确认成片真的有对应声音；波形有能量或工程有音频条目，都不足以证明拟音正确。

原片带声音版本 · 仅供观众试听对照

以下保留《Charge》的官方电影混音，便于听到原片如何表现机械臂、接触、发射与厂房环境。它包含电影的完整声音设计与配乐，不是纯拟音分轨，也不是要求 agent 逐声复制的标准答案；受测 agent 未获得这些原声音视频。

如何比较？

可将首版原声与模型的90秒首版对照，或切换88秒版本与返修成片对照，重点核查事件是否有声、声源是否合理、起止和节奏是否贴合画面。

88秒版仅按返修画面的删镜同步裁剪原混音。原混音无法独立拆出 AMB 环境总线，因此没有模拟“环境降低4 dB”；它不是导演返修完成版的金标准。

原声试听不改变当前评分；合理的新声音设计不因音色不同于原片而扣分。

四、最新评测协议

这是OmniALE原创改编，参考真实软件交付、内容/时序/混音拆分及非目标保护的评测思想，非相关论文的官方题目或成绩。对已见交付开展开发集复核，尚不能视为独立冻结测试集结论。

维度配分判定与汇总
内容5050个动作/声音组件，每版q∈{0,.25,.5,.75,1}；每项0.3×首版q+0.7×返修q。
同步3020项×1.5；每项两版均满足全部条件才得1.5，否则0。接触/起止采用预定2帧容差（24fps下约83.3ms）；四发须逐一对应，持续事件检查起止与覆盖。
混音205项×4：PCM技术质量、剪接伪影、前景层次、音色空间连续性、返修降音及前景保护。技术和返修项复用同一交付的已核实事实。
工程门槛不加分。失败时限制总分；多个失败取最低上限。基础设施证据缺失先待评，不自动扣模型分。

五档内容标准

0：缺失、主要声源错误或仅背景。
0.25：有微弱相关提示，主要动作/材质不可信。
0.5：主要动作正确，但缺必需阶段或材质组件。
0.75：主要阶段齐全，仅次要细节不足。
1：指定组件均可闻，声源、材质和体量可信。

允许合理的科幻音色设计，不要求复制原片。缺失内容不在混音维度重复扣分。

总分和复核范围

总分 = min(内容＋同步＋混音，失败门槛最低上限)

公式的二元判定可以重现，音频模型给出的时间点仍可能不准。固定内容/混音自动分，仅把尚未验证的同步视为0–30分时，范围为：Luna26.77–56.77、Sol49.10–79.10、DeepSeek35.93–65.93。

七、优先复核的问题与结论边界

工程成立不等于拟音成立。三份交付均有可编辑的REAPER/Shotcut工程与原生重放证据。内容、同步和混音需要针对成片听觉另行判断。全片导出时钟一致，也不能证明每一个动作声已贴合画面。

可直接确认的返修问题包括：Luna的前景自动化包络变化与其“保持原包络”报告不一致；DeepSeek部分保留脚步只迁移1秒，而对应段要求迁移2秒。其余下方感知理由属于Qwen提出的复核线索，不作为人工已听证实的结论。
