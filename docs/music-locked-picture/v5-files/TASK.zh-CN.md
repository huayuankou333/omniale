# 画面版本变更后的配乐工程重建与短版适配

你是一名影视音乐剪辑师。画廊动画的画面已经重新剪辑，原有配乐工程丢失。制片方找到了一批未整理的音乐导出：其中有这部片子真正使用过的独立配乐，也有其他项目的音乐。请理解新画面的角色关系、想象与现实、节奏及喜剧转折，从素材库重新设计并制作主版和短版配乐，交付可继续修改的工程和成片。

目标是为**现在的画面**做成立的音乐剪辑。原片配乐的素材身份可以帮助找回作品风格，但旧片的时间顺序与位置不能直接当作新片配乐方案。可以有多种优秀答案，不要求复原某一条原声波形。请让音乐参与叙事，而不仅是覆盖时长；也不需要给每一个动作配重音。

## 输入

- `input/long-lock.mp4`：72秒、1728帧，960×540、24fps，无音轨。
- `input/short-lock.mp4`：24秒、576帧，同技术格式。短版经过独立重剪，跨越主版中的多个画面段落。
- `input/audio-pool/`：160个匿名的48kHz/24bit、立体声PCM WAV。包含独立音乐cue、带余量的重叠乐句、短动机、转接或收束材料，以及其他音乐的候选乐句。并非所有文件都需要使用。
- `input/pool-index.json`：仅有路径、ID、时长、采样参数和SHA256。
- `input/POOL-CREDITS.txt`、`DATA-LICENSES.zh-CN.md`：素材整体署名与许可，允许完整携带该署名。

这里的音乐来自真实发布的独立音乐文件，不是从原片混合声音中分离出来的所谓分轨。库中不提供需要找回的对白、角色发声、动作音效或环境声；也不承诺提供可任意拆分的乐器分轨。不要把本题做成拟音或对白恢复。

不提供原片混音、画面事件时间表、音乐描述标签、旧工程、正确素材清单或示范工程。请自行看画面、试听和判断。所有实际声音均须来自这份素材库；本题离线完成，不得检索原片、下载外部音乐、调用其他模型或生成新音乐。

## 制作要求

1. 两版画面均已锁定：保持帧序、帧数、帧率、时长及画面呈现，不增加字幕、转场、片头或其他视觉元素。
2. 可裁剪、重排、重复乐句、分层、制作音量包络、淡入淡出、均衡、压缩和必要的空间处理。允许保持音高的轻度变速（播放速率0.85–1.15）及不超过±2半音的移调；若采用，请在工程和清单中保留处理并说明音乐理由。不能用倒放、破坏性音质劣化或合成音效代替音乐判断。
3. 保持听得出的主题与配器逻辑。相似风格不等于适合当前画面；需要处理乐句长度、重音、进入、让位、停顿及结尾。没有规定必须使用多少文件或多少剪切点，按听到的效果评价。
4. 短版须按自身画面重新建立起承转合，不能只对主版音频机械裁取一个连续区间。允许复用主题和已完成的剪辑成果；若选择较少剪切，也需实际成立。
5. 配乐是唯一需要制作的声音。成片无需补回说话声、拟音或环境；不要把缺少这些声音当成音乐留白的错误。

## 交付

保存到`/workspace/submission/`：

- `long.mp4`、`short.mp4`：对应锁画加配乐，原始视频帧应保持一致；允许视频流直接复制。音频AAC，立体声。
- `long-music.wav`、`short-music.wav`：48kHz/24bit PCM、立体声，首样本对应首帧；时长误差不超过1帧。与相应MP4使用同一混音。
- `project/long.RPP`、`project/short.RPP`及所有依赖音频：REAPER原生可编辑工程，全部相对引用。保留实际源片段、剪切位置、淡变、包络及处理；迁移到新的离线目录后能打开和重渲染。不得只放一条最终整轨冒充工程。视频封装可用FFmpeg或其他提供的软件。
- `assembly.json`：逐项记录`version`、`pool_id`、`pool_sha256`、`source_in`、`source_out`、`target_start`、`playback_rate`、`pitch_semitones`、`gain_db`、`fade_in`、`fade_out`及其他处理；秒为时间单位。应与实际工程一致，仅作为追溯证据，不按填表给音乐分。
- `edit-notes.md`：简述主要音乐判断、候选取舍、两版的区别和已知不足。建议不超过800中文字。
- `CREDITS.txt`：携带整体署名并说明本次裁剪、重组、混音等改编。

响度目标−16 LUFS（±2 LU），真峰值≤−1 dBTP。音乐仍需保留有意义的强弱、呼吸与空间。

## 预算与评分

服务器Docker中制作及评测，4CPU/8GB；有效工作7200秒；至多140次成功模型调用；总输出131072 tokens，单响应最多8192。原生软件打开、检查和渲染计入工作时间。本题不开放联网工具。

100分全部评价声音成品：音画音乐回应35、音乐结构与剪辑连续性25、素材选择与主题/配器20、短版适配10、混音10。可编辑工程、素材追溯、画面锁定和预算合规是门槛，不送基础分。高分需要可听见的叙事回应、自然的乐句组织及真正适配后的短版；正确文件ID、项目成功打开、技术响度合规，都不能替代这些内容。

完整评分规则见`SCORING.zh-CN.md`。主办方会结合画面和实际声音评价，不以原片波形相似度、自动节拍命中数或剪切点数量直接计算音乐质量。
