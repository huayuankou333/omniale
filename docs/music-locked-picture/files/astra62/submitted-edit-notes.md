# 一颗果子的距离
**The Berry Between Us**　｜　锁画音乐剪辑　｜　故事版 02:08 · 独立短版 00:32

开头，乐队关心的是「谁先吃到」。半空中，问题变成「先接住谁」。我把两种音乐的交接放在羊驼**转眼看小企鹅**时，而不是放在冲出洞口的壮观全景上。

## 两种材料

- **S · Sergio's Magic Dustbin**，Kevin MacLeod。取它不断换配器的同一节奏型：早段脉冲相隔约 0.44 秒，中段收窄到约 0.33 秒，最满处约 0.29 秒。羊驼伸脖子的低声部起句、后段独露的高 D 音、末尾乐队顿奏，都可以从原录音里单独取出。高音起初像一个问号，后来随小企鹅走，最后跟着果子回来。
- **E · Evening**，Kevin MacLeod。取吉他约每 0.48 秒一次的分解音及后来带长线条的乐句。它和 S 一样有清楚的步子，却不催人向前。先在空中露出素的版本；天暗以后才允许旋律舒展开、真正终止。两版均只用这两首录音。

## 故事版 · 128 秒

| 画面时间 | 音乐决定 |
|---|---|
| 0–10 s · 冰上的两次试探 | 第一趟伸嘴只给半句；抬头后只余一个答音，等他再俯下去才续拍。第二批企鹅滑过时乐句紧接向下的短音；摊平后不急着另起一段。 |
| 10–22 s · 迟来的小食客 | 两个分开的音跟最后一只越过羊驼，接一条能走完的轻快乐句。企鹅出了近景，留下的却是一串越来越单薄的下行音；羊驼对着空地舔舌头，句子也吃光了。 |
| 22–37 s · 铁轨 | 先放滚奏的弱起，列车露面时脉冲才站稳。羊驼、列车、浑然不觉的小企鹅三个视点共享同一条进行，不随每个反打重启。33.77 s 跳到同动机升调的齐奏；35.78 s 扑过去就收到一个重和弦，接下来留给观众看他究竟抢救了什么。 |
| 37–49 s · 舌尖与空架子 | 等他坐正，给低音一句；隔轨的小企鹅以细瘦的下行线回应。抛起果子时单独亮一下高音，再让有和声的句子被截断。企鹅和羊驼相继消失，不用轰响，而用两个分开的、越落越低的音。 |
| 49–58 s · 洞底 | 把乐队末和弦降沉，留短混响；醒来时只有几枚稀疏的乐音。果串露出才有高音。两位同时倾身，复用方才「快吃到了」的和声句，却让结尾接到矿车踏空。 |
| 58–72 s · 矿车 | 从原曲较快、较厚的变奏中段起跑。外景稍收，横梁处在进行之上补一记顿奏；近景到出口用原曲的蓄势音型再换一次档。不是给每根梁配响声。冲出后让齐奏突然让位。 |
| 72–90 s · 选择与着陆 | 先让伴奏逐层退去，伸向果子时还在 S 里。77.54 s 改用 E 的吉他开句，给两双眼睛连续的七秒多，不去数翻身。下决心后停住；极远景只剩小小的高音。雪地翻滚用 S 本身的三击收束，最后一击到摊开、露出小企鹅处。 |
| 90–111 s · 以为再见 | 小企鹅脱身带走高音。93.78 s 从 E 较暗的小调低音进入；羊驼落单、天色变暗仍在同一句，直至属和声悬住。109.58 s 一点红色飞来，把原先的问号还给他。 |
| 111–128 s · 回礼 | 礼物揭晓时让属和声落定。族群出现不再引回「抢食」节拍；在羊驼的反应处接入同一首的尾句，共享果子时仅轻点高音。留原曲实际的终止和衰减给远景与灯塔，不在末帧硬切。 |

## 短版 · 32 秒

短锁画对应长版约 **64–96 s**。没有从长版总线裁音。这里的结局不是「朋友还会回来」，而是「被救的小家伙已经跑远了」。

1. **0–8.31 s**：第一帧附近单列低音起句，再接较薄的行进段。横梁用三枚间距重新安排的乐队尾音打断，乘客的表情用弱音回答；看见洞口才把卷奏推到齐奏。
2. **8.31–23.46 s**：余速消失，保留两版共有的下行轮廓。13.52 s 开始直接使用 E **已有旋律**的段落，而非长版的吉他初句；让它经过对视、决定，一直撑到雪地。短版不用另起长版的远景问号和三击翻滚句。
3. **23.46–32 s**：一击接住，企鹅探出头后，**开头的低音句回来走完整个离场**。画面切远景时仍有几拍自己的步子，30.94 s 才落句：把低声部 G 的起音降到 C，再把那枚高 D 降到 C 作答。末尾是高低音的余韵，不是还待下一场的抒情引子。

## 混音与回放

- 五条音乐轨按功能分开。大部分的强弱来自所选乐段本身；片段 gain、轨道 volume automation 再让反应或停顿让路。点音保留起音，边缘有短淡变；不在相邻旋律之上硬叠两套鼓。
- 动作轨对低架及约 266 Hz 略收；洞底与悬空轨在约 4.1 kHz 做柔和高架衰减，ReaVerbate 的湿声约 −14.4 dB，湿路限在约 150 Hz–5.6 kHz。抒情轨仅轻修两端。中心保住主体，少数问答略向两侧错开。母线 ReaLimit 留编码余量，没有加拟音、环境、对白或另造音符。
- `project/long.RPP`、`project/short.RPP` 的渲染设置已保存。媒体、参考画面与全部原下载均随工程；无需此处的任何分析脚本。移动整个文件夹后仍能直接渲染。详见 [工程说明](project/README.md)。

## 剪接单 · 工程值

时间单位为秒，区间左闭右开，源时钟从完整 PCM 解码第 0 样本起算；**S/E 并非预剪的素材包**。速度是「源秒 / 目标秒」；除标 `联动` 外均保持原音高再施加所列移调。区间交叠表示叠音或过渡。下表列到毫秒；[cue-sheet.tsv](project/cue-sheet.tsv) 另列逐件的电平、声像、淡入淡出、精确速度。轨道自动化与 FX 留在 RPP。
