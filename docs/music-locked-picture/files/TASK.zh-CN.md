# 锁定画面的配乐重剪与短版适配 · 联网选材版

## 委托

你是受委托的音乐剪辑师。动画宣传片已经完成画面锁定，需要重新配乐。请自行联网寻找有明确可用授权的音乐，选择、重剪、混合，为同一段故事的 80 秒长版和 20 秒短版分别制作配乐，并交付可编辑工程及成片。

长版是故事片段；短版由长版镜头重新编排，是独立宣传短片。两版应有可辨认的共同音乐身份，但短版需要适应新的镜头顺序、转折和结尾。长版宜让情绪逐步发展，短版要在有限时间内建立情绪并形成收束。不要只给每个动作机械打点，也不要让音乐掩盖画面中的情感变化。

## 输入、联网与素材边界

- `input/long-lock.mp4` 和 `input/short-lock.mp4` 是无声且已锁定的画面。不得改动画面内容、帧序、时长、帧率或呈现，不添加字幕、画面效果或转场。
- 本版不提供候选音乐。使用 `web_search`、`web_fetch`、`download_music` 自行搜索、核对授权和下载。它们在服务器 Docker 中执行真实联网请求；制作容器通过这些工具访问互联网。不要在 shell 中绕过联网工具。
- 从公开音乐库或作者站点获取录制音乐。允许 CC0、明确公共领域，或允许改编和再发布的 CC BY 音乐；保留作者、曲名、来源与许可证据。不要使用来历不明、需要登录购买、仅试听但不允许使用、禁止改编或无明确许可的素材。可从任意符合条件的站点选材，不限定作者、曲目数或音乐类型。
- 可以选用一首或多首，自行择段重剪；允许调音量、均衡、渐变、交叉淡化、时间拉伸和调性处理。不得使用原片原声或原片原配乐，不新增音效、对白、旁白，不使用生成音乐或外部助手模型代做判断。
- 不提供故事标记、目标时间点、乐句切分或参考配乐。自行通过画面观察和音乐分析做判断；使用安装的软件制作，工程必须能由 REAPER 打开并重渲染。
- 音乐应覆盖叙事需要；允许有意设计的短暂留白，不能靠大段静音回避制作。音乐是否连续、使用几首或剪几次，本身不决定得分。

## 交付

写入 `/workspace/submission/`：

1. `long.mp4`、`short.mp4`：与对应锁画逐帧一致，包含立体声音乐；无新增或丢失帧。
2. `long-music.wav`、`short-music.wav`：48 kHz、24-bit PCM、立体声；首样本对齐首帧，时长误差不超过一帧。
3. `project/`：至少一个可编辑 REAPER `.RPP` 工程。全部使用的音频置于工程目录内，以相对路径引用；工程搬迁后能离线打开并导出两版 WAV，不依赖工作目录外的临时文件。视频可相对引用包内锁画副本。
4. `edit-notes.md`：说明选曲、主要音乐段落来源、为短版重构的决策和混音处理；记录源文件及源 / 目标时间范围，单位为秒。保留画面和音乐署名。
5. `source-manifest.json`：列出实际使用的每首音乐：作者、曲名、原始页面 URL、下载 URL、许可名称与 URL、许可证据所在页面、工具返回的下载 ID、原文件 SHA256、包内对应文件及解码 / 处理关系。完整下载原文件置于 `project/sources/` 或工程内其他目录，以便核验。不能只提供搜索摘要作为授权依据。

WAV 与对应 MP4 音轨必须为同一混音。响度目标 −16 LUFS（允许 ±2 LU），真峰值不超过 −1 dBTP，无可闻爆音、明显削波或误触发残留。

## 预算与评价

4 CPU / 8 GB；7200 秒有效工作、最多 140 次成功模型调用、131072 输出 tokens，单次响应最多 8192 tokens。成功模型响应及工具执行（含联网等待）消耗有效时间；模型接口失败与排队不计入该时间。

联网另设 **60 次外部 HTTP 请求**硬上限，含搜索、页面读取、下载、失败请求、重定向的每一跳和显式重试；精确相同 URL 的本次运行缓存命中不产生额外请求。单文件最大 64 MiB，总接收字节上限 512 MiB。每次联网工具返回剩余预算；预算用完后仍可使用已获取素材继续本地制作。`network_status` 可查询预算，不联网。不得将预算上限理解为必须用满。

评分保持：叙事适配 35、音乐结构与剪辑 40、短版适配 15、混音技术 10。工程可打开、迁移、重渲染，以及音源与授权可核验，属于交付门槛，不给内容加分。不存在唯一选曲或时间线，也不以与原片配乐的相似度打分。
