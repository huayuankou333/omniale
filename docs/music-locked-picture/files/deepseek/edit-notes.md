# 动作喜剧锁画重配乐 · 交付说明（long 128 s / short 32 s）

影像：*Caminandes: Llamigos* (2016)，Blender Studio / Blender Institute，导演 Pablo Vazquez，
CC BY 4.0（https://creativecommons.org/licenses/by/4.0/）。本片画面未改动一帧（逐帧 MD5 与输入一致），
只重新配乐。以下时间均为成片时间轴（秒）。

## 1. 选曲与"一套配乐"的身份

五首 Kevin MacLeod（incompetech.com）CC BY 4.0 录音，各自承担一个角色主题，而不是五段相似背景：

| 角色 | 曲目 | 原生调性/速度 | 用途 |
|---|---|---|---|
| Koro 的"算计" | Sneaky Snitch | D 大调 / 86 BPM | 开场窥视、滑倒、投浆果的小把戏 |
| Pikilio（犰狳）与追逐 | Monkeys Spinning Monkeys | G 大调 / 144 BPM | 犰狳审视、矿车追逐、企鹅队伍 |
| 火车 / 危险 / 撞击 | Volatile Reaction | D 小调 / 152 BPM | 雪犁火车、冰湖、坠落、落地重击 |
| 飞行 / 夜 / 奇迹 | Floating Cities | C 小调 → 移调 +2 = D 小调 / 117.5 BPM | 空中慢镜、黄昏灯塔、孤独夜空 |
| 温柔 / 友谊 | Wallpaper | G 大调 / 92 BPM | 事后、独处、赠礼与灯塔结局 |

调性布局是刻意的：主调 D —— 喜剧段用 D 大调（Sneaky Snitch），危险段用同主音 D 小调
（Volatile Reaction），飞行把 Floating Cities 从 C 小调整体上移 2 个半音到 D 小调，于是"危险"和"奇迹"
共用一个主音；结局转 G 大调（Wallpaper，与 Monkeys 同调），把喜剧的明亮色和友谊的暖色放在同一调域。
五首素材因此互相听得见，而不是拼盘。

所有处理只来自这五段录音：剪切、重排、变速、移调、滤波、增益包络、从素材中截取的短促乐音作重音；
没有生成音乐、外部模型、拟音、环境声或原片声音。

## 2. 长版：主要情节的音乐判断

- **0.00–7.35 窥视与迟疑**：Sneaky Snitch 从第一拍进入，拨弦的"蹑手蹑脚"就是 Koro 的意图；
  2.30 的拨弦重音对着他后仰，4.0–6.0 的静止段落音乐也悬着不解决。
- **7.35–8.15 滑倒**：主题在 7.35 被"磁带停"式降速（1.05→0.18 倍速，约 -18 半音），
  8.10 一记低通撞击。音乐跟着他一起失足——这个笑点由音乐承担，而不是靠音效。
- **8.30–13.375 面朝下趴冰**：只剩 Floating Cities 的低通气息（-34 dBFS RMS）和零星高音。
  五秒"尴尬静止"有底噪般的空气，不是无乐空白；13.375 硬切特写时铃音落下。
- **13.375–22.50 犰狳审视**：Monkeys 的稀疏前奏（-26 dBFS）像小动物探头；17.0 它转身时加入拨弦。
- **22.50–35.95 雪犁火车**：Volatile Reaction 30.28 起的驱动段；23.5 火车入画处叠低音撞击。
  26.0 切 Koro 惊慌特写时，同一段音乐低通 1.1 kHz 并降 7 dB——音乐退到画外；28.6 全景火车逼近时恢复。
  35.3/35.85 双击后 35.95 收束，火车擦身而过。
- **35.95–42.00 冰湖对峙**：Floating Cities 的冰面气息（-30 dBFS）。39.0 大全景两人隔湖相望，
  只有极轻的高音铃；留白是"危险前的屏息"。
- **42.00–44.62 投浆果**：Sneaky 的拨弦动机回来做小把戏，42.5/43.3 两个拨弦重音对投掷；
  44.62 浆果打中眼睛，"boing"（1.3→0.55 倍速下弯）把乐句截断。
- **45.00–48.50 木桥**：Volatile 低通 240 Hz 的低音脉冲（-31 dBFS）积累危险；48.5 塌落，
  0.75 s 下坠弯音（1.0→0.25 倍速）接 49.25 落地。
- **49.25–54.15 冰洞**：380 Hz 低通的洞穴低频，空而闷，配 Koro 发懵。
- **54.15–58.15 犰狳带浆果出现**：Monkeys 主题弱奏回来——"同伙"的听觉标记。
- **58.15–69.90 矿车**：Monkeys 86.12 起的律动；67.0 进洞低通 1.5 kHz，62.6 出洞时叠高频铃（冲出黑暗）。
- **69.90–72.00 隧道尽头的光 → 弹射**：1.2 s 上滑 riser（0.55→2.4 倍速），71.1 低音撞击。
- **72.00–85.00 飞行**：Floating Cities（+2 半音）的悬浮和声；74.0/74.6/75.2 三个铃音对慢镜浆果；
  78–81 企鹅乱入时叠 Monkeys 高八度拨弦（喜剧对位）；81 之后只剩悬浮，84.3 后近乎空白，为坠落蓄势。
- **85.00–87.75 山脊坠地**：Volatile 低通脉冲加速，87.25 弹跳重击，87.75 雪地砸落（全片最重一击）加尾音。
- **89.20–96.00 事后**：Wallpaper 钢琴进入，温暖而克制；93.75 全景里犰狳走开，只留高音铃。
- **96.00–103.50 独自**：Wallpaper 继续但收薄 3 dB，Koro 的失落不被音乐"安慰"得太早。
- **103.50–110.80 黄昏灯塔 / 夜**：Floating Cities 的垫子换成夜的颜色（-28 dBFS），孤独但有光。
- **110.80–113.00 看见朋友**：铃音上行 + Monkeys 主题以高八度弱奏远远出现，听觉上"认出"犰狳。
- **113.00–117.20 企鹅队伍**：Monkeys 27.59–31.79 的轻快动机（-15 dBFS），摇摇摆摆的进行。
- **117.20–128.00 结局**：Wallpaper 198.3–209.1 的末段（自带终止式），128.00 收在最后和弦；
  124.0 灯塔光束处叠铃音。最后的和弦与光束同落。

## 3. 短版（32 s）：独立发行版，不是长版截段

短版取长版 64.0–96.0 的连续动作（矿车出洞 → 弹射 → 飞行 → 坠地 → 事后），但重新设计：

- **0.00–7.00 冷开场**：Monkeys 70.94 的律动第一拍就进入（长版这一时刻用的是 86.12 段），
  1.0 冰块爆裂（低音重击），3.0–5.0 进洞低通，5.0 后加速；7.0 弹射重击。
- **8.00–14.00 飞行**：Floating Cities 24.06 起的另一段（与长版 8.06 段不同），
  10.0/10.65/11.30 铃音对慢镜浆果。
- **14.00–17.00 企鹅**：高八度拨弦玩笑；**17.00–21.00 下坠**：悬浮收薄，20.3 后近空白。
- **21.00–24.75 撞击**：低通脉冲，23.25 弹跳、23.75 雪地重击（短版最重），23.3 起磁带停收束。
- **24.75–31.25 事后**：Wallpaper 44.0 段（-23 dBFS）温暖；29.75 全景铃音。
- **31.25–32.00 终止**：直接接 Wallpaper 208.30 的末和弦（0.75 s）作短版自己的终止式，收在 32.0。
  短版因此有自己的开头（冷启动的追逐）、发展（弹射/飞行/玩笑/坠落）和结束（安静、略苦的解决），
  而不是长版音轨的一段。

共同身份：同一五首素材、同一调性布局（D 小调危险 / G 大调温暖）、同一套语汇
（磁带停、riser、低音撞击、悬浮垫）；差异在进入点、段落长度、配器层次和终止式。

## 4. 混音与母带

- 每个 cue 按"目标 RMS"定增益（-34 至 -16 dBFS），形成明确的动态曲线；条目增益、淡入淡出在工程内可编辑，
  危险段/温柔段另有轨道音量包络。
- 对峰值突出的拨弦/追逐/重音素材在预处理阶段做峰值削减（alimiter，见对照表以外的处理后文件）；
  Floating Cities 整体 +2 半音（rubberband，独立于变速）；洞穴、隧道、桥段用低通做"画外/洞内"的空间感。
- 信号链全部为 48 kHz 立体声 24-bit；无削波。
- 母带打印：`alimiter limit=0.871 (-1.2 dBFS), level=disabled`（见 `project/master.sh`）。
  实测（成片 WAV）：long **-16.7 LUFS / 真峰 -1.2 dBTP**；short **-16.5 LUFS / 真峰 -1.2 dBTP**（MP4 的 AAC 音轨测量一致，±0.1 LU）。

## 5. 工程与重渲染

- `project/long.rpp`、`project/short.rpp`：REAPER 7 原生工程，全部音频用相对路径。
  轨道：Sneaky Snitch / Monkeys / Volatile / Floating / Wallpaper 五个主题轨 + `Accents & Gestures` 重音轨。
- `project/media/originals/`：五首原始下载（MP3 原始字节）；`media/source_wav/`：48 kHz 解码；
  `media/processed/`：全部剪切/变速/移调/滤波后的可编辑片段。
- `project/renders/`：工程直接渲染的 48 kHz/24-bit 混音（母带限幅前），可直接对比。
- 重渲染：`xvfb-run -a reaper -renderproject project/long.rpp`（工程已存 48 kHz/24-bit 渲染设置），
  再 `sh project/master.sh <render.wav> long-music.wav 128`；短版同理（32 s）。
- 迁移到新目录后可离线打开、编辑、重渲染；所有媒体均在包内。
