# 一颗浆果，一个朋友 — 锁画音乐重剪说明

## 交付与打开

- `long.mp4` / `short.mp4`：128 秒故事版与 32 秒独立短版。画面流直接复制对应锁画；不加字幕、效果、转场或片尾画面。
- `long-music.wav` / `short-music.wav`：48 kHz、24-bit PCM、立体声，分别为 6,144,000 与 1,536,000 样本。首样本对应画面 0 秒。
- `project/long.RPP` / `project/short.RPP`：原生 REAPER 工程，22 / 9 个可编辑音乐 item，另附各自的无声锁画视频轨。没有把最终混音当作唯一素材塞进工程。
- 全部媒体相对路径；完整原下载在 `project/originals/`。可直接打开工程，按已存渲染设置输出同名 WAV 到工程上一级。详见 `project/README.zh-CN.md`。
- 逐条素材关系在本页附表、`project/cue-sheet.csv` 和两个 `*-edit-map.json`；包络锚点另见 `project/volume-automation.csv`。

## 选曲与音乐身份

**Sergio's Magic Dustbin — Kevin MacLeod** 是动作/喜剧的共同身份。作者目录列出的编制包含大号、马林巴、木管、铜管、鼓与钟琴等；录音本身由较小的机械性短句逐步加速和扩张。开头的短音型用于“我还想吃”的执念；较快的变体用于火车；最饱满的部分只在矿车真正失控时放出。开头和高潮并不是同一个音量档的背景铺陈。

**Evening — Kevin MacLeod** 的木吉他、大提琴、双簧管换掉忙碌的机械脉冲，用于空中目光的转变、离别后的孤单和最后分享浆果的回报。没有在火车或矿车尚未安全时提前给角色一段英雄凯旋。

两首均从作者本人 Incompetech 站点独立发现并核验为 **CC BY 4.0** 的录音；不是“古典作品公版所以录音也公版”的推断。详情页现由 JS 载入，本轮文本抓取空壳并不构成许可证明，故同时保留了作者公开曲库的两条录音记录、作者 FAQ 的 CC BY 4.0 声明及 CC 原站条款证据。详见 `source-manifest.json` 和 `project/evidence/`。

## 长版：音乐对情节的判断

| 画面时间（秒） | 判断与实际安排 |
|---|---|
| 0–7.2 | 羊驼试探着接近浆果。用小编制短句建立执念；3.15–5.6 的等待把脉冲压小约 6 dB，不为每次眼珠移动补一记音。6 秒后恢复力度，让第二次尝试有蓄力。 |
| 7.25–17.43 | 企鹅成群经过、羊驼扑倒，再到小企鹅近景，是三种不同尺度的喜剧。接第二句和答句，不用持续升级的全奏。小企鹅退场后在 17.43–19.08 留出约 1.65 秒真正的空白，让羊驼的死鱼眼成立。 |
| 19.08–22.17 | 用短的下行尾句回应流口水；先结束小句，再换成火车的快脉冲，避免只是将同一首音乐越推越大。 |
| 22.167–36.01 | 火车以更快、更厚的变体进入。羊驼意识到火车的反应段（约 26.15–28.3）收小，随后向铁轨上小企鹅和最后一刻扑出积累。像救援的起势之后，落回嘴边浆果的滑稽现实，而非奏凯歌。 |
| 35.94–42.17 | 接入录音中自然逐渐消瘦的下行句；余音结束后给安全露头的小企鹅留一个静止的观察窗口。不是把动作段硬拉长到每个镜头。 |
| 42.167–50.14 | 小浆果回到舌尖，旧短句回归；企鹅抢走时有短暂的音乐中断，再由答句追上。地面打开处另接原录音的下降尾巴，不添加坠落音效或撞击拟音。 |
| 50–58.92 | 矿洞苏醒时，同一短句改用较暗、较窄的音色，保持身份而缩小空间。54.5 秒矿车悬空的远景用走低、走稀的句子，先让危险被看见，再释放动力。 |
| 58.92–71.17 | 矿车落轨起跑，才进入完整乐队的高速段；64–66 秒稍收，保留羊驼自满表演的空间。66.625 秒额头第一次撞梁前后让主层退一小步，插入从本曲抽出的一个低短音作音乐性纠正；后续低头闪梁不机械逐个打点。 |
| 71.167–78.25 | 出洞飞起接本曲真正的终止和弦与原录音余音，使高速追逐突然变成悬空。浆果进入注意力后，小音型又短暂冒出；这一段不是继续满铺速度。 |
| 78.25–85.17 | 小企鹅的脸占据画面时，吉他主题取代追逐脉冲。目光、犹豫和保护的意向需要时间，所以不在每次表情改变上加打击乐。先出现关心，后出现着落。 |
| 85.17–95.79 | 空中关系段被下降乐句带回现实；87.667 秒接触雪面的动作由同一管弦终止和弦回应。落地不是最终胜利，89.04 秒回到疲惫的小动机；小企鹅跳走时略抬，再随着离开收小。 |
| 95.7–111.17 | 旧执念不再继续跑动。先用安静吉他过桥，再用 Evening 的尾部完整段落承接孤单、日落。98–101 秒仍压低，不因景色漂亮就立即煽情。 |
| 111.17–128 | 小企鹅带着浆果回来，随后出现整个群体：音量包络在 111 秒以后才打开，温暖的声部成为回报。保留录音自然的结束，不在最后一帧生硬切断音乐；灯塔远景让终止余音退去。 |

## 短版：不是截长音轨

短锁画连续对应长版约 **64–96 秒**，但音乐独立重构：

1. **0 秒有新的主题入口。** 长版此刻已在最饱满的高速段内部；短版改以本曲较轻的快变体（源 81.15 秒）建立身份，先让观众进入矿车场景。额头音乐短音放在短版 2.625 秒，与相应画面一致。
2. **约 5.04 秒换入凝缩的全奏收尾。** 用源 142.35–144.475 秒的真实尾部接到 7.167 秒的出洞和弦，是有目的的短版发展与收束，不继承长版几十秒的积累。尾句和和弦在源时间上连续，没有重复两次同一末拍。
3. **悬空与目光保留共同身份。** 小音型在 9.9 秒重新出现，14.25 秒切换到与长版同源的吉他关怀主题；21.17 秒下降，23.667 秒落地。
4. **落地后重新设计结尾。** 长版落地后回小动机，随后还要经历孤独和团聚；短版没有这些后续画面，所以 24.42 秒开始借用 Evening 的原录音终止段（源 177.70–185.28 秒），让恢复、站稳和小企鹅滑走成为有回声的告别。终止与余音在片尾前落定，不留下“音乐被视频截断”的感觉。

短版的开头、出洞前的发展、落地后的终止都与长版对应区间不同；空中看向企鹅的主题与核心出洞/落地和弦则共享，保留同一部作品的音乐身份。

## 混音与可编辑性

- 所有使用的声音都来自这两首录制音乐。额头短音与出洞/落地和弦是音乐摘取，不是新增拟音。没有原片音轨、对白、环境、外部效果库、生成音乐或外部助手模型。
- 没有时间拉伸或调音：**所有 item 1.000×，0 半音**。源曲自身的加速、配器增加与调性变化保留在录音内；不把它写成 DSP 变速。
- 完整预处理链可由 `project/preprocess_audio.sh` 重建：Sergio 高通 32 Hz、6.5 kHz 高频架 −1.2 dB；矿洞版在此之上低通 1.9 kHz、侧声道 0.7；Evening 高通 38 Hz。其余以 native item trim、淡入淡出和轨道音量包络完成。
- 没有混音后再套一个不在工程里的“秘密响度处理”。工程 master 的静态 trim 为长版 **+2.0 dB**、短版 **+1.6 dB**。不需要外部插件、在线资源或额外混响来复渲染。
- 接缝保留毫秒级淡变；关键静止反应有意留白，其他低密度处主要是原录音的乐句余音或收句。没有以长段无声规避叙事。
- 表中增益为 **item trim**，还要叠加对应轨道包络与 master。包络的时间/增益锚点在 JSON、CSV 与 RPP 中可编辑，RPP 使用原生 fader-scaled 音量包络。

## 实测质检

| 文件 | 时长 | 积分响度 | 真峰值 |
|---|---:|---:|---:|
| long-music.wav | 128.000 s | −16.61 LUFS | −1.77 dBTP |
| long.mp4 的 AAC | 128.000 s | −16.62 LUFS | −1.76 dBTP |
| short-music.wav | 32.000 s | −16.95 LUFS | −1.42 dBTP |
| short.mp4 的 AAC | 32.000 s | −16.96 LUFS | −1.41 dBTP |

- 两 WAV 均 PCM s24le / 48,000 Hz / 2 ch；MP4 音轨是同一 WAV 混音的 320 kb/s AAC 编码，没有独立二次调平。
- 对输出与各自输入解码得到的 **3072 / 768 帧逐帧 framemd5 完全一致**；复制视频 elementary-stream SHA256 亦一致。输出视频均 960×540、24 fps，PTS 从 0 开始。
- 把原生工程和媒体搬到另一个目录，使用新的本地 REAPER 配置离线复渲染，两版与交付 WAV 的 PCM **逐样本一致，最大差为 0**。完整数据与工具输出保留在 `project/evidence/qa/`。
- 检查基于实际画面、波形/谱、样本与响度分析及原生复渲染；没有声称完成有监听条件下的主观听审。
