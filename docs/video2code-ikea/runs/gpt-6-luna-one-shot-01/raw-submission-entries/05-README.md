# Local IKEA BESTÅ shopping journey

Run with the configured static server from the project root (the server already serves `index.html` and `/assets`). Open `/` in a browser. All navigation is local and deep links are supported; state persists in localStorage.

Implemented flows: home navigation/search, BESTÅ result filters and price sort, product compare, BESTÅ combination and STUBBARP pages, gallery/dimensions, component list, ZIP/store drawers, cart quantity/removal/undo/assembly, discount-code validation, and customer review sorting. Product catalog and media load from the supplied `/assets/` files.
