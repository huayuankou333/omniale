# Video2Code — IKEA BESTÅ shopping journey

根据随附的真实官网操作视频 `ikea-besta-demonstration.mp4`，实现可以本地运行的网站，复刻视频展示的页面、视觉和交互。视频是界面与行为的主要依据。

复现范围包括首页分层导航、搜索联想和结果列表、筛选排序、商品比较、组合商品详情、图片与尺寸弹层、详情标签与组件清单、独立组件详情、商品变体、邮编与门店选择、购物袋，以及视频实际展示的评论和表单反馈。

页面应通过本地路由相互连接；商品身份、变体、数量、组成、价格和费用应随操作一致更新。用户可以按与演示不同的顺序操作视频中出现过的选项。需要支持浏览器返回、直接打开相关路由和刷新后的状态恢复。

保持视频展示的布局、图像比例、字体层级、色彩、间距、图标、滚动区域、抽屉、弹层、表格和响应反馈。参考视口为 1440 × 900。未提供移动端参考，因此不以猜测的移动端设计评分。

交付源代码、启动说明和可操作的网站。不得以整页截图替代界面，也不得将应在本地实现的功能跳转至 IKEA 官网完成。真实账号、真实订单与支付、三维规划器不属于本次范围；库存、价格、配送日期采用录制时的固定快照，不要求追随官网实时变化。

录屏无音轨，仅包含浏览器网页视口。视频中的短暂空白、加载和无响应尝试属于实际采集过程；不要求故意复刻采集自动化失败。应实现已经展示的稳定结果与合法操作反馈。

正式评测输入契约（本次固定）

使用录屏对应的本地商品切片及图片：`/assets/catalog.json`、`/assets/manifest.json`。可以通过 read_file 读取这两个文件，或在网页 fetch 本地 URL。图片清单提供真实单张商品/场景图片和品牌图标，不包含参考界面的整页截图、HTML、CSS 或脚本。首页自动播放宣传视频可用所提供的照片替代；不因视频帧内容差异扣分。可使用 Arial 等本机无衬线字体，细微字体抗锯齿差异不扣分。

目录为录制相关商品的有限切片，不要求实现全部 165 件商品。165 / 87 等结果数量可以使用固定汇总数据。必须支持视频实际操作的白色筛选、清除、价格升序，两个柜体（60245844 / 00245842）及第三件（70245848）的比较；原木色组合柜 29209829、胡桃木效果组合柜 29612189，以及独立 STUBBARP 20293568 的展示和业务流程。未演示的门店及变体可仅作外观占位，不据此扣功能分。

组件链接可使用同一标签页或新标签页，能返回组合上下文即可；不要求模拟浏览器标签栏。官网路径可保留或使用含明确商品 ID 的本地等价路径。视频中的浏览器返回、再次进入购物袋与刷新都属于复现范围。

匿名购物袋按官网原价计价，Family 价格和节省金额是单独提示。考察数量改变后的行金额、总额、组合组件数量、安装服务费；删除与 Undo；无效折扣码不得降低金额；非法邮编不能保存，95054 与 East Palo Alto 门店按固定快照显示可配送/库存。组合与单独购买的不同 SKU 柜脚必须独立。商品详情还需实现图库、尺寸、组件标签、评论抽屉及最低评分排序。

本地可信静态服务器已配置，前端可用原生 HTML/CSS/JavaScript/SVG，不允许任意 shell、下载依赖或调用外部网站。只修改自己的前端文件，package.json、server.mjs、assets/ 只读。状态可保存在 localStorage。没有需要实现的真实账号或支付接口。

评分为执行 10、页面导航 15、业务交互 25、状态一致性 20、视觉 30，共 100 分。功能依据实际操作结果逐项判定；视觉比较多个页面和弹层，允许合理技术实现差异。所有操作来自视频或本契约。
