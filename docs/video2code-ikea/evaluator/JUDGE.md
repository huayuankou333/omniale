# IKEA v1 评分规则
冻结在候选生成前。28项功能各2.5分，12项视觉各2.5分，总分100。无隐性封顶、额外扣分或事后改权。
功能依据操作前后截图、URL与可见文本/控件，逐项0或1。定位失败需核对真实UI并重试；环境失败或证据不足为unjudgeable，未解决前总分N/A。前置失败应独立重置场景验证，不能凭推测连扣全部后续项。源代码与模型自述不能替代UI证据。允许等价本地路由、文字/ARIA与实现方式。
视觉按每个指定匹配状态评分：1=主要结构、比例、图片、层级和样式吻合；.75=同状态关键布局正确，仅少量局部差异；.5=可辨认同页面但有多处明显差异或一个重要部分缺失；.25=仅粗略布局/主题相似；0=对应状态未实现或画面无对应关系。允许字形抗锯齿/静态宣传视频照片差异，不因未提供的字体或视频素材扣分。整体截图压缩到同尺度后比较，不能只凭首页美观补偿缺失状态。
匿名judge只见reference/candidate截图及条款，不见候选模型身份、目标分数或源码。两个judge独立；视觉差异>.25时结合原始录像补证裁定并披露。服务不可用不得编造judge结果。同家族judge与代理裁定必须披露，不称人类认证。
