02 / WHY THIS IS HARD

困难来自连续操作的正确性。

01

屏幕 → 世界坐标

相机转动后，仍要命中正确的凸点和表面。固定屏幕热点无法通过。

02

几何 → 真实状态

宽深交换、顶面高度、遮挡和删除影响后续操作；几个预制画面不足以复现。

03

模式 → 保留内容

编辑、展示、擦除和模态框各有语义。返回编辑后，作品和工具需要继续正确工作。

不靠隐藏需求增加难度

未演示的文件保存、撤销/重做、单块移动、声音和云协作不计功能分。取消清空的语义在公开任务中明确给出。
