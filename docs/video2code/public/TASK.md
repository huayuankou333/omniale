# Video2Code: 3D Brick Studio

根据 `inputs/demo.mp4` 复刻录屏中的三维积木编辑网站，交付能在本地启动并实际操作的网页项目。主要需求来自视频的画面、指针动作和前后状态；本任务不提供原站源码。

## 交付

- 在分配的项目目录中创建完整代码和 `README.md`，写明启动命令。
- 使用 Node.js 22。提供 `npm run dev -- --host 0.0.0.0 --port 3000`；网站在 `/` 可访问。本次统一使用浏览器原生 JavaScript/HTML/CSS，预装 Three.js 0.180.0（import "three" 与 "three/addons/..."）。不提供 React/JSX 编译器。
- 资源放在本地。验收时禁止联网；不要使用录屏、截图、iframe 或原站来代替交互界面。
- 你需要实际启动、检查自己的网页，修复阻塞错误。最终答复给出入口、启动方式和已知未完成项；自述不代替验收。

## 复刻范围

1. 复现浅灰环境中的立体底板、积木、底部深色工具条、左侧模式按钮和清空对话框。保留视频中的主要比例、色彩、材质与反馈。
2. 实现视频展示的放置预览、网格吸附、相邻放置、在已有积木上叠放、颜色选择、宽/深选择及交换、播放/暂停展示模式、手动改变视角、擦除目标高亮和删除、清空确认。
3. 同一种操作应可重复，能作用于新位置和不同的已展示颜色/尺寸组合。转动视角、交换尺寸或删掉积木后，后续拾取、预览和搭建仍应正确。
4. 初次进入可采用视频开头的一块红色 2×2 积木，也可采用空底板。初始种子不计分；验收统一先清空再开始。
5. 清空对话框的 Cancel/关闭应保留模型，Clear 应移除全部积木并允许重新搭建。该取消语义是本题公开补充约定。
6. 清楚区分放置模式、手动视角模式和擦除模式。模式切换不能意外新增或删除积木。手动视角模式改变相机，不要求移动已放置的积木。

以下不在本版功能评分范围：未演示的文件打开/保存、撤销/重做、自定义颜色弹窗、声音、登录、云端协作、刷新后的作品持久化、手机触控、任意物理碰撞、悬空支撑规则或移动单块积木。界面上可保留其静态图标。不要为它们牺牲已展示的交互。

## 环境与预算

- 主模型最多 15 个逻辑请求轮次；每轮可以请求多个工具，所有调用分别计数。
- 最多 120 次工具调用。网关不执行输出 token 硬上限；每轮请求 9,000 仅为建议值，本轮硬预算是 15 轮调用及工具/图片次数。请简洁地推理并尽快通过工具实现和验证网页；实际 token 用量记录在报告中。
- 四个模型使用同一抽帧/浏览器工具，直接接收相同初始视频帧和后续请求的图片。初始 12 帧计入 256 帧预算。自己的网页截图也直接返回图片。
- 视频观察上限 256 帧；自己的网页观察上限 120 帧。缓存命中也计入逻辑预算。可按需精确抽帧，不限于初始缩略图。
- 视频长 41.333 秒，1280×804，30 fps；原音轨为全零静音，因此无需语音识别，不给音频理解分。
- 可运行、交互与状态一致性、视觉还原和基本可用性分别占 10、60、25、5 分。验收包含原顺序回放以及相同操作的不同位置/颜色/顺序组合；不增加未说明功能。

本题仅检验可观察结果，不限定内部数据结构、DOM 层级、CSS 类名或实现库。不要读取 evaluator/design 目录、原始 WebCompass checklist、其他候选结果或参考实现。

## 本次统一运行约束

项目从空白 index.html 开始。package.json、server.mjs 和 vendor/ 为只读可信环境；npm run dev 使用提供的静态服务器。只能编写前端文件和 README.md；不能执行任意宿主机 shell、Node 后端代码、读取评测目录或联网安装依赖。run_command 支持启动、语法检查和刷新。所有四模型使用完全相同的约束。可通过 browser_action 进行鼠标点击、拖动、键盘和截图来自检。
