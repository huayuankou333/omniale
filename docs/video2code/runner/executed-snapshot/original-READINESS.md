# 正式运行前验收

当前完成的是 **案例设计、真实视频输入、检查清单、场景、媒体工具和评分汇总器**。本轮没有要求四模型实测，因此没有花费候选 API，也没有生成排名。

以下事项尚未完成；不能把本包称为已经通过端到端评测的 benchmark：

- [ ] 编写或取得一份可运行参考复刻，并由独立人员用本 checklist 完整验收，确认所有功能要求可达。原站部署 URL 未随数据发布，不能声称已跑过原站回放。
- [ ] 人工复核关键短时事件、相机手势和全部 43 个断言；将真实演示支持与公开补充约定分开签字。
- [ ] 接通隔离的 coding-agent runner。不能直接给候选宿主机终端或 D:\omniale 根目录权限；只挂载 public 输入、独立工作目录与相同离线依赖。
- [ ] 固定 Node、Chromium、渲染器/GPU、依赖 lockfile 和资源缓存；同一 viewport/device scale。
- [ ] 固定共享观察器版本、提示词、初始帧组及缓存。审计其对尺寸/模式/时序的描述，防止四模型共同的感知瓶颈变成假“低分”。
- [ ] 固定两名独立视觉 judge 和温度；先用已知缺陷样本校准一致性，再冻结所有输入/评分器/环境哈希。
- [ ] 保存四个模型各 3 次有效 trial 的原始轨迹。候选实现问题计失败；API 和评测端故障按预登记规则处理为 N/A 或重新运行。

建议先做 reference + 空白页 + 静态截图伪实现 + 一个可运行但不支持叠层的缺陷样本四类验收。这些是评分体系校准，不是四模型成绩。

升级 v2 的方向：重新录一段 3–5 分钟有明确状态反馈的真实演示，展示保存/导入回环、撤销/重做分支、多选和变换。只有这些行为确实在新视频里被展示，且公开任务同步说明后，才能纳入评分。不能仅凭工具图标就要求它们。
