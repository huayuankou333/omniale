# 3D Brick Studio

本地原生 JavaScript / HTML / CSS + Three.js 三维积木编辑器，Node.js 22。

## 启动

```sh
npm run dev -- --host 0.0.0.0 --port 3000
```

打开 http://localhost:3000/ 。使用环境提供的静态服务器和本地 `vendor/` Three.js，无需联网或安装额外依赖。

## 操作

- 左侧锤子 / **B**：放置模式。移动到板上显示黄色半透明预览，单击放置；在积木上单击可叠放。位置吸附到 20×20 底板网格。
- 底部色板选择 8 种颜色，两个下拉框选择宽、深（1–6），中间箭头或 **S** 交换尺寸。
- 左侧四向箭头 / **M**：手动视角模式，左键拖动旋转，滚轮缩放。不会放置或删除积木。
- 左侧橡皮 / **E**：擦除模式，悬停目标高亮，单击删除。
- 播放：隐藏工具条并自动环绕展示；底部暂停或 Escape 返回编辑。
- 垃圾桶：打开 Clear Set 对话框。Cancel、关闭、Escape 均保留模型，Clear 清空并可继续搭建。

## 范围与限制

初始有一块红色 2×2 积木。材质和混凝土地面使用本地程序生成。未实现范围外的打开/保存、撤销/重做、自定义颜色、声音、持久化和触屏；相应图标仅作视觉保留。不模拟物理、支撑坠落或移动单块积木。
