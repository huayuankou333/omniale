01 / ASSIGNMENT

从识别动作，到两款软件真实交付

作为声音剪辑师，为Spring原片03:40–06:10制作可信的无音乐音效轨。需要自己看片、识别事件、建立cue sheet，从真实录音中选择、分层与加工；不能用原片原声、现成重配答案、生成式音频或测试音代替。

跨软件体现在交付中

  1. 通过搜索、检查、下载工具在线检索Freesound；限CC0或CC BY。
  2. 在真实REAPER工程内剪辑、混音并原生渲染48kHz／24bit双声道。
  3. 导出AMB、FOLEY_HUMAN、FOLEY_PROPS、CREATURE、SFX五总线。
  4. 五分轨进入真实Shotcut/MLT工程导出视频；禁止额外叠加mix。
  5. 封存首版，再按固定要求返修并在两款软件重新导出。

素材如何选择

只提供无声画面与来源署名；没有候选音效库、事件答案或原片参考声。模型决定检索词、素材、动作区间、处理、空间和混音。

可使用脚本和CLI，宿主执行模型写的命令。下载的是公开高质量预听编码，转成WAV不代表原始无损录音。

固定返修：30–100秒AMB降低4dB，其他总线及区间外环境保持不变。

内容使用五档，分别为：缺失／主体错误；弱相关但动作材质不可信；主体正确但缺少指定阶段或成分；主要成分成立、细节较弱；全部指定成分可听且体量材质合理。允许原创电影音色。

06 / FAILURE ANALYSIS

声音覆盖与局部细节之间的差距

近身动作仍有遗漏

C22追逐中的犬类呼吸／低吼、C23追逐中的灵体活动均为0；C24女孩闪避的身体运动仅0.15/1。场面有声音，不代表每个主体的动作都独立成立。

体量成立，细节不足

C17巨物结构纹理0.525；C18狗的威胁反应0.4。巨物落步与主动作较完整，但结构受力、犬类发声等局部细节偏弱或被遮蔽。

工程与同步分别判断

五轨交接及返修保护通过；M03前后景／遮蔽仅2/4，M04空间连续2.3/4。工程可重放不证明局部同步正确；同步控制失败也不证明模型没有同步。

Qwen3.8-omni-flash对实际音频辅助初评；内容控制识别了原声犬吠，并对五项动作的错配云雾底声给0，属于有限校验。没有逐项人类声音专家终审，局部高分也仍可被实际试听推翻。

07 / PROTOCOL

一次含设施修复的试跑

一轮GPT-6.2 Sol生成，包含首版与返修。预算180有效分钟、260成功轮、500工具、800图像、96次外部试听；每轮最多16000输出token。试听工具由外部Qwen提供，结果反映模型与工具组合，不能表述为Sol原生听音。

生成途中两次基础设施修复：图像上下文从最近3批改为最近48张去重图像；原生导出在约94%被180秒终端上限中止，随后单命令上限提高到600秒。从原检查点继续，原决策和已用预算保留。本轮不是工具配置全程不变的严格对比。

题目事件、五档定义、权重、返修内容和200ms容差在生成前固定。评分实现的修复、控制失败及差异哈希均保留。Spring场景比Charge更长，但未做等难度校准，不能根据一个试跑分数直接比较两题难度。
