# RAVDESS Take360 · 表演驱动ADR

OmniALE D3音频后期开发案例：91.5秒/24镜头、8名画面演员、12名候选演员、360条真实第二遍录音。REAPER原生编辑渲染→Shotcut/MLT交接。并行保留的电影场景题见../adr-scene/。
