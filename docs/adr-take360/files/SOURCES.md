# 素材许可与来源

RAVDESS: The Ryerson Audio-Visual Database of Emotional Speech and Song.
作者：Steven R. Livingstone、Frank A. Russo；2018。
官方数据：https://zenodo.org/records/1188976
论文：https://doi.org/10.1371/journal.pone.0196391
许可：Creative Commons Attribution-NonCommercial-ShareAlike 4.0。
许可正文：https://creativecommons.org/licenses/by-nc-sa/4.0/

候选音频保留官方 ZIP 成员的原始字节，只匿名化文件名。锁画片由官方视听表演转为30fps、移除原声并顺序拼接；校准片为官方未改动的中性表演。没有生成图像、生成语音或合成表演。身份/表演标签的映射由评测方隔离保管，测试结束后的来源核验可使用 provenance/ 和 private/ 中的清单；受测 agent 不获这些答案。

本题是基于该数据集的 OmniALE 新构题，不是 RAVDESS 原论文中已有的软件 agent 测试。软件和模型各自遵循其许可；本轮不再分发软件安装包。
