05 / WHAT THE FAILURES REVEAL
性能约束之间，很难只改好一项。
观察与解释分开


01Sol · 增益与带宽
第一版带宽足够，
增益与稳定性没有同时成立。
Sol 第一版 UGF 为 139.63 MHz，超过 89 MHz；增益只有 62.61 dB，未达到 78.4 dB。相位裕度与增益裕度返回空值，按原判据均为失败。
测量含义 带宽快于门槛，不能单独证明高增益、稳定闭环已经实现。


02Sol · 补偿折中
第三版稳定性改善，
仍不足以完成快速建立。
相位裕度由第二版 −8.1° 提高到 26.9°，仍低于 60°；第三版上升 / 下降建立为 31.41 / 42.95 ns，两项均失败。
最终表现 功耗与工作区达标；增益、带宽、两种裕度与双沿建立均未达标。


03Luna · 完整功能
看似更短的建立时间，
伴随输出跟随功能退化。
第三版只有 16.28 dB 增益和 68.64 Hz 带宽；输入在 0.8–1.0 V 切换，输出约为 0.581–0.600 V。同时有 3 个晶体管不满足饱和要求。
评分边界 原指标相对输出自身最终值判断建立。保留原评测规则，展示这一限制，不将 5/8 转换为更高模型分数。


04实验解释
一次三轮失败，
不能直接确定模型能力边界。
本题在当前预算下使两模型均失败，说明它值得继续研究。每模型仅一次反馈实验；此前 case 使用 high 和更多工具迭代，跨 case 表现同时受题目与预算影响。
可复现性 作者参考解在本地 8/8 通过；作者公开失败网表的八项评分指标也在本地复现一致。
