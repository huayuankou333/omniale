# 数据审计与不可混用的证据

1. NASA TP2879，NTRS19900001929，1989年11月：220页PDF已取得。表I/II几何、表III(a)/(b)径向性能、表IV积分权重、表V流量不闭合和表VI激光位置均可读。表III/IV关键页经渲染人工视觉核对后转写为CSV；不是未经校验OCR。PDF正文288.2K与表III288.15K的舍入差异已明示，冻结工具用288.15K。
2. PE/NS出口各9径向位置×4量，加3个整体量，形成各39项、共78项目标。PE校准，NS公开程序性留出。入口19点是边界数据，两个质量流量是工况条件。正式原始目标不因求解失败而改写。
3. 整体效率、压比来自原表报告值；打印位数及历史cp/平均定义造成的微小算术不一致不应被自动改写。先实现NASA九站能量平均并同时报告全环结果。输入/出口积分流量相对孔板有约1–3%差异，表V说明了测量和采样限制。
4. 完整激光原始ASCII在原文称“磁介质可索取”，本包未获取，也没有伪造相位时序。PDF曲线可追溯数字化，给数字化误差；没有取得原始数据的量不可声称已验证。仅轴向/切向速度直接测量，不能将径向分量也标成实验。
5. HiOCFD4/Cenaero页面下载两套CAD：含隙和无隙；归档日期路径不是实验日期。原STEP单位mm，实体是流体流道；含隙版本几何抽样约1.007–1.029mm。导入边界编号依赖Gmsh4.13.1，不假定所有软件编号恒定。无隙版本只供差异审计。
6. NASA设计流量33.25kg/s和设计压比1.63是设计规格，不替代实测PE的34.573kg/s、1.642，也不替代NS。NASA原始Rotor67为风扇转子、无入口导叶/无下游静子，题目称压气机叶型改造是工程扩展。
7. CR1998-206994逆向设计及20050196726抛光研究作为机理/敏感性背景。后者是不同实验活动，不能将其曲线与1989年数据拼成同一验证地图。公开可读不等于有任意再许可权。
8. 五速使命工况、约束、鲁棒盒、畸变、材料、根部边界与目标均是原创合成工程规格，不是NASA测量。没有已知可行方案或隐藏答案。工程拒绝必须有局部有效证据；资料/求解不足为unresolved。
