## 3. 验证、计量映射与数值可信度

PIV只在有效测量点/掩码上比较，区分二维截面和周向平均，采样算子与实验方向一致。报告速度均值及RMS、IRZ长度和上游端位置、中心线速度、剖面与有效覆盖。OH*是视线积分，OH-PLIF是切片激发信号；OH浓度、放热率、OH*不可无说明地等同。没有物理坐标标定的AHEAD原始图只作定性或在可追溯配准后给出位置区间。HYLON组分是摩尔分数，流场组分可能是质量分数，比较前显式转换。

区分测量输入、边界参数、论文数值结果和本次真实预测；不可把任何公开数值场直接当作自己运行的3D输出。要求留出结果覆盖不少于80%的有数据目标剖面；未覆盖与无效点不能从分母静默删除。参数迁移检验是公开结果上的预注册检验，并非真正盲测。

## 4. 回火边界定位与事件判别

以预混管出口为z=0、下游为正。`tau=Dmt/U_bulk`，U_bulk由该工况总入口空气质量、实际空气密度及34 mm管面积计算，并将定义写入配置。HYLON沿其说明书定义坐标，不使用AHEAD的Dmt。

对 AHEAD 两个客户工况族 H=(130 kg/h,623.15 K) 和 C=(180 kg/h,453.15 K) 在phi=0.20…0.90范围做先粗扫再局部夹逼，不假定稳定性随phi单调。默认粗步长<=0.05，边界夹逼宽度<=0.01。每个稳态统计窗至少20 tau，先排除至少10 tau的启动过渡；临界工况至少三个独立扰动/初态重复，并执行降phi与升phi两个方向，记录迟滞和删失。

正式回火事件需同时存在：(a) 活跃放热/耗氢前沿进入z<-2 mm；(b) 上游该区正化学放热积分超过本工况入射燃料低热值功率的0.5%，连续至少2 tau。保留前沿连通性、温度、耗氢率、速度符号和反应热源的原始证据。仅有高温产物或OH回流不算事件。对位置阈值-1/-3 mm、放热阈值0.25%/1%、持续时间1/4 tau做敏感性。可另外提出更物理的判据，但必须保留默认判据结果，并解释差异。

若反应熄灭、持续吹脱、守恒/数值检查失败或观测窗不足，结果分别记 `blowoff`、`numerically_invalid` 或 `unresolved`，不能记成 safe。输出每个真实运行的phi、物理时长、初态种子、事件时刻/删失时刻、前沿位置、反应功率及日志哈希。有限时间内没有事件不等于零概率回火；按观测窗给出风险限制，不将三个重复误报为95%高可靠度证明。

对原表两个boundary工况，计算临界夹逼区间；本题目标是夹逼中点与0.60/0.30的绝对差<=0.03、区间宽度<=0.02，同时与已知稳定点一致。原表未给出的实验误差不得自行宣称为±0.03，后者只是本题验收容差。边界若落在区间外、发生LBO遮挡或始终无FB，分别明确外推/左删失/右删失，而非回填测量phi。

`phi_safe` 定义为在扫描结果中连接到锚点（H为phi=0.80、C为phi=0.60）的连续稳定分支的最低已验证phi：中间不得跨过FB、blowoff、无效或未求解缺口；稳定点间隔<=0.01才可纳入最终边界。它同时受回火与吹脱限制。不能把回火消失却已熄火的状态算作改型收益。

## 5. 抑制设计与制造约束

客户只允许改动AHEAD轴向空气支路的可更换节流件，保留旋流器7 mm阻塞环、所有燃料孔/稀释孔、预混管、燃烧室以及供气拓扑。基准严格为8.0 mm孔径原始CAD。设计变量为节流喉径8.0…10.0 mm、同一节流件的有效直孔段长度相对基准0.5…2.0倍，以及入口圆角半径0…0.8 mm。变动只在识别出的节流件内实施，壁厚>=1 mm，不得堵孔、隐藏改变其它面积或引入额外外供气。有效直孔段若CAD不支持独立改动可固定为1.0倍，说明识别依据，不得靠移动整个轴向喷嘴替代。

须交付参数化CAD/网格脚本、关键截面及尺寸、体积/拓扑差分、最小壁厚和制造公差。D_or=8.8 mm原型数据只用于留出验证，允许它成为设计候选但不能据其公开稳定标签直接声称工艺成功。至少计算基准、两个有物理理由的不同候选和最终候选。优化代理可用，最终基准/设计要在相同锁定模型、精度和统计窗上独立重放。

目标是在两个工况族和第6节九场景下都扩展可用贫燃范围。每个配对场景要求 `phi_safe_baseline - phi_safe_design >=0.05` 且相对下降>=15%；两者都要满足。若基准phi_safe在扫描范围外而删失，不能给出确定改善值，须报告收益上下界，且只有保守下界满足时才算达标。此目标尚未经参考解证明可达。

以下约束必须在两工况族的锚点、共同验证稳定区间以及设计最低稳定点检查：

- 相同phi/场景下基准与设计的总空气、燃料流量和入口焓一致；不能增加额外空气、降低热负荷或篡改燃料喷孔来换安全裕度。最低设计phi处若基准已经FB，不要求强行保持一个不存在的稳态基准，而与本题共同安全锚点约束和绝对上限一起检查。
- 共同安全点上的供气总压降<=1.10倍基准。总压降是同一取压定义的质量流量加权总压损失，不能把静压恢复当作供气节省。
- 氢燃尽率>=99%，新设计出口NOx<=max(1.10倍相同安全工况基准,基准+2 ppm)，且<=25 ppmvd@15%O2。设计新扩展区间无稳定基准处使用绝对25 ppm限值。氧修正、残氧接近空气时的失效和采样方式要披露。
- 共同安全点的唇部/预混管壁面热流q99<=1.10倍基准，热模型的金属峰温不高于基准+30 K；绝对温限按本题自设1200 K检查，并给材料/冷却适用性说明。规定Dirichlet壁温不能作为预测峰温证据；没有可验证固体热响应时相应约束记为未证实。
- `p_rms/p_mean<=0.01`，且相对相同安全基准不恶化超过10%。压力检查至少覆盖20 tau，不能将短统计窗或不可压模型无法解析的声学量直接填零。低马赫模型需独立声学/可压缩核查支撑此项。

新设计最低稳定点的压降与热流上限相对于同一工况族锚点基准检查，燃尽/NOx/温限/压力用上述绝对上限。中间共同区间逐phi配对；因失稳不能配对时不能删除该点冒充完整覆盖。

## 6. 不确定性与工程决定

每个工况族固定9场景：nominal；air及H2共同乘0.97/1.03以保持给定phi；air入口温度±15 K；相同冷却系统的环境/冷却剂温度±50 K；节流喉径制造偏差±0.10 mm。其余名义值不变。公差同时施加于相应基准与候选；2种结构×2工况族×9场景共36条真实边界搜索记录，每条保留稳定分支和事件证据。它们是自设确定性压力测试，不是95%联合置信保证。由共同温度/压力边界重新计算支路流量，禁止只在后处理里缩放已有解。

另分析机理、湍流闭合、入流涨落、未测壁温、喷孔不均、网格与统计窗的不确定性。HYLON Phase 3的1/3/6 bar输入只用于一个明确标为外推的风险检查，不能因常压模型过关就宣布高压回火边界或NOx已被验证。
