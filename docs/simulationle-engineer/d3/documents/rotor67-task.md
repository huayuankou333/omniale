# NASA Rotor 67：多工况压气机叶型改造

## 1. 工程委托

某工业轴流压缩部件研发团队计划更新Rotor67衍生的22叶片跨声速转子。机匣、叶数、接口与转速制度已经确定，希望通过重新制造叶片，提高部分负荷到超设计转速的加权效率，同时扩大稳定工作范围，控制进口畸变、叶隙增长、表面粗糙化与制造偏差造成的性能退化。没有授权靠缩小名义叶隙、增设导叶、机匣处理或主动控制获得收益。

你负责从公开实验验证出发，交付至少三套实质不同的三维叶型，比较后锁定一套，完成鲁棒气动、动态稳定和结构检查，给出accept、reject或unresolved及其证据。无法完成或无法量化误差时用unresolved；拒绝某候选不等于证明全部设计空间无解。本题是原创研究委托，工程阈值是本题合同，不代表NASA、真实业主或适航认证要求。难度不因任何未来模型时间预算而降低。

## 2. 几何、数据与两个基准对象

NASA TP2879的设计转速为16043 rpm，22叶片；表I为设计转速运行形态。HiOCFD提供的是单个**流体流道实体**，原始STEP长度单位毫米；不是叶片金属实体。几何与边界检查见geometry/README.md。叶片金属重建、体网格、真实叶隙和周期性都属于解题工作。

必须分别建立：

1. **NASA验证模型**：用PE/NS两组各自入口实测径向总压/总温、流角和NASA测量站，在指定修正质量流量下比较出口测量；PE可校准，NS作为公开程序性留出。保留HiOCFD与NASA表I/II之间的坐标、间隙、圆角和制造差异，不能宣称CAD自动等于实验实物。
2. **D3工程基准**：以冻结源几何为名义运行几何，统一工程入口、气体、材料、根部边界与使命工况。工程扩展数据未经NASA实验验证，不可把设计转速验证自动外推到所有转速、畸变和改造。

坐标为右手系，z沿下游；旋向须按叶型及绝对/相对速度审计。报告LA的AP坐标要加2.159cm转换至几何z；“10% span”等从叶尖起且沿设计流面，不是简单几何展高。表III/IV计算平均的九个站和面积排除了部分端壁区；不能把全环面积平均或流量平均总压直接当NASA能量平均总压。绝对总量用于性能，禁止用旋转相对总温/总压混算效率。

## 3. 实验验证与模型锁定

对PE、NS分别完成真实三维可压缩黏性旋转流道计算。转子/轮毂旋转，机匣在惯性系静止；转动坐标系中机匣速度不是零。使用原始真实间隙，不能用无间隙CAD替代主验证。单流道质量流量乘22后才与整转子比较。

PE指定mc=34.573kg/s；NS=32.305kg/s；两者Nc=16043rpm。这些流量是工况条件，不是独立预测成绩。入口总量/方向和出口静压闭合，不要同时强制所有实测静压与目标流量。通过出口压力调节到目标流量后对出口性能作真正预测。边界延伸及非反射/径向平衡处理必须做敏感性分析。

PE允许选择湍流、转捩、入口扰动和离散设置；提交参数/脚本哈希后锁定，NS不得按输出重新调损失系数。若修正程序错误，保留迭代、重新锁定并重报两组。所有目标公开，不称秘密盲测。78项表格目标见validation/targets.csv，其中39项NS留出须按协议通过。NASA原始激光ASCII未取得；报告中的局部马赫数/流角曲线可用于带人工数字化误差的诊断，必须记录页码、像素/曲线和不确定度，不能制造原始实验时序。

至少提取NS、PE在10%、30%、70%标称流面上的相对马赫数/激波/尾迹图，按表VI真实位置取样，比较论文相应图。没有独立数字化确认的曲线仅作定性诊断，不纳入假精确误差分。

## 4. 三套改造与多工况地图

按inputs/design_constraints.json提出A/B/C三套不同的负荷分配/弯掠/扭转/厚度方案，说明弱化激波、泄漏涡/激波干涉、端区分离与扩压损失之间的权衡。保留根部接口及过渡；三套不能只改命名或颜色。提交可制造金属CAD和参数化脚本。

完成required_nominal_runs.csv的60个配对工况：基准+A/B/C，Nc为60/80/90/100/105%，每速三种q。修正流量mc=33.25*(Nc/16043)*q，q=0.98/1.00/1.03；权重见mission_points.csv。这些是原创客户工作点，尚无可行性预判。若某点不稳定，诚实标记并证明失稳，不能改q、转速或偷偷替换成峰效点。锁定selected为A/B/C之一后再进入确认；若生成D或继续改形，按新候选重做相关矩阵。

对基准/selected五个转速各建一条完整地图，共10个campaign，每条至少15个实际出口压力点，自阻塞附近推进至稳定边界；每点都有流量、能量平均及流量平均性能、轴功率、出口畸变、泄漏量、熵增及收敛证据。适应性细化激波突变/分离/失稳区域。使命点与地图点完全相同时可共享原始计算并明示alias；不能重复计算完成次数或以代理预测充当CFD。

名义加权效率增益的保守下界≥0.005（0.5个百分点），任一使命点效率变化下界≥-0.002；压比相对基准0.99–1.02，功率比≤1.02，阻塞能力比0.99–1.02。误差必须小于所声称收益，定义见acceptance_targets.json。不得通过改变平均方法、比较不同流量、丢弃高损失端区或增大未报轴功率获取“改进”。

## 5. 动态失稳与进口畸变

NASA NS是已测的近失速稳态点，不是动态失速标签。单流道RANS不收敛、残差振荡、背压极限均不能单独证明旋转失速。动态判据必须使用全周22叶片，避免扇区周期性抑制低周向模态。

对10条地图，每条在边界附近至少三个真实背压状态、三个固定扰动种子1103/2207/3301作全周非定常括区。用20转过渡、至少60转分析，未能分离慢漂移时延至200转并报告未判定。保存全周机匣压力、近叶尖轴向速度、逐叶载荷和总流量；按周向模态、传播速度、低频能量增长和多种子重复性识别稳定/失稳，详见协议。得到保守失速裕度区间；均匀入口下相对基准增益下界≥2个百分点。说明这是给定边界/出口模型的转子稳定边界；没有容腔/管道系统就不能声称预测了整机喘振。

完成required_distorted_runs.csv的24个全周非定常使命点：基准/selected，N80/N100/N105，L98/L100，2%/4%固定惯性系总压亏损，120°扇区、5°余弦过渡、保持环向平均总压不变。不得让畸变随转子共同旋转或用单通道的时变总压代替空间非均匀作用。另对两个畸变强度、三个转速、两种设计各完成全周动态稳定括区（12个附加campaign，单独登记）。畸变效率变化下界≥-0.003，稳定裕度不得退化。完整波形定义见工具与协议；幅度不是DC60指标。

## 6. 制造与运行鲁棒性

32个角点由叶隙偏移、展向加窗安装角误差、厚度偏差、等效砂粒粗糙度ks和入口Tu五维组合；基准/selected在N80/N100/N105与三个负荷共576个真实三维工况。粗糙度ks不是Ra/RMS，不能把论文表面光洁度直接当砂粒高度。变形/偏差后出现负厚度、接触、失稳即记录失败，不能剪裁至可行或补值。

按robustness.json作至少64个初始实际评估+32个适应性实际评估的连续不利搜索，联合转速、q与畸变幅度/扇区。用代理加速可以，但代理必须有独立误差/外推检查；6个新不利点独立确认，其中3个用全周高保真复核。计算有限样本不能证明全局最优或全域绝对安全。稳健效率/损失/功率/稳定边界的误差界必须联合传播，不能把单点数值收敛等同于鲁棒。

## 7. 叶片金属结构、冷态反求与振动

重建真实金属叶片，不得对流体流道实体赋予钛密度。材料与根部约束按material_and_structure.json，是原创等效叶片模型；禁止声称NASA真实材料或轮盘接头被验证。

将冻结运行外形作为N100目标，反求与之相容的冷态形状，验证离心/气动变形后外形误差≤0.04mm。随后检查60–110%转速的变形、热应变和叶隙，避免对热态几何重复叠加离心伸长。主矩阵可先用规定运行形状筛选，但最终selected须给冷/热形态一致性修正与误差影响。

对基准及selected的名义最坏、畸变最坏、鲁棒最坏载荷和110%超速，映射同一时刻压力/黏性场，计入离心与两档温度。真实E、密度、厚度；强度安全系数≥1.5，运行最小叶隙≥0.4mm；质量与极惯量相对基准各≤3%。夹持奇异点、局部根部过渡、映射平衡及网格收敛均要报告，不能删峰值后宣称合格。

输出前12阶预应力模态与Campbell图。工作转速与轴频1–6阶及叶通过阶22间隔≥10%，或完成受迫响应并通过所给疲劳代理。首3阶模态在N80/N100/N105、L98下，对22个行波相位角计算气动功/阻尼并给下界；无独立证据不能声称无颤振。根部理想化、缺盘耦合/失谐、材料疲劳数据缺失须保留适用范围；这不是寿命或适航认证。
