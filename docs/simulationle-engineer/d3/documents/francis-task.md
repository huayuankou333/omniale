# Francis-99 D3：变负荷导叶轨迹与压力风险优化

你是一名受委托的水轮机仿真工程师。某电站希望在现有 Francis 机组由最佳效率点 BEP 向部分负荷 PL 过渡时降低水力压力风险。请恢复可执行数值模型，用公开实验约束稳态基线，再设计并验证可实施的导叶关闭轨迹。交付目标是可复核的工程项目和计算证据。

## 交付与实验目标

1. 从 `/inputs/raw` 的 Workshop 2 原始资料、`/inputs/geometry_mesh` 的原始几何/网格和官方示例建立仿真工程。核对坐标系、转动方向、运行点、边界条件、接口、物性与量纲。原始示例不是保证可运行的工程；你需要自行检查和恢复。允许修改求解器、重构网格或采用其他可获得的工具。
2. 对 BEP、PL 建立稳态实验对照：报告流量、水头、转速、压力测点统计、尾水管 PIV 分布及其不确定性。解释测量截面、压力参考、周期扇区与整周流量口径，检查质量守恒、网格质量和数值收敛。
3. 建立 BEP→PL 的真实非定常数值模型。请为导叶运动、转子与定子相互作用、尾水管非轴对称不稳定性选择有依据的空间与时间模型。稳态混合平面可以用于初始化；分立稳态结果拼接、只改变入口流量或只做数据拟合，不能冒充动导叶瞬态验证。若提出近似模型，应标明证据等级，并用独立、更高保真计算检验关键结论。
4. 构造下述基准轨迹并优化。基准和候选必须使用相同初场、物理模型、边界条件、转速与数值精度。导叶运动、压力/流量边界及水力系统应一致；不能同时过度指定压力、流量和导叶运动。引水系统参数未被公开资料充分约束时，请给出明确假设与敏感性分析，不要将假设称为实测值。
5. 将代码、网格、可编辑工程、完整运行命令、实际生成的场/测点序列、环境版本和资源使用写入 `/workspace/submission`。提供 `run.sh`、`report.md`、`metrics.json`、`trajectory.csv`、`evidence/`、`logs/`。若未完成，明确列出已验证部分、未完成部分和阻塞证据。不得伪造运行记录或将拟议结果称为计算结果。

## 本次试验冻结的设计条件

以下执行器条件是本题人为规定的设计要求，不是 Francis-99 实测调速器参数：

- 导叶从 9.84° 关闭到 6.72°，过渡时间固定为 10 s；两端角速度为零。
- 角度单调不增，角速度绝对值 ≤ 0.5°/s，角加速度绝对值 ≤ 0.2°/s²。
- `trajectory.csv` 的列为 `time_s,angle_deg,velocity_deg_s`；结点间按三次 Hermite 曲线插值，曲线为 C1，加速度可以在结点处跳变；本次未规定 jerk 限值。结点时间严格递增，首末时间为 0、10 s。
- 基准曲线为 α(t)=9.84+(6.72−9.84)(3s²−2s³)，s=t/10。该曲线满足上述运动学约束。不得修改基准曲线来增加候选改善幅度。
- 稳定 BEP 初场和共同运行转速应从原始报告恢复。稳态与瞬态的具体水力系统设定必须记录，且在基准和候选中一致。

主要比较量是两个尾水管测点在固定 t∈[0,10] s 内的压力变化：

`J = sqrt((Var_t[p_DT5] + Var_t[p_DT6])/2) / (rho*g*H_BEP)`。

时间方差按实际时间积分，各点分别减去该区间的时间均值；它同时包含慢变压力与脉动。另报告完整原始序列、RMS、峰峰值、频谱及带限能量，以便人工判断改善是否有工程意义。均匀输出测点序列应至少达到 1 kHz，并用时间步/采样敏感性说明可解析频段；单纯插值不能增加求解器的有效时间分辨率。

同时报告并检查：候选转轮输出能量 ≥ 基准的 98%；候选最低绝对压力不得低于基准；候选转轮峰值绝对力矩不得高于基准；相同过渡时间与最终工况必须满足。以上是本题规定的设计约束，尚未经过参考解校准。若无法可靠确定绝对压力基准，应明确说明，不能宣称已经验证汽蚀裕度。

压力采样率为 5 kHz，文本时间戳只保留到 0.001 s，不能直接用相邻文本时间戳推断采样间隔。PIV 测点坐标比速度列多一个点，匹配时必须审计列名与点位，禁止悄悄补造。数据许可、数值条件和测点定义以原始报告和元数据为准。
