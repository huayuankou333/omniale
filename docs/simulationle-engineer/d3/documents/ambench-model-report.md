# IN718 裸板热模型校准、pad 迁移与扫描设计报告

本轮使用 NIST AMB2022-03 公开数据（DOI 10.18434/mds2-2716 与 10.18434/mds2-2718）完成了输入审计、原始热像分块处理、三维瞬态焓法求解、单道/多道计算、九场景成对压力测试和合法命令生成。所有计算在远端 `/workspace/submission` 执行；入口为 `run_all.sh`。

扫描文件实际为 `/XYPT/Ypad/{X,Y,P,T}`，Ypad 共 25,499 行、24 个开光段（中央 pad 23 段加 Leg10），Xpad 为 117,999 行、47 个开光段。XYPT 的 T 是位掩码，未发现 `digital_rate` 属性，按 Yeung 等 2021 的 10 μs 数字指令约定取 `dt=1e-5 s`。原始最后一行也计入保持时窗。D4σ 作为直径，源项标准差使用 `sigma=D4σ/4`，并以离散体积归一化保证 `∫q dV=ηP`。

截面 Excel 共 232 条记录，单道每工况三次重复、每次有 P3/P4 两个切片；pad 的逐切片记录不是独立试验重复。本报告对单道按工况聚合，不把切片数当作 n。测量对照保存在 `measured_single_track.csv`，热学表中的 TTAM/TSCR/TLCR 来自公开 challenge results PDF。

主模型是三维 Cartesian 显式有限体积能量方程，温变 `k(T)`、`cp(T)`、潜热焓区间 1533.15–1609.15 K、初温 296.65 K、顶面/侧面 Robin+辐射边界和归一化移动 Gaussian 源。锁定参数为 `eta=0.80`、`absdepth=0.03 mm`、`kscale=0.50`；最多三个全局可校准量，来源和插值范围见 `material_properties.json` 与 `calibration_lock.json`。校准历史见 `calibration_history.csv`。选择依据是四个规定校准工况的粗网格灵敏度扫描，未使用逐工况吸收率。

这组结果明确未达到任务的留出几何、热学和能量闭合门槛；尤其模型形式和网格仍不足以支撑工艺放行。pad 基准在 0.2 mm、20×10 μs 聚合下 `J=0.8816`，最终候选 `J=0.8817`；九场景成对计算在 0.2 mm、100×10 μs 聚合下已完成，nominal 最坏 J 从 0.8092 降至 0.8037，改善约 0.67%，低于 10% 要求。候选保留完整原始 25,499 行并插入 120 行、每处 0.2 ms 停顿；`validate_command.py` 已返回 `valid=true`，总时长比为 1.0047、入射能量 nominal 保持不变。

原始热像审计保存了 `Line_0_1_*` 和 `Y_pad1_*` 中间数组与 `raw_thermography_audit.json`。温标采用数据集 `a=0.9655,b=197.2,c=43920000` 的回归形式、DL<100 掩码和 ε=0.5；这只是表观测量处理，未将 ε 当激光吸收率。测得 Y-pad PTAM 参考为全分布均值 1.04 ms、中位数 1.24 ms，>0.5 ms 均值 1.28 ms、中位数 1.31 ms；模拟 PTAM 分布保存在 `Ypad_baseline_roi_ptam_s.npy` 和 `final_power_balanced_roi_ptam_s.npy`。

收敛运行覆盖单道 0.2/0.15/0.1 mm 与 5/3/2 行时间聚合，以及 pad 0.2 mm 下 100/40/20 行聚合；结果在 `convergence_results.json`。单道深度为 0、53.5、45.0 μm，pad 的 J 为 0.809、0.602、0.882，关键量变化明显超过 5%，因此精化结果只作为数值证据，不能宣称收敛通过。没有执行流动熔池高保真交叉求解，详见 `limitations.md`。

最终工程决策：拒绝自动放行当前扫描设计；先修复能量守恒和高温边界离散，再用含流动/蒸发的局部高保真模型和在线热像重复试验复验。测量位置应覆盖中央 pad 轨迹、odd/even 轨迹和单道中心，采样至少 30 kfps、三次重复；深度/宽度、TTAM、TSCR/TLCR 和 PTAM 的通过条件按任务中预注册阈值执行。
