# 评估协议

## 1. 证据先于分数

`rubric.json` 规定100分。专家按可重放的实际完成证据给分；自动工具不输出总分，也不认证物理正确性。计划、合成演示数据、抄写目标、可执行程序的帮助信息都不是求解证据。分开报告交付完整率、实验验证、数值可信度、工程约束、候选释放结果与专家评分。

## 2. 实验幅值

全部30项公开。校准限B1/B4；18项锁定验证限B2/B3/B5。冻结参数后不能按每个留出波况重新调 Cd、阻尼或载荷倍率。若修改参数，记录新迭代，重新报告全部验证；不得只报最终挑选的点。

对每项：E=|X_pred-X_exp|，U_val=sqrt(U_exp²+U_num,95²)。差频项要求 E≤U_val 且 E/X_exp≤25%；一阶项≤15%。U_num,95/X_exp 分别不得超过15%/10%。论文 U_exp 保持原文总不确定度定义，其与求解者95%数值不确定度组合是本题预先规定的工程判断规则，不声称严格统计独立或实验区间已重新标定。必要时报告相关性和保守包络的敏感性。所有18项同时合格才记“锁定幅值验证通过”。未通过时仍按已完成工作给分。

仿真的波幅应距规定值≤5%，一阶反射≤5%。差频自由波污染幅值与 a1*a2/L 的比≤0.20，并对剩余污染传播到载荷的不确定度。不得用“波高正常”替代差频污染诊断。保留至少4个完整稳定重复周期；相邻整周期组的载荷幅值变化≤3%。窗长、起点、频率与实际采样均须记录。工具 `harmonics.py` 只示范规范的最小二乘复幅值提取；它不判定仿真稳定或物理有效。

## 3. 海况统计与比较

分析区间为 t∈[1200,12000) s；全尺度输出步长≤0.1 s。PSD 用一致的 Welch 单边密度、600 s Hann窗口、50%重叠、逐段去均值；以实际离散频点积分。LF=[0.005,0.05) Hz，WF=[0.05,0.30] Hz，不重复边界。水平 LF RMS=sqrt(integral(Sxx+Syy))，纵摇 LF RMS 和垂荡 WF RMS同理。角度内部用rad，报告注明转为度。另报告全记录均值/漂移，不用高通掩盖大静偏移。

水平偏移=√(x²+y²)，从未扰动原点计，p99 用线性插值样本分位数。纵摇和各线张力峰值来自原始有效区间样本，不是PSD或RMS换算的“峰值”。这些是规定3h记录的样本极值，不是50年设计极值。补充独立种子/区间以支持决策。

张力DEL：按完整反转点序列雨流计数，半循环权重0.5，范围ΔT，不是幅值；DEL=(Σ n_i ΔT_i³/(1 Hz×10800 s))^(1/3)。每种子先取三根线DEL最大值，再对基准/候选配对。报告每条线，不能只取总体平均。

对每个海况/波向/推力组及每项正值指标，r_i=metric_candidate_i/metric_baseline_i；配对同一波组件文件与随机种子。基准指标≤1e-12（采用该指标SI单位）时标记不可辨识并给出绝对量评价，不能除零或计成100%收益。以 l_i=ln(r_i)，单侧95%上界 R95=exp(mean(l)+t_0.95,n-1*std(l,ddof=1)/sqrt(n))。这采用独立种子近似，必须检查重尾/离群；不成立时增加种子并做保守配对自助法与上述界的较大者。角点3种子不能自动产生稳健统计结论。

每项比值还加入模型、离散、插值和尺度外推误差的保守上界：R_release=R95+U_model_ratio+U_num_ratio+U_scale_ratio。相关误差可在有明确配对协方差证据时使用更紧的传播；不得简单假定全部抵消。所有组满足0.80（水平LF）、0.80（纵摇LF）、0.90（最坏线DEL）、1.05（垂荡WF）、1.05（最坏线峰值）才允许声称规定域内改造合格。绝对峰值/偏移也需满足合同，输出其不确定度与余量。

## 4. 高保真交叉验证与鲁棒域

运动CFD与工程模型比较：静平衡、自由衰减周期、衰减包络、低频运动谱、载荷与张力时序。自由衰减周期偏差≤5%，等效阻尼偏差≤20%；动态段LF/WF RMS、张力DEL和样本峰值偏差≤15%。不能只比较相近均值。若不满足，先更新误差界/模型，不能把校准误差藏入设计收益。

32角点不是连续域保证。连续搜索须包括谱峰穿越共振、共振频率随附件改变、黏性残余变化和系泊非线性。以已验证的残余模型作筛选，用高保真复核至少两个新增不利点。可报告保守经验鲁棒结论，但未提供连续域误差证据时状态应为unresolved。不得声称有限样本证明数学上全域最优。

## 5. 数值与结构

空间/时间分离细化至少3级；报告原始指标及实际网格尺寸/时间步、GCI或等价误差。至少对B1/B4、候选最坏固定波、最坏运动工况研究。域边界、波吸收、线段、结构网格和压力映射分别检查。压力/黏性积分与控制体动量平衡差≤5%；累计质量误差相对于时间积分绝对入流量≤0.5%，另列相对静水体积误差避免零通量陷阱。

附件结构使用净厚度、实际开孔、接头边界和载荷路径；载荷来自相应波况的同一时刻空间场。屈服、屈曲、安装、腐蚀/检修、自由液面稳性及质量均为硬约束。真实材料刚度不可被调高以减少位移。链疲劳DEL和附件热点DEL是比较代理，本题不提供认证级S-N寿命模型。

## 6. 最终状态

- accept：实验/数值/模型/结构证据充分，完整规定域满足全部目标且有误差余量。
- reject：足够证据表明所推荐候选不满足一项或多项约束，清楚界定已检验的设计与范围。并不等于整个设计空间无解。
- unresolved：计算未完成、验证不通过、误差过大、资料不足或鲁棒证据不足。

高质量且有证据的拒绝可以得到高分。参考解空缺不阻止基于物理闭合、实验对照和工程验收规则进行暂定评分；没有专家复核时不发布认证式结论。
