# 验证与工程验收协议

## 1. 定义、平均与边界

Nc=N/sqrt(Tt_in/Tref)，mc=mdot*sqrt(Tt_in/Tref)/(Pt_in/Pref)。工程均匀入口的Pt/Tt为指定绝对总量；非均匀入口采用全环质量流量权重总温与以下能量平均总压，不得对候选使用不同校正。扇区流量需换算整转子。气体gamma=1.4，R=287.05。

NASA平均用表IV九条带的w_i=rho_i*Vz_i*Area_i。Pbar/Pref=[sum(w*(Pt/Pref)^((gamma-1)/gamma))/sum(w)]^(gamma/(gamma-1))；Tbar=sum(w*Tt)/sum(w)。PR=Pbar2/Pbar1，TR=Tbar2/Tbar1，eta=(PR^((gamma-1)/gamma)-1)/(TR-1)。同时输出全环质量流量平均总压、能量平均总压、总温、轴功率。不要混合不同出口定义。工程性能统一用全环积分，NASA历史九带平均只用于与该实验比较。

NASA壁静压仅为边界检查，不能同时固定Pt、Tt、速度、Ps的过定边界。实际求解流量距两实验条件≤0.3%。该流量已被条件化，不计独立预测分。

## 2. 实验资格

表targets.csv的容差是本题工程验收带，不是NASA发表的95%测量区间。对每项要求abs(pred-target)+U_num95+U_geometry95≤tolerance_abs。不能扩大不确定度带换通过；缺项或缺界即未取得资格。NS共39项同时通过才记公共锁定验证通过。PE也须给全部结果，整体PR/TR/eta在表定带内。

NASA局部LA图作补充：至少PE/NS×三个标称流面，提取实际测点及误差条、坐标和纸面数字化误差；对二维测得速度对应的相对马赫数与完整3D定义分开比较。缺原始ASCII不自动失败，但伪造原始数据或把图上误差条改成任意统一误差不接受。程序性留出参数锁不可在看到NS结果后偷偷改；所有迭代可追溯。

## 3. 数值资格与守恒

流体网格须真实解析两侧边界层、尖隙、前后缘及激波/泄漏涡。目标y+≤1覆盖至少95%叶片及尖隙相关壁面，最大≤5；使用壁模时必须提出并验证替代误差控制，不能把低Re湍流模型与粗壁面网格混用而无说明。叶隙跨高至少20单元作为初始要求，是否足够仍由独立加密判断。单元数不是质量证书。

分别进行三层空间、三层时间步和独立轴向域/出口敏感性；至少覆盖PE、NS、selected N100/L98、名义最坏、畸变最坏和一个鲁棒不利点。网格代表尺度比≥1.3，保持拓扑/边界层策略可比；不在非单调序列强套Richardson阶数。NS/最坏附加第二种闭合（如SA/SST）比较；模型分歧须进入设计差值误差预算。

稳态监控至少2000后续迭代的质量、转矩、PR、eta，不仅残差。相对质量不闭合≤0.1%；轴转矩×角速度与绝对总焓通量差（含非定常储能及热流）≤1%；叶面力矩与角动量通量含壁面贡献差≤1%。非定常在完整分析窗口积分并列储能；旋转坐标中的伪功项须转换清楚。输出原始进出通量而不是只给残差。

## 4. 动态稳定判定

扰动在全周入口初始5转施加，随后撤去：deltaVz/Vz=0.002*sum(m=1..5 cos(m*theta+phi_m))/sqrt(5)，phi由PCG64指定seed产生；不要持续强迫后把强迫响应称自由失稳。保持平均流量扰动零均值。出口压力单调扫描与反向扫描均需记录迟滞。

每一边界用至少一个稳定态和一个持续增长/饱和非均匀旋转态括住，出口压力括区宽≤0.2%Pref；至少三个压力状态与三个种子。至少22个等间距机匣探针，推荐88个；同时输出入口、前缘附近、后缘后两个轴向截面。对p与Vz作周向Fourier m=1..5，时间采样≥100步/叶通过周期，基于三层dt证明相位和增长率收敛。

稳定需要撤扰后后60转的非叶通过低频模态包络无持续增长，后半段与前半段均方根变化≤5%，质量/压比无单调漂移，各seed一致。动态失稳需至少两个互相支持的现象：非轴对称m=1..5模态增长并形成传播单元、持续局部回流、显著低频载荷/流量振荡，且对dt/域/初始噪声稳健。量化增长率置信区间与传播速度；阈值扫描如0.2%/0.5%/1%Pt用于敏感性，不能把任一任意阈值当普适物理定义。未形成可靠稳定/失稳分离时为unresolved，而非假定NS=最后收敛点。

SM=100*((PR_NS/mc_NS)/(PR_OP/mc_OP)-1)，OP=L100同速/同入口。用括区与误差传播得到区间，比较selected最保守端与baseline最不利端；均匀入口增益≥2个百分点，畸变不退化。该量是本任务稳定裕度代理，不能称为系统喘振裕度实测值。对N100基准还要进行至少一种不同湍流/尺度解析策略的全周交叉检查。

## 5. 畸变及配对收益

在惯性系theta0=0处设置亏损扇区，总宽120°（连续搜索60–120°），边缘各5°余弦过渡。D=1在扇区核心，边缘半余弦，外部0。Pt(theta)=Pbar*(1-d*(D(theta)-mean(D)))，完整环周平均保持Pbar。d=.02或.04是本题峰谷尺度，不称DC60。密度/流量重分配是求解结果。Tt均匀、名义无入口旋流。保持畸变空间固定，报告逐叶通过低压扇区的时间相位。

所有基准/候选在相同Nc、mc、入口场、误差向量下配对。Delta_eta下界=Delta_eta-U_delta95，U必须含数值、时间采样、模型闭合、几何/制造及尺度/边界影响；若能证明配对相关性可采用协方差，否则用保守相加。使命加权目标sum(weight*Delta_eta)≥0.005下界；任何点不满足合同即不能accept。设计选择后的确认使用重新冻结的设置与新扰动种子，不能只报最优抽样。

## 6. 结构与可制造性

流体实体与金属实体分开验收。冷态几何、离心/温度和映射载荷具有一致参考；根部夹持理想化要有敏感性。压力映射总力/矩误差≤1%，结构反力/外力含体力不闭合≤0.5%。三层金属网格独立收敛应力、位移、模态；局部奇异峰必须保留并给可解释的有限区域/结构应力度量，不可任意删除。屈服、给定Goodman代理、间隙、质量和模态/气弹条件逐项验收。

材料及疲劳参数是任务输入，均不得提升以使设计通过。没有轮盘/根部真实图纸、试验疲劳曲线或机匣热伸长数据，因此结论限于约定等效部件，不出寿命/适航认证。

## 7. 评分与运行协议

rubric.json明确区分“真实三维求解执行”与“实验验证合格”，前者失败才触发30分上限；真实但不准确的三维结果按具体项扣分及实验验证59分上限处理。至少80分且全部证据门槛通过才算完整工程评估。高质量reject可以得高分，unresolved不等于不可行证明。

资源上限由独立评测协议设定，不由模型改写题目。启动前必须检查内核cgroup的cpu.max/memory.max或实际cpuset，不能只读取systemd配置。若失效，标记算力不可比；已有输出仍可评分，不静默续跑/改记录。本包只建题，不启动模型、不生成参考解。
