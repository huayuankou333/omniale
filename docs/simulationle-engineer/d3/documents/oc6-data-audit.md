## 容易导致错误结论的细节

1. 官方“最终数据”说明中的时序已经 Froude 放大到全尺度，并加入淡水998.6→海水1025 kg/m³ 密度比例，时间步0.1 s。若未来取得该数据，不得再次乘50。
2. 力按 λ³ρ比、矩按 λ⁴ρ比、时间按√λ 缩尺；模型黏性不服从 Froude 相似，另列 Reynolds 外推误差。
3. 说明记录配置 J 的 starboard 载荷无效、应使用 K；P/Q 使用修复后的重复试验。本版没有这些原始文件，不能伪造“已修复”记录。
4. 三柱模型没有中央主柱/撑杆/系泊。三柱实验水深换算250 m；工程平台水深200 m。各自的系数不得混用。
5. 总矩参考点已是 SWL 全局原点；不能再按力传感器力臂重复平移。斜浪不能使用头浪镜像求和。
6. Table 7 包含反射/差频自由波引入的总不确定度。不能用 Table 3 较小的不确定度冒充完整区间。正文仍保留原中心值，未将 Table 5/6 的试探修正值替代它们。
7. Table 7 只有幅值。不要将幅值当实数 QTF 并假设零相位；Newman 近似不能自动补出所有离对角和交叉方向项。
8. 包内 `.12d` 为 9576 行、9列、仅0°/0°、六自由度。周期2.0944–25.133 s；原版0°系数不能证明本题斜浪与短峰海况适用。
9. `.hst` 不等于包含全系统重力与系泊的最终恢复矩阵；错误叠加/遗漏 CG 项会产生虚假不稳定。r-test 的结构质量/填充压载分拆与本题已含压载的质量不相同。
10. OC4 文档对细撑杆使用人为放大刚度以匹配基准。工程附件必须使用真实钢材。原船体全尺度结构重新认证不在本题的可验证声明内。

## 原创输入与实测数据的分界

海况 S1–S4、给定推力、RNA点质量、三处排水舱理想化、制造边界、350 t预算、系泊4.5 MN限值、收益目标和评分阈值均为本题设计输入。它们不是来源论文的试验观测，不对应特定海域或回归期。输入几何构建和波谱生成不是参考解。
