# D1 / RLE-Bench Task08：一种移动底盘适配三种机械臂

设计一个麦克纳姆轮移动操作底盘，使用同一套底盘、轮组、电池和机械臂安装位置，分别承载 Panda、UR5e、xArm7。设计从零开始，公开工作区不提供完整底盘。

提交 `robot.xml` 和自包含 `controller.py`。评测器会替换预览机械臂为可信机械臂，控制器需从公开初态出发，调整底盘和机械臂，完成货架中全部 12 个公开目标的到达与保持。每个机械臂分别在 1 kg 和 2 kg 负载下测试。

必须保留标准轮组的 16 个独立被动滚子和规定命名，使用指定电池与安装接口。底盘需满足物理有效性、结构连接、全向移动、资源效率和稳定性要求。动态测试由独立评测器控制；货架任务由提交的控制器控制。评分对三种机械臂逐检查点取最差值。

控制器接口：`make_controller()` 返回具有 `reset(context, seed)` 与 `act(observation)` 的对象。动作以 50 Hz 返回全部执行器控制值；物理步长 0.002 秒，每个目标最多 30 秒。每个目标使用新控制器进程。

原始英文完整规格见同目录 `instruction.md`，包括坐标、命名、接口、资源目标和运行限制。英文原题是本地复现的权威规格；本文件仅为阅读摘要。

受测 agent 的输入只应包含 `instruction.md` 和 `workspace/`。父目录的官方源码、参考解、验收器及验证记录属于运营侧资料。
