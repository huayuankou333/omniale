# Task07 原题与 mixed-v1：公开评测协议

本页面展示 SimulationLE 于 2026-11-08 至 2026-11-09 完成的六组有效开发，不是论文已报告的模型成绩。

## 来源与改编

原题：RLE-Bench Task07 `bin-clearing`。固定仓库 https://github.com/RLE-Bench/RLE-Bench ，commit `c6bf572283b5453c0ee76eaa3054f23d691e433d`。269 个上游文件的 SHA-256 已核对。原生物理与验收流程保留，上游 4 h 开发预算改为本项目统一 2 h。

mixed-v1 是 SimulationLE 改编：长度 50.4 / 72 / 90 mm 的三类同色支架，质量随几何变化；三工位分别接收短、标准、长件。正确类别、单件、释放、速度低于 0.02 m/s 连续 0.5 s 才清出。错工位每零件 / 目的工位记一次错投，扣 0.05 reward，并失去完美回合奖励。错投可返工。

两版本独立开发，不将差分当作同一策略消融。Linux CPU、MuJoCo 无头运行，不需要 NVIDIA GPU。现有复现复用既有镜像层与 Harbor 依赖，未在全新机器验收一键安装。

- 提交或到时停止该开发容器全部进程，再收集冻结产物。提前结束不补时，不按成绩选择重跑。

## 独立验收

2×20 s smoke 检查加载、契约、稳定性与确定性，再运行 8×120 s 隐藏回合。每回合策略计算累计等待 360 s，单次 `act()` 挂起 30 s，仿真和渲染不计策略等待。独立验收外层 10800 s，不占开发 2 h。六份有效提交四 gate 均通过，无策略故障。

提交接口：`make_policy()` 返回 `reset(cell_spec, seed)` / `act(obs)` 对象；20 Hz 输出七关节位置目标与磁铁 0–255，RGB-D 为 10 Hz。policy seed 与隐藏堆料 seed 分离。

## 评分

令清出比例为 f。非线性清出函数：f≤0.6 时为 0.1f/0.6，否则为 0.1+0.9((f−0.6)/0.4)^3。评分吞吐 tp 为每分钟正确清出数；只有完整清空才使用完成时间作为分母，否则使用完整 120 s。

每回合 reward = clip[0,1](0.30×perfect + 0.35×clear_curve(f) + 0.20×min(tp/10,1) + 0.15×perfect×min(tp/15,1) − 0.03×掉落 − 0.05×损伤 − 0.05×撞箱 − 0.05×错投)。原题错投项为 0；perfect 要求完整清空、无掉落，混料版还要求无错投。

最终为八回合 reward 的平均值并应用 gate；本批无 gate 截断。展示分数乘以 100。原生逐回合与总分各自舍入，分解项可能有轻微舍入差异。清出率不等于工程分；未完成回合的 `makespan_s` 是最后清出时间，不是完成时间。展示吞吐使用 `episode_tp_ppm`，不使用旧 `throughput_ppm` 解释未完成回合。

每条件一次 agent 开发，8 隐藏回合不是 8 次 agent 独立开发。结果不支持稳定排名或跨开发方差结论。错投为事件计数，不是独立分类准确率样本。
