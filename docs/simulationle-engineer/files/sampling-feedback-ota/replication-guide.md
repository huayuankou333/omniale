# 增益 8／10 ns 采样反馈 OTA：原题与评测复现

原题：`sky130-fd-sampling-feedback-ota-gain8-settling10ns-noise1mv-pvt-mc`。
源码提交：`972f7cd7c95381134387b250edf18f3bd23bdd25`。
完整原题见 `TASK.md`，原始 24 个文件及 SHA256 见 `upstream/source_manifest.json`。

从原始空白 starter 自主设计晶体管级电路，唯一提交物为 `circuit.spi`：

```spice
.subckt sampling_feedback_ota vss iref vdd vinn vinp vocm voutn voutp
```

反馈电容 Cs=1 pF、Cf=125 fF，每端 CL=250 fF。要求 0.9 V 差分阶跃在 10 ns 内建立到 1%，相位裕度 ≥60°，输出积分噪声 ≤1 mVrms，输出共模与功耗达标；覆盖 30 点 PVT、3 个共模扰动工况及 20 个失配样本。

原始 `tests/verify.py` 和 `tests/utils.py` 不修改，直接调用原验收流程、指标解析与评分。Windows 适配只替换路径、进程和输出目录。标称功能门槛失败时全部 15 项为零；通过门槛后执行完整 143 次 ngspice。原题通过项比例、完整通过状态和标称门槛分别报告。

公共失配种子为 **51000**；最终 20 个种子为 **41000–41019**，两者不重叠。公共开发台完整保留；可通过工具在题目声明的工艺／电源／温度范围内扩展诊断。正式验收与参考解不向模型开放。

模型精确请求 `gpt-6-luna` 和 `gpt-6.1-sol`，运行前查询 `/models`，不替换模型。API 请求及服务返回的模型 ID 记录在每轮证据中，底层权重无法独立核验。

每模型一次独立上下文，串行 API，相同预算：36 次响应、32 次开发诊断、最多 160 次开发 ngspice、70,000 输出 token（含服务计入的推理）、单次 8,192 token、high 推理、两小时 agent 时间。与 Beta 实验预算上限相同。最终冻结后不根据正式分数修复模型电路。

项目内 Python、ngspice 和既有 LDO 目录中的同镜像 SKY130 PDK 被复用；不增加商业 EDA、原理图、版图或拓扑评分。上游为 Linux ngspice 46，本地为 Windows ngspice 47；必须先验证参考解，但不声称与上游逐位一致。
