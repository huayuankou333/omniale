# 直角齿轮箱：公开安装与执行契约复测

本轮是原题的 public-contract-v2 变体。公开有效轴段、轴半径和直径、轴分配启发式、Python 内置函数与导入白名单、执行时限，并提供公开静态构建／安装兼容检查。题目首轮输入包含完整补充契约。工具代码在 Agent 容器中只读挂载，不包含参考设计、目标几何、动力学或评分。

交付仍为自包含 final.py；独立验收仍使用未修改的原 CAD-bench 评分器。没有改为 STEP 交付，以便本轮只比较公开契约与诊断工具带来的效果。原来的运行 20261109T131216Z 完整保留。新模型从空白工作目录开始，不能读取旧设计、旧运行、参考解或正式验收器。

三模型共同上限：2 小时、36 回复、96 工具、98,304 累计输出 token、单次 32,768、medium reasoning、8 CPU／12 GiB、单终端 180 秒、最多 3 次正式快照。内部建模与静态检查不限于 3 次，受共同预算约束。仅评最终磁盘交付，不挑历史最佳，不由主机修复，不在开发中回传正式分数。

先复核公开检查工具中的通用执行函数与原版逐 AST 相同，确认参考静态构建与分轴通过、受限函数及导入能复现原执行限制，再以参考解独立评分确认原功能分保持 0.9771256766325821。随后冻结全部输入、检查工具、运行器和评分源码，分别评测三个模型一次。

报告分别保留原 overall_score、reward、build_success、是否进入正式运动仿真、运动指标、停止原因、预算用量、工具轨迹和冻结交付哈希。静态诊断通过不代表传动成功；单次试跑不构成稳定排名。
