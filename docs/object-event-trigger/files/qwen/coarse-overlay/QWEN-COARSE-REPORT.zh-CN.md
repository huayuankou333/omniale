日期：2026-11-24。模型：qwen3.8-omni-flash。

**辅助初评分缺少必要证据，尚不生效。**

**该数字是Qwen的粗粒度内容估计，不是原rubric的逐事件实测总分；正式分保持待评。**

## 如何得到分数

使用原70/20/10权重，但输入是单个自动judge的0/1/2/3/4档粗估计：P和R分别粗估触发正确比例和目标事件覆盖比例，除4后取调和平均作为F_estimate；R_estimate是有正例单元召回估计均值。困难负例两组等权得到N_estimate；边界仅评明显截断、拖尾和跨静音，得到B_coarse_estimate。空输出且有目标声音的单元F/R为0；确实无正例也无输出的单元不获免费分。工程不加分。

初评 = 70×0.5286 + 20×0.8214×0.8021 + 10×0.8214×0.7500 = **56.3**。

## 输入与局限

8个目标查询均使用完整同期原声视频和目标标记，视频上按程序实际起止实时点亮预测类别和编号；judge不用自行估计时间。开发A/B用原交付，封存H1/H2用独立重跑，A-Q1迁移结果不重复计入。原始音轨不改、候选身份不披露。

原生视频路径正确分辨静音、三声、五声，但三声一处起点偏差约0.7秒；显式音频路径也未通过定位且五声计为四声，两套失败记录完整保留。未通过的严格计时方案停止，没有放宽阈值重算为通过。本方案是另行登记的粗内容量表，复用首条路径已观察到的粗听音证据，不声称它通过事件定位或器具归属校准。

## Qwen提出的可复核内容问题

### A-Q1
**impact**：在视频的大部分时间里，可以听到勺子刮擦和敲击小金属锅内壁的声音。这些声音表现为清脆的、带有金属质感的撞击声。；画面：从视频开始到结束（约0秒至64秒），操作者持续用勺子在目标小金属锅内进行舀取动作，勺子与锅体发生多次可见的物理接触。例如，事件1 (IMPACT) 发生在视频开头，当时勺子首次接触锅底；事件21 (IMPACT) 发生在视频末尾，此时锅内食物已大部分被舀出，勺子仍在刮擦锅壁以收集剩余物。。
- 事件None；整个视频中，每次勺子敲击或刮擦锅体时；uncertain：音频中混合了勺子刮擦锅壁的摩擦声和偶尔更尖锐的敲击声。由于两种声音紧密相连且音色相似，难以精确区分每一次是纯粹的“impact”还是“friction”。；画面：视觉上，勺子的运动轨迹既有贴着锅壁的滑动（倾向于产生friction），也有抬起后落下敲击的动作（倾向于产生impact）。。
**friction**：可以听到持续的、较为柔和的金属刮擦声，这是勺子在内壁上滑动的结果。这种声音与更短促、响亮的撞击声有明显区别。；画面：当勺子紧贴着锅的内表面移动，试图将粘稠的绿色酱料刮下时，就发生了摩擦。例如，事件7 (FRICTION) 和事件19 (FRICTION) 都对应着勺子用力刮擦锅壁的动作。。
- 事件7；视频前段，约13-15秒处；false_positive：此处的声音听起来更像是一次清晰的敲击（impact），而非连续的刮擦（friction）。；画面：画面显示勺子似乎是点状地接触锅壁，而不是大面积地滑动。。
- 事件13；视频中段，约27-28秒处；false_positive：该时刻的声响特征更接近于一个孤立的撞击声。；画面：视觉上是勺子快速地从锅中提起并轻碰边缘的动作。。
- 事件15；视频中段，约30-31秒处；false_positive：声音短促而响亮，符合撞击的特征。；画面：动作是勺子向下按压并敲击锅底。。
- 事件18；视频中后段，约34-35秒处；false_positive：听到的是一声明显的“铛”声，是典型的金属撞击音。；画面：勺子以一个角度切入并碰到了锅的边缘。。
- 事件23；视频后段，约52-53秒处；false_positive：这个声音虽然有些拖长，但起始部分是一个非常明确的撞击声。；画面：勺子先是敲了一下锅，然后才开始有轻微的刮动。。
- 事件24；视频后段，约53-54秒处；false_positive：与事件23类似，这是一个由强撞击开始的复合声音。；画面：同样是先敲击后刮动的组合动作。。
- 事件28；视频结尾附近，约58-59秒处；false_positive：这是一次干净的敲击声，没有后续的刮擦尾音。；画面：勺子垂直地敲击了一下锅底。。

### A-Q2
**impact**：视频中有多次清晰的敲击声，但均来源于勺子刮擦或敲击上方的不锈钢容器，而非下方的目标黑色平底锅。；画面：在所有IMPACT事件（如Event 1至7）发生时，画面显示操作者正用勺子在上方倾斜的不锈钢锅中进行刮取和敲击，目标黑色平底锅静止在下方且未受到任何物体的直接撞击。。
- 事件1；视频前段，用勺子敲击/刮擦上方不锈钢锅；false_positive：金属敲击声；画面：接触点在上方不锈钢锅。
- 事件2；视频中段，用勺子敲击/刮擦上方不锈钢锅；false_positive：金属敲击声；画面：接触点在上方不锈钢锅。
**friction**：无针对目标的摩擦声。；画面：无相关动作。。

### B-Q1
**impact**：在视频开头（约1-5秒）和结尾部分（约26-27秒），可以听到明显的金属撞击声，对应锅体与水槽或盆壁的接触。中间清洗过程中也有零星的碰撞声。；画面：系统标记了8个Impact事件。Event 1 (1.7s), Event 2 (3.5s), Event 3 (4.7s) 对应初期将锅放入水中及初步刷洗时的磕碰；Event 9 (18.7s) 对应翻转锅体时；Event 11 (22.7s) 对应刷锅底时；Event 14 (25.7s) 和 Event 15 (26.7s) 对应最后阶段的动作。大部分标记与视觉上的硬物接触吻合。然而，在视频中段（如10-15秒左右）也存在锅具移动产生的轻微碰撞声，似乎未被完全覆盖或归类为摩擦。。
- 事件None；视频前段至中段过渡期；false_negative：存在间歇性的清脆敲击声；画面：锅体被提起或调整角度时发生的非持续性接触。
**friction**：全片贯穿着海绵擦拭锅体的沙沙声（湿摩擦）。特别是在Event 4 (5.0s), Event 5 (11.7s), Event 6 (13.7s), Event 8 (16.7s), Event 10 (20.7s), Event 12 (24.0s), Event 13 (25.7s), Event 16 (27.7s) 期间，这种声音非常清晰且连续。；画面：系统标记的Friction事件几乎完美覆盖了所有使用海绵用力擦洗锅体内壁和外底的过程。例如Event 5对应清洗外底，Event 10对应再次清洗内部。这些时刻画面中都有明确的相对运动和对应的摩擦音效。。

### B-Q2
**impact**：视频中可听到明显的敲击声（如事件1、3、6等），但声音来源是黑锅与金属水槽的碰撞，而非目标物体（白色洗涤盆）。；画面：画面中黑锅多次撞击不锈钢水槽底部或边缘。虽然系统标注了8次IMPACT事件，但这些事件的物理接触点均不在黄色框选定的“白色洗涤盆”上。。
- 事件1；视频开头 (t≈0.7s)，黑锅放入水中并触碰金属槽底；false_positive：沉闷的金属撞击声；画面：黑锅直接接触的是不锈钢水槽，未接触白色盆体。
- 事件2；视频前段 (t≈1.7s)，黑锅在清洗过程中晃动撞击；false_positive：清脆的硬物碰撞声；画面：接触对象为金属水槽壁。
- 事件3；视频前段 (t≈4.5s)，黑锅被提起后落下；false_positive：响亮的撞击声；画面：黑锅落回金属水槽中。
- 事件4；视频中段 (t≈16.0s)，黑锅倾斜刮擦/撞击；false_positive：混合了摩擦和撞击的声音；画面：主要接触面仍为金属水槽。
- 事件5；视频中段 (t≈18.5s)，黑锅再次撞击；false_positive：短促的敲击声；画面：黑锅与金属槽底的碰撞。
- 事件6；视频后段 (t≈22.5s)，用力刷洗时的撞击；false_positive：较重的撞击声；画面：动作发生在金属水槽内。
- 事件7；视频末尾 (t≈24.5s)，翻转黑锅时的磕碰；false_positive：连续的磕碰声；画面：黑锅边缘碰到金属槽沿。
- 事件8；视频末尾 (t≈25.5s)，最后的放置动作；false_positive：收尾的撞击声；画面：黑锅最终停留在金属水槽区域。
**friction**：存在持续的刷刷声（海绵擦拭声）和水流搅动声，但没有针对硬质塑料盆体的独特刮擦声。；画面：唯一的FRICTION标记（事件9, t≈27.5s）对应的是手拿着海绵在黑锅内壁进行擦洗的动作。接触双方是“海绵+黑锅”，完全未涉及“白色洗涤盆”。。
- 事件9；视频末尾 (t≈27.5s)，手持海绵擦洗黑锅内部；false_positive：湿润的多孔材料摩擦声；画面：摩擦发生在黑锅内部，目标是外部白盆，二者无接触。

### H1-Q1
**impact**：视频后半段存在明显的金属撞击声或硬物敲击水槽的声音，但视觉显示此时目标物体（锅底）正被海绵覆盖擦拭或被手握住，并未发生碰撞。声音源极可能是另一只手的手指敲击锅沿、或者背景中其他餐具的碰撞，而非目标本体的受击或主动撞击。；画面：在IMPACT事件触发期间（如Event 4, 5, 6），画面主要展示戴黄色手套的手用绿色海绵用力擦洗锅内壁。虽然动作剧烈，但没有观察到锅体与其他物体（如水槽壁、水龙头）发生物理接触或碰撞的瞬间。。
- 事件4；视频中后段，手部快速用力擦洗锅底时；false_positive：伴随擦洗动作出现的沉闷撞击声，更像是手腕/手掌拍打锅底的肉声，或者是海绵挤压水的声音，不符合典型的固体间Impact定义；且即便视为撞击，也是工具与目标的互动，非目标参与的外部碰撞。；画面：仅见海绵在锅内运动，无外部碰撞。。
- 事件5；同上，持续擦洗过程中；false_positive：持续的摩擦噪音中夹杂的峰值，归因于Impact缺乏明确的视觉碰撞支持。；画面：无明显碰撞动作。。
- 事件6；视频末尾，清洗结束阶段；false_positive：可能有放置物品的声音，但在该时刻画面仍聚焦于锅内擦洗，未见锅体移动产生撞击。；画面：目标静止于水槽中，仅有内部清洁动作。。
**friction**：全片贯穿着清晰、连续的“沙沙”声，这是典型的海绵/百洁布在光滑表面（涂层锅底）上反复摩擦产生的声音。；画面：从开始到结束，戴手套的手始终握着海绵在白色圆形器具（锅）的内表面进行圆周运动的擦洗。FRICTION事件标记准确覆盖了主要的擦洗过程。。

### H1-Q2
**impact**：无。视频中可听到持续的摩擦声和偶尔的碰撞声（如盘子放入沥水架），但没有任何声音是由被洗器具直接撞击不锈钢水槽本体产生的。；画面：全程为戴手套的手持海绵在盘子上擦拭，盘子悬于水槽上方或浸入水中，未观察到任何物体与水槽壁发生物理接触或敲击动作。。
**friction**：无。虽然存在明显的“沙沙”摩擦声，但该声音源自海绵与陶瓷盘表面的接触，而非与水槽本体的摩擦。；画面：画面显示清洗动作完全集中在盘子表面，手部和清洁工具均未与水槽内壁或底部产生相对滑动摩擦。。

### H2-Q1
**impact**：在视频前段（约3-5秒），可以听到海绵被用力按压并敲击目标部件时发出的沉闷撞击声。；画面：对应IMPACT-event 1和2的横幅出现期间，画面中右手持黄色海绵反复、有力地敲击左手所持的黑色圆形部件内部。。
**friction**：在视频中后段（约6-23秒），有持续且清晰的摩擦声，是海绵与目标部件表面接触产生的声音。；画面：对应FRICTION-event 3和4的横幅出现期间，画面显示右手用海绵在黑色圆形部件内外进行持续的擦洗动作。。
