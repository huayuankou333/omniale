# 内容评测规则 v1

本文是题包规则。参考事件必须完成声源归属和边界审核后才能产生正式成绩；未经审核的候选标注不能作为确定答案。当前题包状态见组织者 `BUILD-REPORT.zh-CN.md`。

## 门槛与执行

封存源代码、依赖、模型版本、远程服务及默认阈值。在隔离容器内对未见录像重新运行，录像与查询路径重新命名，目标指示从实际参数读取。不能仅提交预计算事件表。工程检查不加分。

- 没有能处理新输入的程序、伪造结果或使用对应源视频答案：总分0。
- 组织者环境、网关、服务或媒体故障：暂停内容计分并修复；不自动记0。
- 缺少事件表／触发日志、实际复核片段／网页、依赖恢复说明的其他交付问题：记录为门槛未通过，补齐前不发布正式总分；不任意添加内容加分或事后调整上限。

## 参考事件与排除区

每条参考必须有目标对象、类别、起止、声音证据、视觉归属证据、边界不确定度和审核状态。原数据集声音标签只是候选，不能自动变成逐对象真值。只评 `approved` 条目；含有未完成归属判断的时间段标为 `ignore`，不得当成负例。

边界使用 `[start_min,start_max]`、`[end_min,end_max]` 表达审核允许范围；清楚事件可以是同一时间点。边界范围超过0.30秒或类别／归属仍无法确定的事件不进入正式评分。参考合并／切分与题面0.4秒停声规则一致。

困难负例另行列出：`other_object_sound` 为其他器具同类可听事件，`silent_target_action` 为目标有动作但没有对应目标可听事件。负例不能与目标正例、排除区交叠；每个负例有视听证据和审核状态。没有标注不等于没有声音，不能用原数据集空白处自动生成负例。

## 一对一事件匹配

使用候选最终输出的全部事件，不对每条录像调阈值。同一查询、同一类别分别进行最大基数的一对一匹配，再在最大基数中最小化边界误差。一个预测最多匹配一个参考，重复预测均可能成为误报。

预测起点到参考起点允许范围的距离不超过0.30秒；终点到参考终点允许范围的距离不超过 `max(0.30秒, 参考事件时长×20%)`。两项都满足才允许匹配。参考时长取两边界范围中点之差。

完全落在排除区的预测不计；跨越排除区但在可评区仍有声音主张的预测不能整条豁免。实现将排除区两侧分别裁切成可评片段再匹配，参考事件不得跨排除区。一个跨区预测在多个可评区留下的片段分别计数。所有裁切保留原始预测ID供复核。

错误器具、错误类别、重复或边界超差产生FP；漏掉的参考产生FN。不把“听到金属声”自动算作目标正确，也不按帧准确率让长静默占便宜。

## 70分：事件识别与目标归属

对每个有目标正例的“查询×类别”单元计算：

`F1 = 2TP / (2TP + FP + FN)`，`Recall = TP / (TP + FN)`。

有参考或有预测的单元等权平均F1，得到 `F`；两者都为空的单元不参与F1平均，无参考但有预测的单元F1为0。`R`只对有参考正例的单元等权平均。错误类别不能放进无参考类别逃避扣分。正式验收须至少有两个独立录像来源，每类均有正例，并覆盖两种目标查询。

本项 `S_event = 70F`。大量易例不能按持续时间淹没短事件。

## 20分：困难负例控制

分别计算两组已审核负例的“完全没有错误触发”的比例，再对两组等权平均，得到 `N`。一个负例中出现任意预测起点，或预测区间与负例连续重叠超过0.15秒，即该负例失败；不能把触发起点挪到负例外、再用长区间覆盖来规避。即使实际目标声音类别为空，其他器具同类声仍属于负例。

本项 `S_negative = 20 × R × N`。目标召回率缩放保证空输出拿不到负例分。两组负例任一未完成审核时，此项待评，不能把缺证据默认为正确。

## 10分：边界质量

只对已匹配事件计算边界到参考允许范围的距离 `d_start`、`d_end`。每边的质量：距离≤0.08秒得1；0.08—0.30秒线性降至0；≥0.30秒得0。事件质量取两边平均，随后在“查询×类别”单元内平均，再对有正例单元等权，得到 `B`；没有匹配的单元质量为0。

本项 `S_boundary = 10 × R × B`。这一项在粗容差匹配基础上评价剪口精度；不要求采样级定位或高于原画面／录音所支持的精度。

## 总分与满分条件

`Total = 70F + 20RN + 10RB`。

全部目标事件类别和归属正确、无多报漏报，全部困难负例不触发，起止均在允许范围外0.08秒以内且工程门槛通过，可得100。选用哪种模型、是否训练、代码量和页面装饰不改变内容分。

空输出：F=R=0，总分0。错误器具且与参考无匹配：同样为0。全场检测器会在其他器具负例与FP上失分。整段常开会因边界不匹配而失分。计分器附带这些逻辑边界的合成单元校验；这些是公式检验，不冒称真实素材上的能力基线。

Qwen等模型只可辅助定位、描述和复核证据。正式标签必须单独审核；最终数值按已冻结标签和公开公式计算，不让judge直接凭印象报总分。若素材可解性、边界一致性或模态必要性尚未完成确认，报告“未评测”，不发布候选成绩。
