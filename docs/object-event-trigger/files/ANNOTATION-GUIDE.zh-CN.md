# 组织者：内容审核与开测条件

这是组织者私有文档，不能打入候选模型题包。当前没有已审核的逐对象事件真值，不能把空参考当成“没有目标事件”。

## 审核步骤

1. 先播放同期音视频，确认每个目标框、点和简短描述指向同一器具；目标身份不清时更换指示帧。对嵌套器具逐一确认，不能把整个区域当成目标。
2. 不查看候选模型答案，对每个查询逐段听看，独立写出目标直接参与的可听 `impact`、`friction`。先确认声音存在，再确认可见接触关系。接触双方都可计入，旁观、邻近或共同移动不能推断归属。
3. 以波形和反复试听辅助标起止，不用音量峰值自动代替声音类别；采用0.4秒停声拆段规则。填写起止允许范围、声音证据、视觉归属证据和审核状态。边界允许范围宽于0.30秒或归属／类别不稳定时排除。
4. 单独标注 `other_object_sound` 和 `silent_target_action`。每个负例须给出听觉与视觉依据，不能从原数据集未标注处推定。负例不与目标正例或 `ignore` 交叠。
5. 将无法判断的片段明确列为 `ignore`。参考事件不可跨排除区。检查整段标注已完成后，才将查询设为 `annotation_complete=true`。
6. 由另一位审核者独立复核，保存分歧与最终裁决。Qwen观察、EPIC声音候选均只用于寻找待看片段，不能直接批准为逐对象真值。

## 内容预验证

封存验收至少覆盖两个独立录像来源、两种声音类别和两类困难负例。需要验证同一录像更换目标后，正确事件集确有区别；不能仅因存在两个框就声称有目标归属难度。当前H2的静止杯子查询可作为负例候选，但不能取代其他目标上的可靠正例。

提供一个仅使用公开输入的可解性参考实现或人工辅助的合法路线，确认目标声在实际压缩音频中可辨，未依赖隔离真值、原动作表或额外录制。用音频单模态和视频单模态做对照，检查联合视听确有必要。没有完成这些工作时，不宣称达到OmniALE难例标准。

当前四段是素材初选。水流掩盖、持续单一擦洗和被动容器可能使有效事件不足。若审核后无法覆盖上述条件，应替换素材；不能通过强行标注微弱声、增加无声目标或收紧容差制造难度。

## 计分与工程门槛

先冻结已审核参考与排除区，再封存候选代码、模型版本、阈值和推理预算。更名路径并用未见录像重新运行，检查输入依赖、日志、片段、缩略图、网页与依赖恢复。辅助 `check_output.py` 仅检查输出契约，不能代替声音正确性、输入依赖和新输入重运行检查。

`score.py` 默认只在标签通过时返回内容分，默认不发布正式分。程序化调用 `score(reference, predictions, engineering_gate=True)` 仅供组织者在工程门槛实际通过后使用。CLI保持 `engineering_gate=None`，不能把一次结构检查等同于完整工程验收。

正式分计算前必须审查引用材料、逐对象证据、负例和模态必要性；任何未完成项保留为待评。空的 `REFERENCE.pending.json`、辅助模型描述和合成自测100分均不能作为实际素材的高质量参考输出。
