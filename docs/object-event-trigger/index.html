01 / INPUT

声音、画面和一张目标指示

输入为同步的无声视频、混合录音，以及带框和点的器具参考帧。开发仅有 A/B 两段录像、四个目标；不提供事件标签、对象轨迹、转写或干净声轨。

02 / REASONING

既要可听，也要归属成立

跟住移动、转动或短暂遮挡的器具，把实际可听的碰撞与摩擦归给正确目标。安静的动作不触发，邻近器具的相似声音也不能直接算到目标身上。

03 / DELIVERY

可换输入重新运行的程序

交付检测代码、固定依赖、事件 JSON、触发 JSONL、原声复核片段和网页。代码封存后，更换录像、目标和路径重新运行；文件可播放是交付门槛。

同一次直接接触，可以同时属于两个被查询器具。

A 撞到 B 并产生声音，查询 A 或查询 B 均可成立；静止的器具也可能被撞响。仅仅在旁边、同时移动或只听到水声，则不构成目标的碰撞／摩擦。

04 / FROZEN CONTENT RUBRIC

只给事件判断打分。

完整匹配与计算规则 ↗

下面是题目的正式评分标准。工程作门槛，没有交付基础分；空输出和全场常开都不能靠负例或长静默得分。

70分

识别事件，归对器具

同查询、同类别做一对一匹配。误报、漏报、错误类别、重复预测和超差边界都会失分。按“查询 × 类别”单元等权平均 F1。

S_event = 70 × F
20分

相似声音，不乱触发

检查其他器具同类声，以及目标安静动作两组困难负例。两组抑制率等权平均，并乘目标召回率，防止靠空输出拿分。

S_negative = 20 × R × N
10分

起止贴合真实声音

只在匹配事件上评价边界：距审核允许范围 ≤0.08 秒得满质量，至 0.30 秒线性降为零，再乘目标召回率。

S_boundary = 10 × R × B
正式总分70F + 20RN + 10RB

起点匹配容差 0.30 秒；终点为 max(0.30 秒, 参考时长 ×20%)。归属或类别难以确认的区间先排除，不能当负例。完整事件正确、无误报漏报、负例不触发且边界达标，可得 100 分。
