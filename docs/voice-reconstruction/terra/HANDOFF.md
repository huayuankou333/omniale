# 读唱双模式交接

## 交付与使用范围

- `render.py` 是实际对任意新片段运行的转换器；`read_model.npz`、`sing_model.npz` 是从相应模式的三组配对录音拟合的参数，而不是原始音频或缓存的查询结果。
- `audio/` 是 11 个公开 brief 的独立转换文件；`Voice.RPP`、`Voice.wav`、`session.json` 是按原 brief 顺序制作的工程、演示和时间表。
- 参考材料是 NUS-48E，**仅限研究用途**。请保留 `DATA-LICENSE`，并引用：Zhiyan Duan, Haotian Fang, Bo Li, Khe Chai Sim and Ye Wang, “The NUS Sung and Spoken Lyrics Corpus: A Quantitative Comparison of Singing and Speech”, APSIPA ASC 2013。不得将通用模型的许可误认为覆盖原始数据及其派生物的许可。

## 适配方法

这是轻量的、内容受源信号约束的谱包络转换，不是端到端重唱。先用 WORLD 的 DIO/StoneMask 和 CheapTrick 从每个独立真人参考提取 10 ms 的音高及 36 维编码谱包络；对说话人分别作标准化，利用谱特征和时间差分、清浊音及宽松的时间约束做动态时间规整。只在配对的有声帧上，用岭回归拟合「导引倒谱 → 目标减导引倒谱」；无声帧使用较弱的平均颜色修正。说话和歌唱分别拟合，以容纳两种发声方式和不同音域。最终提交参数使用所有三组配对；不需要原始参考文件即可推理。

运行时以导引信号的 10 ms 倒谱预测频率响应，限制外推范围并平滑清浊切换；该响应作用于原信号的复数 STFT，保留其相位、起伏和时间结构。频率响应和慢速能量补偿是随时间变化的，不是简单整体增益或固定 EQ。清辅音与呼吸采用较轻修正，避免把非周期部分强行当作有声元音。最后仅在会发生 PCM 削波时做整体防溢出缩放；无伴奏、混响、压缩或母带处理。

使用 `pyworld`（WORLD 分析，Python wrapper）、NumPy、SciPy 和 SoundFile 等已安装库；交付中没有这些软件的副本，也不下载模型。探索和对照时使用了 `/opt/models` 的 **OpenVoice V2** 通用权重及参考编码器，MIT 许可，许可全文见 `OPENVOICE-MIT-LICENSE`。它不参与最终推理，也未随包复制权重。直接使用其通用转换器的实验中，输出音高明显偏离导引，因此最终采用上述保相位方案。OpenVoice 参考编码器的余弦只是辅助诊断，不是经过本任务校准的身份评分。

## 重新推理

环境需要 Python 及已安装的 `numpy`、`scipy`、`soundfile`、`pyworld`。脚本和两个 NPZ 必须同目录；提交目录可只读。输入必须是 24 kHz 单声道 WAV；输出写到可写目录，为同采样点数的 24 kHz 单声道 24-bit PCM WAV：

```bash
python /workspace/submission/render.py --input /path/input.wav --output /path/output.wav --mode speech
python /workspace/submission/render.py --input /path/input.wav --output /path/output.wav --mode singing
```

脚本限制数值库线程数；不访问参考目录、不联网、不使用公开 brief 的名称查表。长音频按整段处理，没有分块交界。极短信号在内部补零分析，返回时裁至原长度；全静音直接保留。

## 工程

`Voice.RPP` 使用 `audio/...` 相对路径，每段一个独立 track 和 item，item 原速、无 FX、无自动淡入淡出。`session.json` 的 `start` 和 `seconds` 以秒计，相邻 item 的间隔恰为 0.5 秒。工程采样率和渲染均为 48 kHz，双声道、24-bit PCM，最后一段末尾即结束。演示为 REAPER 实际渲染，左右声道相同。

可将整个目录复制到可写位置，打开 `Voice.RPP`，使用 File → Render，保持工程保存的输出格式。Linux 无显示环境下例如：

```bash
cp -a /workspace/submission /tmp/voice-project
xvfb-run -a reaper -newinst -nosplash -renderproject /tmp/voice-project/Voice.RPP
```

注意从可写副本渲染，避免覆盖只读交付。已将 RPP 和音频实际复制到另一目录并重渲染；对交付 `Voice.wav` 的逐样本比较完全一致。

## 验证与限制

**本轮没有直接听音**；以下均为程序测量，不是人工听感、MOS、可懂度或验收评分，也不能证明达到了 80 分的声音门槛。

- 11 个公开输出均为 24 kHz mono PCM-24，长度与各输入完全相同；峰值绝对值在 0.482–0.895 之间。导引与输出的波形相关系数为 0.875–0.938，说明仍保留大量原始激励，同时也并非原样波形。
- 对公开输出用 WORLD 独立测 f0，在输入和输出均判为有声的帧上，绝对偏差的中位数为 1.1–1.7 cents，各片段的第 95 百分位为 17.9–39.7 cents。f0 测量在清浊边界会有误判，不能据此保证每一个辅音或瞬态均完全相同。
- 留一首配对曲目、不用该曲目拟合的测试：先以独立表演间 DTW 对齐，计算有声帧的 35 维 WORLD 倒谱（不含能量项）平方误差之和的均值。朗读三首原导引分别为 5.079、5.424、4.778，转换后为 3.710、3.043、2.832；歌唱原导引分别为 6.086、7.931、5.496，转换后为 3.138、3.107、2.459。歌唱第一首测试强度为 1.0，其余为 1.1（最终为 1.1）；朗读为最终的 1.3。此指标依赖自动对齐，且并非组织方隐藏参照指标。
- 同一留出曲目的 OpenVoice 参考编码器余弦，朗读导引对目标约 0.402–0.459，转换后约 0.500–0.572；歌唱约 0.397–0.516，转换后约 0.529–0.643。这说明该辅助特征有朝目标移动，但并不等于确认目标身份、自然度或主观相似度。
- 还对一段 WORLD 重合成、音高乘 1.25 且速度乘 1.25 的未参与拟合导引做过处理：长度完全相同，双方均有声帧的 f0 绝对误差中位数约 1.27 cents、95 百分位约 13.06 cents；约 24 秒输入在本机单线程推理约 1.7 秒。不同硬件、音高范围及长片段的速度不能由此保证。

保相位方法保留了导引的声门激励、发音习惯和大部分非周期细节；它无法完整重建目标的发音、气声及个体声带纹理。目标参考和导引参考的典型音高明显不同，而本任务要求保留导引音高，因此目标身份尤其可能只部分接近；超出参考范围的音高、语速、特殊辅音和长持续元音也可能表现不稳定或出现滤波痕迹。应由有权限的人进行听审和必要的进一步制作，不能把这些测量当作自然度或身份已达标的保证。
