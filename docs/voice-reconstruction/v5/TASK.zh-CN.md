# 30秒演唱 · 声线重建与长视频精准寻段

版本 v5-retrieval（2026-11-26）

## 制作委托
为一段30秒真实演唱制作指定歌者声线的研究样片。团队分两次交付素材。先仅凭导唱和目标歌者参考重建人声，再在长视频中找到这段演唱对应的原始表演，准确剪出30秒，制作自然同步、可编辑的成片。

画面人物是原表演者，声线参考来自另一位歌者。保持导唱歌词、旋律、节奏、发声起止、呼吸和表演起伏。保留目标歌者跨音区身份；不能只移调、均衡或复用原声。不得以原歌者声线填补缺陷。

## 第一阶段：声线重建
仅发放 `stage1/`，包含 `guide.wav`（30秒，24 kHz mono）、`references/target_01.wav` 至 `target_03.wav`（三个不同歌曲的24秒参考）、任务与许可。交付 `Voice.wav`（30秒、24 kHz mono、24-bit PCM）及可打开的 `Voice.RPP`，并提交 `voice-handoff.md`。声线应自然、清楚、无明显机械或拼接伪影；干声不得附加伴奏、混响、环境声或合唱。

组织方收到第一阶段交付后将其保存为不可替换的评分副本并记录哈希。第二阶段使用已锁定的同一条干声，不可根据画面对歌词、旋律或局部节奏重新生成或改写。

## 第二阶段：长视频寻段与剪辑
发放 `stage2/Footage.mp4`（约148秒、720×720、25 fps、无音轨）及本阶段说明。它包含同一表演者的多次真实叠录，且仅有一处正确的30秒连续演唱。视频未附时间码、字幕、源音频、正确起点或对齐标注。

- 结合导唱与已锁定的转换声，观察口型、音节起止、换气、停顿和连续的乐句动作，在长视频中定位正确表演及其精确入点、出点。以原始25 fps帧编号表示区间（左闭右开）。
- 保留正确表演的连续750帧，原速、原序，输出30秒。不要重排、加速、减速、重复或生成口型。方形原片等比居中置于1280×720画布，完整保留人物及嘴部。
- 配合锁定干声进行同步，允许固定电平及单声道复制到双声道，无新增伴奏、局部拉伸或换声。最终音轨必须来自第一阶段干声。
- 在交接说明提供至少3处相隔的音画证据，包括导唱中的时间点和听到的音节/停顿、长视频对应帧号及观察到的口部动作。说明排除相似表演的依据。

## 第二阶段交付
`Final.mp4`（1280×720, H.264, 25 fps，30秒，48 kHz stereo AAC）、`Mix.wav`（48 kHz stereo, PCM 24-bit）、`Edit.mlt`（引用原始长视频与Mix的可编辑工程）、`timeline.json` 和 `HANDOFF.md`。第一阶段文件随工程保留。

`timeline.json` 结构示例（其中源帧号仅为格式示例）

```json
{"fps":25,"duration":30,"source":"Footage.mp4","source_in_frame":0,"source_out_frame_exclusive":750,"output_in_frame":0,"output_out_frame_exclusive":750,"speed":1}
```

工程使用相对路径，移动整个提交目录后仍能重开，音轨与实际渲染保持一致。研究样片须在交接说明披露画面与目标声线来自不同表演者。
