# 读唱双模式：恢复可复用的人声身份

配音与歌曲制作团队需要恢复同一位表演者的声音身份，用于新的导读和导唱内容。`references/` 包含目标表演者和导引表演者对三组相同内容的真实朗读/歌唱录音。请从原始录音中建立可复用的声音复刻方案，使 `guides/` 中新内容以目标表演者的音色呈现。

这是以导读/导唱为内容约束的人声转换工作：保持导引中的音素内容、时间、语调/旋律、颤音、停顿和表演起伏，重建目标表演者的声道共鸣、元音质感、辅音、气声/粗糙度及跨读唱模式的声音身份。配对参考是独立的真人表演，长度和音高未被预先对齐；没有提供声音身份向量、声学特征标签、对齐结果或目标模型。

`references.json` 解释文件配对，`briefs.json` 是要交付的长片段。还会在未公开的新音区、速度和片段组合上运行你的转换引擎。请保持说话和歌唱两种模式中的身份一致，并处理长句、持续元音、辅音过渡、换气、音高变化和长片段的稳定性。

交付到 `/workspace/submission/`：

1. `render.py` 及必需的模型/状态/资源。必须支持：

   ```bash
   python /workspace/submission/render.py --input INPUT.wav --output OUTPUT.wav --mode speech
   python /workspace/submission/render.py --input INPUT.wav --output OUTPUT.wav --mode singing
   ```

   接收 24 kHz mono WAV；输出同长度（误差不超过 80 ms）的 24 kHz mono、24-bit PCM WAV。引擎要能处理新片段，不得只返回已转换文件。重新运行时只提供只读的提交目录、查询 WAV、已安装软件及 `/opt/models` 的通用模型；适配过程需要的状态应保存在提交中。每段复测在 4 核 CPU、8 GB 内存、无网络条件下最多运行 240 秒，可写 `/tmp` 和指定输出目录。不要复制原始参考或导引录音作为随包资源。

2. `audio/<brief_id>.wav`：完成所有公开 brief 的转换，不改变内容、旋律、速度和停顿，不添加伴奏、混响或母带效果。
3. `Voice.RPP`、`Voice.wav` 和 `session.json`：真实 REAPER 工程，按 brief 顺序放置转换后的独立可编辑 stems，中间留 0.5 秒，渲染 48 kHz stereo、24-bit PCM 的完整演示。`session.json` 列出每段的 `id`、相对文件 `path`、`start` 和 `seconds`。工程应使用包内相对路径，可移到另一目录重开、渲染。
4. `HANDOFF.md`：说明适配方案、通用模型及许可、读唱模式的处理、重新推理与工程渲染方法、已验证的行为及剩余差异。如只进行了测量而未直接听音，应明确说明。

**v2人声声音评分说明**

声音100分：目标身份30（读唱各15）、自然度25、有声段伪影15、内容与可懂度10、最差片段目标身份保持5、相对导引的目标谱形改进10、表演保持5。读、唱等权。

原样返回导引、仅改整体音量/极性或微小延迟，命中波形比对后该查询0分。保留内容和音高不能替代身份转换。明显机械的输出不能通过质量核心门槛：自然度低于“大致像真人，仅局部不自然”时最高59分；严重持续机械感最高39。身份基本未转换最高19，身份只部分接近最高59。

以目标真人参考为身份/自然度条件。使用经对照校验的音色编码器、相对基线声学改进与原生音频Qwen辅助judge；不将Qwen不可靠的身份等级纳入评分。工程只作门槛。声音至少80并通过工程方可验收。

谱形相对改进10分使用构造的WORLD测量参照：组织方提取隐藏目标真人录音的谱包络/非周期性，再结合导引音高与时间重合成；它不是真人目标的新演出。身份评分另用真实目标/导引参考校准的音色编码器，自然度、伪影与内容使用原生音频辅助judge。未公开音区与速度请求含WORLD处理的导引变体。自动指标不等同于专家听感MOS。

素材来自 NUS-48E，仅限研究用途，使用时保留 `DATA-LICENSE` 和引用。团队恢复场景为评测构造。模型接口无法原生接收音频，本轮是工具辅助音频条件。请先阅读 `TOOLS.md`。
