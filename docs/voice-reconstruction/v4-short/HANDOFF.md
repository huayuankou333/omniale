# 30 秒目标声线研究改版 · 交接

## 状态与披露

这是**原表演画面＋参考歌者条件下的神经声线转换研究样片**，不是目标歌者真实演唱该视频的记录，也不表示其背书。全段已进行神经换声；没有用原导唱、人声参考的歌词片段或另一声部补洞。没有伴奏、混响、合唱、加倍或失真。

**听感验收仍待有效盲听。** 本接口没有原生音频输入，我没有直接听过导唱、参考或输出。以下把实际图像观察、信号测量、软件复现分别列出；不据它们宣称目标身份、自然度、伪影控制或歌词清晰度已达标。按任务协议，正式 A/S 保持 `null / 待复核`，不确认 A>59，也不把 59 当成已得分。

## 2. 如何找到音画绑定

### 实际图像观察

先观察了 F17/F63/F82 各自整段抽帧，再逐帧检查口部。三条是独立声部表演，未把它们当作可互换机位。候选筛选后，检查了覆盖全长五个 6 秒窗的连续口部接触表，以及 14 处初始检查点的 ±160 ms 图像。较有区分力的例子：

- 导唱约 **6.24–6.44 s** 对应 F63 **17.60–17.80 s** 的闭唇；约 **6.52–6.56 s** 出现开缝与齿部，源帧 **17.88–17.92 s**。
- 约 **17.08–17.40 s** 有短暂开、闭唇组合；随后源片 **28.80–28.84 s** 从闭唇过渡到圆唇开口，映射到导唱 **17.44–17.48 s**。
- 约 **23.52–23.72 s** 的闭唇准备与 F63 **34.88–35.08 s** 对应；随后在源片 **35.12–35.16 s** 明显张开，对应导唱 **23.76–23.80 s**。
- 还检查了起段齿部暴露、11 s 附近圆唇长音准备、27 s 附近圆唇再起及尾段重新张口。静音时并不总闭嘴，没有把“开嘴”直接等同于“发声”。

证据在 `evidence/binding_anchors_*.jpg`、`release_at_*s.jpg` 和 `sync_report.json`。这些是制作观察，不是专家转写或组织方冻结的音素真值。

### 信号辅助筛选与成片回查

从实际像素提取唇色连通区域，以其面积变化与导唱 40 ms 对数 RMS 做候选内偏移扫描。该辅助方法下，F17 的最佳相关约 0.178（22.56 s），F82 约 0.218（15.00 s），F63 约 **0.456（11.36 s）**。这只是筛选证据，最终入点由上述口部序列与声学频谱起止共同核对，帧级不确定性约 ±40 ms。

对**正式 Final** 的全部 750 帧回查：中心画面逐帧对应 F63 的 284–1033 帧；中心画面平均像素绝对差 0.579/255，口部区域平均差 1.192/255（编码差异），没有完全重复的解码帧。详见 `evidence/qa_current.json`。此检查证明源帧和顺序，不冒充音素级唇同步评分。

## 3. 声线适配与处理链

1. 使用离线 **OpenVoice V2** 通用神经音色转换模型。将三段目标参考的全部 **72 秒**按每首三个 8 秒窗提取参考条件，九窗等权平均；源导唱以五个窗提取源条件。没有按文件顺序选取一个参考来替代全部目标，也没有把编码器相似度当作身份分。
2. 在模型原生 22,050 Hz 上，对整段连续推理，`tau=0.3`、随机种子 115；前后各加 22,016 样本反射上下文，推理后移除。**不是独立乐句拼接**，没有交叉淡化叠声或原声混入。模型进行后验编码、源/目标条件流映射及神经解码，不是仅移调或 EQ。
3. 初版出现约 +0.8 半音的系统性偏高，经 WORLD 与独立 YIN/短窗谐波检查交叉核对后，用 **Rubber Band 3.3 / R3、离线、保共振峰**做固定 **−0.81 半音**纠偏，时间比例始终为 1。此步仅用于恢复导唱旋律，**不作为换声线的证据**。最终取精确的 720,000 样本。
4. 固定增益 +6.2144 dB，导出 `Voice.wav`；样本峰值 −2.00 dBFS，RMS −20.87 dBFS，没有削波。不做压缩、限幅、噪声门、EQ 或空间效果。
5. REAPER 仅重采样到 48 kHz 并把单声道等量送到左右声道，生成 `Mix.wav`；MLT 不添加音频效果，仅进行 AAC 编码。

## 4. 工程重开与重渲染

把**整个 submission 文件夹**一起移动，保持 `media/` 和三个 WAV 的相对位置。所有项目媒体引用都是相对路径，无符号链接。

- **REAPER 7.85**：打开 `Voice.RPP`。File → Render，使用工程保存的 0–30 s 范围、Master mix、48 kHz、Stereo、24-bit WAV，输出 `Mix.wav`。工程内没有实时换声插件，也不应新增效果器或自动淡化。
- **Shotcut 24.04.01 / MLT 7.22**：打开 `Edit.mlt`，时间线为 V1 原片与 A1 Mix。导出 H.264、1280×720、25 fps、AAC 48 kHz stereo。项目预览不依赖参考音频。
- 已将必要文件实际复制到另一目录，从无 Mix 输出开始重开 REAPER 并渲染，再由移动后的 MLT 工程重渲染完整成片：**Mix 样本逐个相同，Final 的 SHA-256 逐字节相同**。记录见 `evidence/portability_report.json`，不只是 XML 语法检查。

复现实际成片的 MLT 命令（在项目目录执行）：

```bash
QT_QPA_PLATFORM=offscreen melt Edit.mlt in=0 out=749 \
  -consumer avformat:Final-rebuilt.mp4 vcodec=libx264 crf=16 preset=slow \
  pix_fmt=yuv420p acodec=aac ab=320k ar=48000 channels=2 \
  movflags=+faststart threads=3 real_time=-3
```

本无声卡容器的 Shotcut 预览使用 `SDL_AUDIODRIVER=dummy`；REAPER 离线渲染使用 `linux_audio_mode=3`。初次普通 GUI 启动曾遇到音频设备不可用，离线渲染不依赖该设备并已成功复验。设备设置不是音频处理；GUI 电平表与截图也不代表已听音。

## 5. 剩余问题与有效听审

- 未取得两位有效独立盲听者，未使用未经资格验证的自动 judge 填分。五窗及全长的身份、自然度、伪影、清晰度和最差片段均保留待复核，没有虚构缺陷时间点或“真人 MOS”。
- 通用转换器对歌唱中的持续元音、快速辅音、气声及跨音区身份仍有风险；**频谱、F0、非等价导唱检测不能排除金属、蜂鸣、颤动或身份不足**。不能将本交付直接宣传为“已通过指定歌者身份验收”。
- 复核应对照题包 `references/target_01–03.wav` 和 `guide.wav`，干声单独盲听完整 30 秒及固定五个 6 秒窗。至少两位独立、资格有效的评审；顺序盲化；覆盖所有乐句，记录最差时间段。核心等级差≥1或上限判断冲突时请第三位复核，按题包协议处理硬上限。
- 12–18 s 窗是本次信号测量中 F0 中位误差略高的一窗；这是优先核查建议，**不是已听出的声音缺陷**。高音、轻辅音和换气需同等检查，不能只听最好的一句。
