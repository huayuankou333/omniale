# 30秒演唱视频：目标声线替换与音画同步

版本：v4-short，2026-11-15。30秒导唱、3条各54秒的匿名无声视频和3段各24秒的目标歌者参考已经构建。正式主观分须通过有效盲听复核；自动评审资格不足时依协议保留待复核。

## 制作委托

制作团队要为一段30秒的演唱影像制作指定歌者声线的研究样片。原表演者的画面与导唱仍在，但原视频片段与音频的对应位置没有整理。请根据真实表演画面找到匹配的片段，将导唱转换为 `references/` 中指定歌者的音色，完成一支自然、同步、可继续编辑的30秒视频。

目标是让人听到指定歌者在演唱这段内容：声道共鸣、元音、辅音、气声、音头及跨音区身份都应可信；保留导唱的歌词、旋律、节奏、换气和表演起伏。不能仅靠改变音高、音量、均衡或混响声称完成换声线。

这是一段歌唱任务，不含朗读。画面中的人仍是原表演者；目标声线来自另一位真实歌者。样片须在交接说明中披露研究改版性质。

## 输入

- `guide.wav`：30秒单声部干声导唱，24 kHz mono。它规定需要演唱的内容、旋律、节奏与时间轴；不是可直接交付的目标声音。
- `footage/`：3条匿名、无声的原始表演候选视频，每条45–60秒。它们来自同一原表演者的独立声部记录；不是三个可互换的同时拍摄机位。至少一条包含导唱对应的完整真实表演。
- `references/`：目标歌者3段真实干声参考，每段20–30秒，总计不超过90秒。歌词与导唱不同；没有把参考预先整理成音色向量、音素库或逐词对齐表。
- `brief.json`：目标时长、输入格式、输出格式与目标参考文件列表。不包含正确视频ID、源时间点、口型对应或剪辑答案。
- `DATA-LICENSES.md`：来源、研究用途条件、人物/声线说明及组织方处理记录。

没有提供正确视频映射、导唱转写、口部标记、对齐曲线或已有样片。不要把文件顺序、命名或人物服装当作绑定答案。需要实际检查视频中的口部动作、发声起止、停顿与导唱内容的对应关系。

## 交付范围

只制作这一段30秒作品，只重建一条人声。无需处理整首歌、六个声部、长篇合唱，也不要求实现可以处理任意新歌曲的通用转换服务。

1. 全段转换为指定歌者的声线。高音、较低音、持续元音、快速音节、辅音和换气应保留同一身份；不得以原歌者的未转换片段补洞。
2. 输出可直接单独试听的干声。不得用器乐、环境音、混响、合唱、加倍、失真或大幅压低音量掩盖机械感、金属音、蜂鸣、颤动、音素涂抹、漏字和拼接痕迹。
3. 从候选记录中选出与导唱匹配的真实表演并对齐。只允许使用该声部、该实际表演的正确时间段；不得把另一声部的嘴型作为替代画面。
4. 一个准确、完整的连续镜头即可。允许有依据的短剪切或等比裁切，不要求凑镜头数。不得用全程多宫格、长黑幕、空镜、遮嘴、定格、极短闪切或生成嘴型回避音画同步。
5. 发声画面保持原始帧序和速度，不生成或重绘人物与口部动作。允许源片取段、位置、等比缩放、轻微色彩调整；导唱的旋律与节奏不能为了对嘴而被任意改写。
6. 成片的声音必须就是提交的转换干声。除固定电平调整、单声道到双声道复制及必需编码外，不增加掩盖问题的音频处理。

## 必需文件

交付到 `/workspace/submission/`：

- `Final.mp4`：30秒，1280×720、25 fps、H.264，音频48 kHz stereo。允许编码尾部导致不超过80 ms的时长差。
- `Voice.wav`：30秒目标声线干声，24 kHz mono、24-bit PCM；与导唱时长误差不超过40 ms，未削波、没有异常静音。此文件承担全部声音质量评分。
- `Mix.wav`：实际用于成片的48 kHz stereo、24-bit PCM音轨，与 `Voice.wav` 内容一致。
- `Voice.RPP`：真实可编辑的REAPER工程，引用独立的 `Voice.wav`，可重新渲染 `Mix.wav`。轨道数不加分，不强求七轨。
- `Edit.mlt`：可在Shotcut/MLT中重开、实际引用原始视频和 `Mix.wav` 的剪辑工程，可重新渲染成片。
- `timeline.json`：包含 `fps`、`duration`、`shots`；每个镜头记录 `start`、`end`、`footage_id`、`source_start`，单位为秒，速度为1。声明必须与真实成片一致。
- `HANDOFF.md`：说明音画绑定的证据、声线适配与处理、工程重开方式、素材许可及剩余问题。直接听音、图像观察和信号测量要分别如实说明。

工程应使用相对引用，可移至另一目录重开。原始媒体可用相对链接或按题包约定重新链接，不要求复制完整原始数据。若使用自定义状态或效果器，须随交付提供重渲染必需的依赖或明确的环境依赖清单。

REAPER和Shotcut/MLT为两个实际使用的制作软件。工程可重开、文件格式正确只作门槛，不给声音加分。无需交付用于额外隐藏新歌曲测试的 `render.py`；组织方只验收这一段作品及工程复现。

## 评分和不可补偿的质量要求

声音A、音画X、成片可用性V各为100分：

`S_raw = 0.80 × A + 0.10 × X + 0.10 × V`

声音分配：目标身份35、自然度30、伪影控制20、内容清晰与完整10、表演保持5。可听身份占目标身份中的30分，经过独立验证的音色特征最多占5分；谱形相似不再单独给分。声音覆盖完整30秒，并复核全部有效乐句与最差片段。

- 原样导唱，或仅整体增益、极性、微小延迟的变体：A=0。通过极小噪声逃避波形检测、但没有可听身份变化，仍按身份失败处理。
- 未建立指定歌者身份，主要仍像原歌者：A最高19；仅部分接近目标、跨片段身份不稳：A最高59。
- 明显持续机械、金属或蜂鸣，或有显著重复伪影：A最高59；严重持续机械/破损：A最高39。音准、歌词正确或视频漂亮不能解除该上限。
- 明显漏字、错词、缺失乐句：A最高59；大段内容缺失或无关：最高29。
- 自然度、身份或伪影的关键判断存在未解决分歧时，不得仅凭一个自动评审的乐观响应确认A>59。可以报告未决区间和待复核原因，不把缺失证据伪装成确定分数。

若A<60，总分S最高59；若A<80，总分S最高79，不能由视觉项补成合格。A≥80时S=`S_raw`。总体合格需S≥80、A≥80、X≥80、V≥70，并通过工程门槛。

详细换分、逐片段上限、最差片段汇总及评审可靠性要求见 `PROTOCOL.zh-CN.md`。规则约束所有模型和所有作品，不预设某个模型必然低于60分。明显机械或身份不足的作品必须触发相应上限。
