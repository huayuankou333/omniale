# 专业音乐分析与证据化研习网站

你是音乐院校的分析课助教。使用5首真实钢琴演奏的录音/总谱，以及8段真实风格音乐录音，解答20道专家来源问题，并制作可离线使用的互动研习网站。重点是实际演奏中的声部、断连、渐强、弹性速度、音色、曲式，以及节拍、调式、和声与即兴手法。

## 输入与边界

- pieces.json列出所有原始媒体和谱面；questions.json给出20题。英文是来源原题，中文供理解；语义冲突以英文原题为准。
- Q01–12必须结合实际音频和谱面；Q13–20是原作者的四选一音频问题，没有为这些曲目虚构总谱。
- 没有提供标准答案、MIDI、逐音标签、源数据集仓库、候选预测或预对齐时间线。不得检索这些外部答案。
- 钢琴时间以完整录音为零点。H01–H08以官方截取片段起点为零点；不要把原歌曲时间误作本地播放时间。
- 允许脚本、PDF几何分析、音频信号分析和有真实音频输入的听音工具。工具未听清时应重听或保留不确定性，不能编造观察。禁止把乐谱中的理想演奏当成实际听到的处理。

## 交付到output/

1. answers.json：按模板填写20题。Q01–12使用来源指定的答案格式；Q13–20只填A/B/C/D，不因选项顺序猜答案。
2. evidence.json：每题给出实际证据回放窗口和音乐解释。Q01–12另给PDF页码、0–1归一化谱面矩形；跨段比较题给两处证据。Q13–20解释至少一个看似合理的干扰项为何不符合录音。
3. site/：离线学习网站，包括媒体播放、20张题卡、揭晓按钮、逐题一键定界回放；12道联合题可定位谱页并标框。给学生解释听觉证据与谱面如何关联。不可伪造未提供的独立声部、演奏视频或乐谱。
4. README.md：启动命令、依赖、时间基准、来源与限制。

网站用python -m http.server 8000 --directory output/site运行，断网仍可用；避免双重音频，手机窄屏可读。原始媒体不得改速、变调、替换或生成。

## 评分

20题每题5分，二元判分，共100分。Q01–12保留来源可接受答案及按类型的标准化；时间题主分使用公开的±1秒容差，同时另报来源精确分。Q13–20按作者正确选项精确判分。没有LLM给音乐知识主分，也不按文风或页面美观补内容分。

网站实际可用性、回放与谱面证据另行验收。内容满分不能替代网站验收；证据错误也不能由answers.json正确掩盖。全部问题都能追溯到发布的人工原题，本题新增的是中文说明和研习网站交付。
