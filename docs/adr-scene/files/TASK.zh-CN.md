# D3：真实复杂场景对白重建（REAPER → Shotcut）

你是对白剪辑师。为锁定的142秒、24fps真实电影片段恢复台词和列出的非语言发声。素材包含控制室、桥上人物、屋顶防守与画外播报。识别真正的发声者，选择正确的真实表演片段，完成跨镜头衔接和口型/节奏对齐。

## 输入

- `input/picture.mp4`：无声锁画，保持原镜头、原速度、原分辨率和帧数。片中已有的场内投影文字不是另加字幕，不得删改。
- `input/dialogue-script.json`：依次出现的34条台词/呼喊，无说话人和时间答案。
- `input/candidates/`：200个真实电影中置声道片段；76个原句家族，76个标准句段、76个上下文版本、48个局部句段。它们不是200次独立表演，也没有合成语音。
- `input/candidate-index.csv`：可搜索父句文字、长度与片段类型。父句索引不保证每个partial含完整台词，也不保证context没有相邻人的声音；必须试听和剪辑。
- `input/role-cards.json`：7种可识别的画面角色/声音类别。桥上男子与控制台男子分轨；投射/操控关联不等于当前发声来源相同。

## 工作与交付

1. 看完整片段，建立逐句的说话人、候选、源内入出点、时间线位置及依据。判断画外音、反应镜头、遮挡和跨切镜连续发声。
2. 在REAPER建立可编辑的逐角色音轨，使用真实候选剪辑。允许调增益、淡入淡出、EQ和保音高的有限伸缩；不可合成新台词、克隆声音或获取原片完整原声作为成片。
3. 输出48kHz的 `mix.wav`、A–G角色分轨、`session.rpp`和所用素材；在Shotcut/MLT把音轨与锁画交接，交付 `timeline.mlt` 和 `final.mp4`。
4. 交付 `edit_plan.json` 和 `cue_sheet.json`，每条包含U编号、角色、候选ID、source_offset、duration、at、rate、置信度及不确定原因。只能给出真实执行的剪辑，不得以报告代替作品。

本题只恢复对白及所列发声，不要求制作音乐和拟音。原声道可能含低量环境或已有失真；评测不把素材自身瑕疵算作你的错误。不得把原片完整原声或私有参考放入运行环境。

## 稳定运行约定

文字索引用于快速筛选；不要200条盲听。先建立可渲染的最小草案，之后分批修正，每完成约4句保存一次计划。工具失败保留已完成工作；单次音频观察超时最多重试一次，随后标记不确定并继续。到预算70%完成首版渲染，85%停止新增观察并检查交付。外部音频工具不可用是基础设施故障，须单独记录，不解释为模型没有听懂。

## 评分

台词与人物归属68分、跨镜头语境4分、同步24分、混音4分；工程不加分，作为总分门槛。同步采用两帧容差且全部锚点满足才通过，不以字幕时间或模型口述替代证据。可用不同候选或多个片段恢复同一正确源区间，不要求唯一ID答案。
