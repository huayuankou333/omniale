01 / THE BRIEF

题目要求

你是对白剪辑师。为142秒、24fps的无声锁画恢复34条台词及列出的非语言发声。识别控制室、桥上人物、屋顶防守与系统播报的真实发声来源；对画外音、反应镜头和跨切镜连续发声作出判断。

  1. 观看画面，试听真实候选，建立逐句的角色、录音、源内剪辑点、时间线位置和判断依据。
  2. 在REAPER建立可编辑的角色音轨，裁切、淡化、调整增益并进行保音高的有限时间伸缩。
  3. 交付48kHz混音、A–G角色分轨、原生REAPER工程；通过Shotcut/MLT交接到锁画，交付原生工程与MP4。
  4. 提交真实执行的剪辑计划及逐句清单。保持原分辨率、镜头顺序、3408帧和24fps。

只恢复对白及指定发声，不要求音乐或拟音。允许候选中原有的环境声与失真；禁止合成新台词、克隆声音或把原片完整声轨用作交付。本题为单阶段任务，没有固定返修。

专业任务定位

模拟交接信息不完整时的对白重建与剪辑修复：完整装配真实录音、确认发声归属、完成视听时序和跨镜头连续性，并交付可继续加工的工程。

跨软件体现在哪里

REAPER负责逐角色声音编辑、分轨和混音；Shotcut/MLT负责画面与混音的原生交接和成片导出。评测检查工程重放、混音一致性和画面锁定，工具不会代选录音或自动对齐。

同步的数值修正与能力边界

原函数在静音搜索窗上产生异常归一化相关性。当前先排除零/近零能量窗，再匹配波形，时间窗与阈值保留。真实对白嵌入静音的对齐正例、12个AAC正例、12个250ms延迟负例及全静音负例已核查。

这项指标检验原片声轨复原程度，尚未逐一认证嘴唇运动。来源映射取所有重叠素材的最大误差，可能受上下文和重复片段影响；两帧整项二元规则也会使不同程度错误集中为零。证据待人工复核。
