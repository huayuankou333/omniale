# 白鹤原视频 → 参考引导绿幕抠像

这是 ALE `visual_media/chroma_key_from_reference / crane_flyingsky` 原始公开输入在本地 DaVinci Resolve 上的 API 桥接复现。

请在当前独立空工程中完成：观看 `media/input.mp4`，以 `media/input.png` 为目标外观参考，从已经合成在天空背景中的白鹤视频里分离白鹤，将所有非主体区域替换为纯绿色 `#00FF00`。每一帧都只保留原白鹤与纯绿背景。

输入：
- `media/input.mp4`：ALE 官方原视频，1280×544，24 fps，241 帧，时长 10.041667 秒。
- `media/input.png`：ALE 官方绿幕目标参考图；它是静态外观参考，不是可代替视频运动的素材。
- `reference/`：本地安装版本的官方 Resolve API 文档；Fusion 控件可以通过公开查询接口查看。

要求：
1. 从新工程开始，用本地 Resolve/Fusion 制作可编辑的抠像、遮罩、合成链路，并由 Resolve 原生渲染。
2. 保留完整原片时长、24 fps、1280×544，以及主体的原始位置、尺寸和运动。不能裁剪掉难帧、冻结参考图、生成替代白鹤或直接交付原片。
3. 去掉全部天空、云层和其他场景残留；主体羽翼、颈部、喙、腿、尾羽、运动模糊尽量完整，边缘不要大面积硬切、光晕、孔洞或闪烁。
4. 每个非主体像素以纯绿为目标；有损视频编码造成的微小误差会区别于未去除的背景残留。
5. 查看自己的实际导出帧，并自行决定是否修正；不得访问隐藏参考视频或其他模型的输出。

交付至 OUTPUT_ROOT：
- `output.mp4`：完整成片，H.264；音频不是本题评分重点。
- `project.drp`：可导入、可继续编辑和重渲染的原生 Resolve 工程。
- `README.md`：简述处理方法、关键参数和已知缺陷。工程内的 Fusion 节点与素材引用应可追溯。
