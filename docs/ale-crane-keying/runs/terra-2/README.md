# 白鹤绿幕抠像

## 交付

- `output.mp4`：Resolve 原生渲染的 H.264 成片，1280×544、24 fps、241 帧（10.041667 秒），无音频。
- `project.drp`：可导入 DaVinci Resolve 的工程，时间线 `Crane Green`，包含完整源片和可编辑的 Fusion 合成。

## 方法

以 `input/media/input.mp4` 的每一帧为前景，静态 `input.png` 仅用于比较首帧外观，没有参与成片合成。Fusion 中 `CustomTool1` 以蓝、红通道差生成羽毛/天空分离的软遮罩，同时增加暗部和高亮保护，以保留黑颈、红顶、喙和细腿；`CoreMatte` 提供小范围身体内部补孔；`CloudSuppressLegs` 和 `CloudSuppressWing` 为局部云层抑制区域。`CraneGarbage` 定义总体范围，`WingUpCleanup` 用可编辑的 Level 关键帧，在翅膀收起的安全窗口清除下方云斑。`Background1` 为 RGB (0,1,0)，`Merge1` 合成后接 `MediaOut1`。

颜色键的主要软阈值为 `max(0,(0.04+R-B)*40)`，并结合暗部 `max(0,(0.46-max(R,G,B))*15)` 与高亮保护；局部云抑制区改用更严格的亮度遮罩。时间线素材的 ZoomX 为 120/119，ZoomY 为 1：这是补偿源文件被 Resolve 识别为 0.9917 像素宽高比而在方形像素时间线上产生的左右黑边，使输出对齐源片的像素坐标。其余时间线未做裁剪、变速或冻结。

导入 DRP 后若显示脱机，请将媒体池中的 `input.mp4` 重新链接到本次输入 `media/input.mp4`；Fusion 图和遮罩保留在时间线片段内。

## 检查及已知缺陷

已检查实际导出的首尾和多个拍翼、遮罩切换帧，且修正了曾影响羽尖的遮罩切换。由于原视频是天空和白鹤已混合的有损图像，灰云与羽毛颜色重叠，一些帧在翼下或附近仍有少量浅色云斑及轻微边缘噪声；细羽、脚趾和运动模糊也存在轻微丢失或绿边，不能保证完全无闪烁。H.264 的色度子采样及视频电平会使纯绿解码值产生少量偏差。
