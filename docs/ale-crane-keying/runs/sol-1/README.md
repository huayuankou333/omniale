# 白鹤天空分离 / 纯绿背景

## 正式交付
- **output.mp4**：由本地 DaVinci Resolve 原生渲染的 H.264 成片，1280×544、24 fps、241 帧、10.041667 秒，无音频。
- **project.drp**：本次独立工程的原生导出。主时间线 `Crane_Green_24p`，单一原始视频片段，Fusion 合成 `Composition 1`，范围 0–240。
- **Crane_Green.comp**：相同最终 Fusion 图的文本导出，便于检查节点、通道公式和素材来源；正式工程已包含这些节点。

`test_v*.mp4`、`diagnostic_source.mp4`、`inspection.comp` 和 `.fusion-imports/` 是制作过程的测试/诊断记录，不是正式成片，也不是工程的依赖。

## 素材与重渲染
唯一运动素材为本次输入 `input/media/input.mp4`。工程保留其原始路径引用；在其他机器导入 DRP 时，如媒体离线，请将 `input.mp4` 重链接到随任务提供的同一原视频。`input/media/input.png` 仅用于观察目标外观，没有作为视频画面、遮罩素材或冻结帧使用。没有使用外部模型、替代白鹤或生成图像。

源文件带约 0.9917 的像素长宽比标记；`Source_SquarePixel_Reformat` 在完整 1280×544、零偏移的画布上覆写为方形像素，以匹配输入解码图及目标参考的像素坐标。不做主体缩放、平移、时间重映射或时长裁剪。

## 原生 Fusion 方法
1. **White_Dark_Red_CoreSeed**：根据原片采样建立近白羽毛、黑羽/腿、红冠和暖中性灰羽的核心。喙尖观察范围内另加暗色保护。
2. **Core_Close_Dilate / Core_Close_Erode**：以 +0.022 / −0.022 的原生形态闭合填回中间灰羽；`Recover_Gray_Edge_Band` 的 +0.0025 仅提供小范围支持。
3. **Sky_ColorDifference_Matte**：使用蓝减红差异、暗部保护和蓝减绿中性约束拒绝蓝紫天空及粉灰云。主要蓝差上限/过渡为 **0.11 / 0.09**，暗部保护为 **0.30 / 0.12**。节点 RGB 储存宽松支持 matte，Alpha 储存严格 matte；具体公式保留在节点 Intermediate / Channels 中。
4. **Flight_Envelope_v2**：保守的可编辑原生多边形垃圾遮罩覆盖完整飞行范围，仅排除远离主体的背景，不用它描摹羽毛轮廓。
5. **Small_Hole_Fill_Dilate / Erode**：仅对 Alpha 做 +0.009 / −0.009 的局部闭合，修复源视频压缩色块造成的小孔。最终 Alpha 受宽松支持 matte 上限约束，避免把翼间天空整体填回。
6. **Original_RGB_Through_Refined_Matte**：重新读取原始视频 RGB，以细化 Alpha 预乘一次；白鹤内部颜色和运动均来自原片。
7. **Pure_Green_00FF00 → Crane_over_Pure_Green → MediaOut1**：全画幅 Background 设为精确浮点 RGB **(0,1,0)**、Alpha=1，与原白鹤合成。

所有关键节点均有 Comments 说明；无第三方插件、外部遮罩序列或参考图依赖。

## 已知局限
这是从已合成且有损压缩的天空片中反求 matte，并非原始带 Alpha 素材。极细脚趾、羽丝和快速运动的半透明混合边缘可能有少量收缩、柔化、轻微边色或逐帧变化；没有宣称恢复不可见细节或逐像素无误。检查过的正式帧未见大块天空/云团残留或大面积主体孔洞。
