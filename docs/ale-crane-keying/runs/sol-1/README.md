# 白鹤天空分离 / 绿幕交付

## 正式交付
- `output.mp4`：DaVinci Resolve 原生渲染，H.264，1280×544，24 fps，241 帧，10.041667 秒，无音频。
- `project.drp`：本次独立工程的原生导出；时间线 `Crane_Green`，视频轨 1 的原视频片段内含可编辑 Fusion 合成。
- `Crane_Key.comp`：同一片段的原生 Fusion 图副本，便于检查节点、公式及连接。

唯一运动素材为官方 `input/media/input.mp4`。`input/media/input.png` 仅用于观察目标外观，未作为前景或运动替代素材。保留完整源片段，未冻结、变速、删帧或重绘白鹤。

## 处理链路与关键参数
1. `MediaIn1 → SquareRasterMetadata`：完整 1280×544 光栅，偏移均为 0。Crop 节点仅将源文件约 0.9917 的像素宽高比元数据改为 1:1，以匹配解码参考图的光栅坐标；没有裁掉画面或对主体另做位移、缩放。
2. `SkyDifferenceMatte`（原生 Custom Tool）：以 `B-min(R,G)` 的蓝色过量建立天空排除遮罩。一般截止/过渡为 0.025/0.018；下方偏左的近中性云区使用 0.006/0.006。叠加亮白羽毛保护和暗羽、细腿、折叠翅尖保护分支。暗部截止/过渡在上翼及腿区为 0.62/0.20，其他区域为 0.46/0.12。具体区域条件、亮部阈值都保存在节点公式内。
3. `SubjectGarbage`：可编辑 Polyline 广域排除遮罩，SoftEdge=0.002。它只限制主体可能出现的范围；实际细轮廓和运动仍由每帧原视频决定。
4. `MatteClose_Dilate / MatteClose_Erode / InteriorRepairOnly`：0.003、-0.003、-0.004 的原生形态处理。仅将修补结果加入主体内部，保留原遮罩的外沿和羽尖间隙，减少压缩造成的内部透明斑点。
5. `SubjectSupport_Core / Expand → RejectDetachedSkySpecks`：-0.004 / 0.018 的空间支持范围清理，去掉脱离主体的小云片；颈、喙及局部暗细节有保留分支。
6. `ApplyRepairedAlpha`：将最终 Alpha 乘回原视频 RGB，并将蓝色过量保守限制在 `max(R,G)+0.006`，减轻天空蓝边。
7. `CraneOverGreen`：Normal Over 合成到 `PureGreen_00FF00`，背景原生 RGB=(0,1,0)、Alpha=1，最后接 `MediaOut1`。

各关键节点都有英文 Comments，可继续调节参数及遮罩。没有外部抠像模型或外部图像生成步骤。

## 检查与局限
已反复查看实际 Resolve 测试渲染和正式 `output.mp4` 的首尾帧、抬翼、交叠、下扑及折翼阶段，并针对云片、内部孔洞和细线断裂做了修正。正式文件已核对为完整 241 帧。

这是从已压缩、已与天空合成的图像反推遮罩，并非原始 Alpha：个别快速运动的羽尖、脚趾及细腿仍可能有轻微灰边、轮廓软硬变化或亚像素细节损失。H.264 色度抽样在细黑轮廓旁也会产生少量绿色色度渗入。大面积背景为统一绿；最终文件在首帧角落及原云片位置抽查解码为 RGB=(0,252,0)，相对合成节点的 (0,255,0) 存在约 3 级编码/输出偏差。
