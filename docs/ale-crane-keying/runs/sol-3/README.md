# 白鹤绿幕抠像交付

## 正式文件
- `output.mp4`：Resolve 原生渲染的 H.264 成片，1280×544，24 fps，241 帧，10.041667 秒，无音频。
- `project.drp`：实际制作工程，可导入 Resolve 后继续修改、重渲染。
- `README.md`：本说明。

工程时间线为 `Crane_Green_Master`，源片完整使用第 0–240 帧，没有裁掉难帧、变速、冻结或替换白鹤。唯一视频素材为本次 `input/media/input.mp4`。`input.png` 仅用于观察目标外观，未作为合成素材使用。工程保留原始本地素材引用；迁移到其他目录后，请将离线素材重链接到该 `input.mp4`。

## 原生 Fusion 链路与参数
主链为 `MediaIn1 → Crane_ColorDifference_Matte → Crane_Over_PureGreen → MediaOut1`。所有颜色来自逐帧原视频；Custom 节点输出原 RGB 乘以计算得到的 alpha，然后通过正常 Over 合成至 `Pure_Green_00FF00`。该 Background 的未编码 RGBA 为 **(0, 1, 0, 1)**。

- 色差指标：`B − min(R,G)`。主要蓝色清除阈值 0.026、过渡宽度 0.020。
- 黑羽、细腿和喙的暗部恢复：最大 RGB 阈值 0.48，过渡 0.18。
- 白羽边缘恢复：最小 RGB 起点 0.78，过渡 0.18。
- 背景低 alpha 清理：0.25；羽毛恢复窗口中使用较宽松的 0.040 / 0.028 色差参数。
- `Subject_Safe_Envelope` 是原生多边形范围遮罩，去除主体运动范围外的偏中性云块，不用它替代白鹤轮廓。
- `HighConfidence_WhiteBlack_Core` 从白/黑主体像素生成支持区（最小 RGB > 0.88 或最大 RGB < 0.45），经原生 ErodeDilate 闭运算（Amount ±0.015625）和小幅扩展（0.00234375）排除孤立云块。该支持区不直接成为最终羽毛边缘。
- 两个原生 RectangleMask 提供羽翼灰色区域的色差恢复窗口；`Pack_CoreSupport_And_FeatherRecovery` 将支持区和窗口分别打包至 alpha 与红通道，供主抠像节点使用。节点均有清晰名称，关键节点附有 Comments。

源文件的像素宽高比标记约为 119:120。时间线水平 Zoom=120/119、垂直 Zoom=1，仅抵消 Resolve 对该标记造成的横向压缩及两侧窄黑边，使输出按原始 1280×544 栅格呈现；未改变主体运动或垂直尺寸。

## 实际导出检查与限制
制作过程中多轮原生渲染并检查了全片不同摆翼阶段；正式 `output.mp4` 也已重新解码抽查首帧、末帧以及 0.5、1.5、3、5、5.75、7.25、8.5、9.25 秒等时刻。已针对云块残留和灰色翼根孔洞修改链路，最终抽查未见大片天空或云层残留。

已知限制：最淡的运动模糊及压缩混色边缘采用较保守的清除，细趾、喙尖和快速摆动的细羽可能有约 1–3 像素收缩、局部轻微断续或透明度变化，不能从已合成的有损源片完美还原独立 alpha。H.264/视频色彩转换也带来轻微数值误差：背景抽样约为 RGB(0,252,0)，工程内绿色仍为精确的 #00FF00。未声称逐像素无损。

目录中的 `key_test_v*.mp4` 是调参检查片，`inspection.comp` 和 `.fusion-imports/` 是制作检查/原生节点导入记录；正式成片以 `output.mp4` 为准。
