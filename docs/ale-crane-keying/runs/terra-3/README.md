# 白鹤绿幕抠像

- `output.mp4`：Resolve 原生渲染，H.264，1280×544，24 fps，241 帧（10.041667 秒），无音频。
- `project.drp`：含完整时间线和可编辑 Fusion 节点。素材引用原始 `input/media/input.mp4`；在其他机器打开时若素材离线，请重链接该文件。

## 方法

在单个原片片段的 Fusion 合成内，根据蓝红差、亮度和蓝绿通道差构建抠像。`CoreLuma` 保护亮白羽毛、深色细节及暖灰羽毛，`CoreGrow` 的扩张量为 0.008；`ChromaComposite` 将色差蒙版、暗部保护和核心限制组合后与绿屏进行通道合成。`GarbageCrane` 是限定鸟的活动范围的多边形垃圾遮罩；`CloudCleanupMask` 和 `CloudCleanup` 对片头短暂可见的云块做局部、关键帧绿填充。`PureGreen` 为 RGB (0,1,0)，帧格式 1280×544，方形像素。没有使用静态参考图代替运动素材。

渲染后实际查看了开头、清理动画转折、多个中段姿态和末帧，并核对视频尺寸、帧率和完整帧数。

## 已知缺陷

源画面已把白鹤与天空合成，羽毛边缘和背景颜色存在混合，数学色键并不能完全恢复被背景污染的边缘。少量灰白云残片仍可能在片头及约 1 秒附近靠近腿部或下垂翼的位置出现；细腿、羽尖和运动模糊局部可能有轻微软化、色边或逐帧变化。H.264 的色度采样和编码也会使解码后的纯绿及主体边缘出现轻微数值误差。
