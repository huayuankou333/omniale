# 白鹤绿幕抠像交付

## 工程与输出
- `output.mp4`：Resolve 原生时间线渲染，H.264，1280×544、24 fps、241帧（10.0417秒）。
- `project.drp`：本次Resolve工程，含原始 `input.mp4` 媒体引用及Fusion合成，可继续调整与渲染。重新打开时需维持输入媒体路径可用或在Media页面重新链接。

## 处理方法
Fusion链路使用源 `MediaIn1` → `ChromaKeyer1` → `Merge1` 前景；`Background1` 为RGB (0,1,0)纯绿并连接Merge背景，Merge输出至 `MediaOut1`。ChromaKeyer依据天空蓝/青色范围键控，保留主体源画面的原始尺寸、位置与运动。Fusion节点参数：Red 0.34–0.88、Green 0.38–0.92、Blue 0.53–0.96，Soft Range 0.10；低/高Matte阈值分别0.02/0.13。参考PNG仅用于目标外观观察。

## 已知限制
天空云层与部分接近白鹤浅色羽毛的亮色在颜色上高度重叠。当前简单RGB范围色键保住了主体主要轮廓、腿、颈、翼和尾羽，但成片检查可见若干云层/亮天空残留斑块及少量边缘不均；这不是逐帧精细 roto，难以在不损伤白色羽毛的情况下彻底清除。建议后续在Fusion为这些区域添加随时间跟踪的垃圾遮罩、优化Matte并逐帧检查。输出并非完美纯绿背景。
